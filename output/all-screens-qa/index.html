  • 새 제작 화면의 표지·내지는 실제 등록된 템플릿 문서입니다. 채워진 사진 화면은 레이아웃 검토용 샘플이며 사용자 앨범에 샘플 사진을 넣지 않습니다. 실제 제작 연결 캡처는 샘플 사진을 비운 상태로 규격·진행 표시·사진 채우기·뒤로가기를 검증합니다.

  • 앨범·사진·가격·주문·주소·초대 링크는 로컬 검토 자료입니다. 실제 저장·공유·결제·AI·배송 요청은 하지 않았습니다.

  • 계정과 알림 캡처도 mock 자료입니다. 실제 탈퇴·로그아웃·재설정 메일·기기 권한 요청·알림 전송은 실행하지 않았습니다. 확인 시트는 고정 버튼과 스크롤 본문을 구분하며 닫힌 시트의 늦은 입력을 차단합니다.
