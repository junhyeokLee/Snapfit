생성부터 자유 편집까지 이어 만들기를 연결했습니다. 편집 중 임시 저장, 저장 실패·복원과 앨범 초대의 보내기·받기 화면을 확인할 수 있습니다.

이번 편집 개선에서는 선택해도 썸네일 크기가 변하지 않고 현재 쪽이 목록 안에 자동으로 나타납니다. 추가·삭제는 사진 위에 겹치지 않는 별도 버튼이며, 80쪽 목록도 화면 주변만 생성합니다. 레이어의 실제 사진·장식과 문구 글꼴을 미리 보여 주고, 가로의 좁은 패널은 이름과 순서 이동 손잡이를 분리합니다. 가로에서 레이어를 선택해도 편집 화면이 닫히지 않으며 기존 겹침 순서·실행 취소를 유지합니다. 같은 레이어의 사진·문구 교체도 새 내용으로 갱신합니다. 캡처의 반복 페이지는 동작 검증용 자료이며 새 판매 템플릿이 아닙니다.

새 제작 미리보기, 설정, 사진 채우기와 전체 확인은 승인한 홈과 같은 표지 재질을 사용합니다. 가로 내지는 실제 좌우 페이지를 붙여 보여 주며, 설정의 ‘사진 추가 전’은 샘플 사진을 사용자 앨범에 저장하지 않는 기존 규칙을 나타냅니다. 전체 확인에서는 빈 사진이 있는 쪽만 모아 보고 원래 쪽 번호로 돌아갈 수 있습니다. 긴 앨범의 제작 미리보기 목록은 화면 주변 항목만 생성합니다. 표시된 사진과 앨범은 테스트 자료이며 실제 저장·구매·기기 설치는 실행하지 않았습니다.

초대 화면은 실제 앨범 표지·편집 권한·현재 링크를 확인하고, 하단의 버튼으로 같은 링크를 복사·공유합니다. 가로 화면은 두 열, 작은 세로 화면은 스크롤 가능한 본문과 고정 버튼으로 구성하며 시스템 버튼·카메라 여백을 확보했습니다. 준비 중에는 권한 변경과 공유를 잠그고, 실패 후에는 재시도할 수 있습니다.

초대는 모의 데이터로 화면과 동작을 검증했으며 실제 메시지를 보내지 않았습니다. 현재 서버의 앱 전용 링크는 카카오톡 공유 대신 복사로 대체됩니다. 초대받은 사용자의 앱 진입·로그인·권한 확인·수락 화면 연결은 아직 후속 작업입니다.

사진 채우기와 표지 편집을 오가도 미사용 사진 보관함·선택한 페이지·실행 취소 기록을 유지합니다. 표지에서 나중에 수정한 내용은 사진 채우기의 이전 되돌리기 기록이 덮어쓰지 않도록 분리했습니다. 전체 확인에서 실제 앨범 비율과 빈 사진 자리를 확인하고, 사진이 있는 페이지를 눌러 수정할 수 있습니다. 아직 디자인하지 않은 빈 쪽은 편집 시작 후 꾸밀 수 있습니다.

임시 저장은 이 기기의 계정별로 한 개씩 보관하며, 홈의 ‘이어 만들기’로 복원합니다. 새 앨범 생성 후 자유 편집에서도 수동 임시 저장·나가기·앱 비활성화 시 수정한 표지와 내지, 배경색, 사진 구도, 현재 쪽을 함께 보관합니다. 복원할 때 같은 앨범으로 이어지고, 표지와 내지 좌표를 따로 보존해 크기를 다시 맞추지 않습니다. ‘저장 안함’은 이번 편집 진입 전 상태로 돌아가며, 앨범 전체가 서버에 저장된 뒤에만 임시 저장을 정리합니다. 이전 편집 화면의 늦은 저장은 다른 새 초안을 덮어쓰거나 지운 초안을 되살리지 않습니다.

기존에 저장된 앨범을 리더에서 수정하는 경로는 기존 저장 방식을 유지합니다. 임시 저장은 기기 간 동기화가 아니며, 실행 중 강제 종료 전에 저장이 완료되었다고 보장하지 않습니다. 사진 원본을 복사하지 않으므로 갤러리 삭제·접근 권한 변경 시 사진을 다시 선택해야 할 수 있습니다. 앱을 다시 열어 복원한 경우 실행 취소 기록은 새로 시작합니다.

사진 채우기 단계에서도 배치·교체·구도·삭제를 실행 취소하거나 다시 실행할 수 있습니다. 교체·삭제 후 사용되지 않는 사진은 보관함으로 돌아오며, 최근 30개 작업을 기억합니다. ‘다음 빈 자리’는 같은 쪽 안의 모든 사진 자리를 거쳐 앨범 순서대로 이동합니다. 가로 화면은 보관함과 페이지 목록을 양옆에 배치하고, 작은 세로 화면은 도구 영역을 압축해 앨범 공간을 확보했습니다. 회전해도 사진과 기록을 유지하며, 새 템플릿으로 바뀌면 이전 작업은 적용하지 않습니다.

홈·리더의 앨범 연출과 책 넘김은 유지했습니다. 편집 화면의 사진 교체는 기존 프레임 안에서 새 구도를 확인한 뒤 적용하며, 취소하면 원본을 유지합니다. 갤러리 중복 사전 로딩과 사진 크기 선택창 취소 후 추가 문제도 수정했습니다. 실제 사진·프레임 미리보기, 무료·유료·보유 필터, 즐겨찾기와 구매 권한 확인은 유지합니다.

초대 링크는 로그인 전후와 앱 재시작에도 보관하며, 로그인만으로 자동 참여하지 않습니다. 앨범과 권한을 확인하고 직접 수락합니다. 사용·만료·삭제된 링크는 재요청을 안내하고, 네트워크 오류는 직접 다시 확인합니다. 가로 화면은 앨범 안내와 참여 권한을 양옆에 배치합니다. 참여 후에는 공유 앨범이 홈에 함께 표시되며, 보기 전용 앨범의 편집을 제한합니다. 새 서버 함수와 데이터베이스 변경은 아직 운영 서버에 배포하지 않았습니다. 실기기 링크·카카오톡 연동은 별도 검증이 필요합니다.
