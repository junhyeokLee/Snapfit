# 둘만의 여행: 펼침면 구조 연구

2026-09-09. 여행 수집물 컨셉과 단일 사진 표지는 유지하되, 페이지의 실루엣과 사진 면적, 재료의 역할부터 다시 설계한다. 기존 20쪽을 지운 것이 아니라 별도의 읽기 전용 보관본으로 분리했다.

## 보관본

- 빌더: `lib/core/templates/authored_travel_keepsake_archive.dart`.
- 원본 문서: `tool/template_studio/archives/travel-keepsake-20/{portrait,square,landscape}.json`.
- 세 문서 전체를 보관 빌더 출력과 깊은 비교하는 회귀 테스트로 변경을 감지한다.
- 기존 렌더 결과: `output/template-preview/travel-keepsake-20/`.
- [20쪽 보관본 열기](http://127.0.0.1:4323/?collection=travel-keepsake-20#/travel-keepsake-20).
- 미리보기 상단 시안 선택에서 **둘만의 여행 · 20쪽 보관본**으로 이동한다. 문구 편집은 숨기고 규격 선택, 목차, 확대와 사진 숨기기는 유지한다. 저장된 원본은 수정하지 않는다.

## 현재 작업 범위

**승인된 표지 + 대표 내지 8쪽, 4개 펼침면**. 한 권 20쪽 완성본이나 판매 등록본이 아니다. 활성 주소와 즐겨찾기 식별자 `luminous-edition`은 유지한다.

| 쪽 | 왼쪽 | 오른쪽 | 차이를 만드는 요소 |
| --- | --- | --- | --- |
| 1–2 | 화면을 채우는 바다 사진 | 일정표와 여행 서류 포켓 | 이미지 중심과 수집물 중심의 대비 |
| 3–4 | 메모 여백을 둔 3컷 인덱스 | 원형 테이블 사진과 코스터·영수증 | 직선 사진 띠와 원형 구성 |
| 5–6 | 페이지 폭을 쓰는 항구 사진 | 접은 편지와 봉투, 사진 없는 기록면 | 가로로 긴 사진과 세로로 읽는 편지 |
| 7–8 | 두꺼운 매트의 인물 사진 | 문구가 붙은 가로 인화 엽서 | 세로 프레임과 가로 카드의 대비 |

사진 개수나 장식 최소 수를 모든 페이지에 똑같이 적용하지 않는다. 장식이 사진을 가릴 이유, 종이가 겹쳐지는 이유, 읽는 순서가 있어야 한다. 반복되는 색과 일부 우표는 책의 통일성을 위한 것이며 페이지 구조는 분리한다.

표지 구성은 보관본과 완전히 동일하다. 편지, 여행 기록, 이름, 날짜와 사진은 기존 편집 가능한 레이어 형식을 따른다. 원형 사진과 모든 재료는 세로/정사각형/가로 규격에서 원래 종횡비를 유지한다.

## 추가 재료

**반투명 여행 서류 포켓** (`travelDocumentPocket`): 가로형 종이 포켓의 손잡이 홈, 접착선, 절취 점선과 무광 반투명 질감. 기존 작은 정사각형 봉투를 억지로 늘리지 않고 별도 재료로 제작했다.

기존 56종을 유지하고 1종을 추가해 총 57종. 실제 앱의 여행 기록 꾸밈 목록과 미리보기 갤러리, 즐겨찾기, 삽입·실행 취소·저장에 동일한 키로 연결한다. 기존 무료 37종 및 프레임·문구는 변경하지 않는다.

## 검증과 출시 경계

- 보관본 세 규격 전체 JSON 일치, 기존 표지 일치.
- 대표 8쪽의 사진 개수, 면적 대비, 서로 다른 구성, 원형 크기, 재료 종횡비.
- 실제 Flutter 렌더로 글자 잘림, 겹침, 경계, 사진 교체 슬롯 및 저장·복원.
- 포켓 홈의 투명 영역과 반투명 중심, 기존 재료와 같은 렌더러 사용.
- 브라우저 검수: 휴대폰 세로·가로 및 데스크톱에서 세 규격, 네 펼침면, 목차·문구 편집·즐겨찾기·비교·보관본 탐색.

사용 사진은 기존 프로젝트의 레이아웃 검토용 샘플이다. 이번 작업은 AI API 호출 없이 사람이 구성한 디자인이다. `catalogPublishable: false`, `accessTier: unassigned`를 유지하며 자동으로 유료 판매에 등록하지 않는다. 인쇄 실물, 사용자 사진 교체 결과 및 에셋 권리 검수는 출시 전에 별도로 필요하다.
