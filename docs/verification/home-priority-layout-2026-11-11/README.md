# 홈 우선순위 배치 반영 — 2026-11-11

## 적용한 판단

매일 사진을 남기는 목적을 첫째로 두고, 직접 만든 앨범을 크게 보는 것을 바로 다음에 둔다. 사용자가 두 목적 모두 중요하게 생각하며 우선순위 판단을 위임한 데 따른 작업자 제안이다. 사용성 실험이나 리텐션 수치로 검증된 결론은 아니다.

현재 순서는 **월간 기록·오늘 기록 → 큰 앨범 한 권 → 작은 앨범 선택 목록 → 모아둔 순간·월간 앨범 엮기·이어서 만들기**다. 보조 기능을 제거하지 않고 기존 `HomeAlbumSlider.footer`로 옮겼다. 빈 앨범·오류·로딩·목록 화면은 기존 전체 기록 구성을 유지한다.

높이 700px 미만의 유효 기록 화면에는 달력 위에도 작은 기록 버튼이 나타난다. 기록 전에는 `오늘 기록하기`, 기록 후에는 `새 기록 남기기`이며 기존 작성 콜백을 그대로 사용한다. 로딩·로그인 전·오류 상태에는 추가하지 않는다. 달력 전체, 하단 오늘 기록 상태/사진과 큰 앨범의 크기는 유지했다.
