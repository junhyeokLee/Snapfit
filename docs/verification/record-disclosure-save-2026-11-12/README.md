# 기록 펼침·저장 로딩·저장 사진 표시

2026-11-12 KST. 사용자 요청의 기록 화면 세 항목은 실제 Flutter 소스에 반영했다. 앨범 좌우 넘김은 확인용 대화 샘플만 수정했고 Flutter reader 자체는 변경하지 않았다.

## 반영한 동작

- 저장 기록은 기본 접힘이다. 날짜 헤더를 누르면 그때 저장한 사진이 펼쳐지고 다시 접을 수 있다. 모호한 … 버튼을 제거하고 명시적 기록 다듬기는 펼친 내용 안으로 이동했다. 캘린더로 같은 날짜를 다시 선택해도 열리고, 접었다 다시 열면 표시 사진과 공유 대상이 첫 사진으로 일치한다.
- 저장 중 전체 화면에 해제 불가 로딩을 표시한다. 헤더·본문·스크롤·웹 메뉴·키보드·접근성 탐색과 뒤로가기를 막는다. 서버 저장과 공개 상태 확인이 끝날 때까지 유지한다. 실패하면 잠금을 풀고 입력·임시 기록을 보존한다.
- 저장 완료 화면에서 임시 월간 표지를 만들던 경로를 삭제했다. 방금 저장한 사진/지면 자체를 원래 비율로 표시한다. 자동 합성하던 사진 분수·월 제목·표지 배경은 없다. 사용자가 원본 지면 안에 직접 만든 텍스트·배경·레이어는 그대로다. 월간 앨범 생성 도메인은 변경하지 않았다.

## 넘김 샘플

기존 한 장 교체 모델을 펼친 책과 읽는 쪽을 따라가는 화면 이동 모델로 바꿨다.

| 출발 | 도착 | 동작 |
| --- | --- | --- |
| 오른쪽 2쪽 | 왼쪽 3쪽 | 앞면 2쪽/뒷면 3쪽이 같은 종이의 앞뒤로 제본을 축으로 회전 |
| 왼쪽 3쪽 | 오른쪽 4쪽 | 같은 펼침 안에서 읽는 쪽으로 화면 이동 |
| 왼쪽 3쪽 | 오른쪽 2쪽 | 이전 장을 역방향으로 회전 |

왼쪽을 볼 때 제본은 오른쪽, 오른쪽을 볼 때 제본은 왼쪽이다. 실제 앨범 규격 1:1·4:3·5:4, 드래그 추적·취소·속도·버튼 이동·멀티터치 방어·규격/크기 전환 취소를 유지한다. 앞뒷면의 글자가 뒤집히지 않는지도 수학적으로 확인했다. 이 샘플은 실제 브라우저/기기 렌더를 검증했다고 주장하지 않는다. 대화에서 사용자 확인이 필요한 움직임 컨셉이다.
