# 피드·알림·내 디자인 개선 적용

2026-11-16. 승인한 네 항목을 적용했다. 기존 아이콘을 사용하면서 안내의 가독성, 되돌리기, 목록의 공간 사용을 개선했다.

| 항목 | 적용 결과 |
| --- | --- |
| 오류 안내 | 오류 배경과 대응 본문 색을 함께 사용한다. 실제 대비는 라이트 2.27→6.46, 다크 1.56→7.72로 개선됐다. |
| 즐겨찾기 해제 | 내 디자인에서 `즐겨찾기 해제 · 되돌리기`를 4초간 제공한다. 사라진 미구매 항목을 실제 목록과 저장소에 복원한다. |
| 중복 필터 | 즐겨찾기만 선택했을 때 반복되는 조건·초기화 행을 생략했다. 검색·분류·정렬을 결합한 조건 표시와 빈 결과 초기화는 유지한다. |
| 댓글 이름 | 공간이 부족하면 작성자 배지·시간을 다음 줄로 보낸다. 320dp·글자 1.8배에서 이름이 표시되고, 기본 390dp와 가로 화면은 한 줄을 유지한다. |

## 동작과 구현

즐겨찾기 되돌리기는 내 디자인에서만 활성화한다. 제작·편집기 선택 도구는 기본 동작을 유지한다. 이미 다른 곳에서 다시 즐겨찾기한 항목은 되돌리기를 눌러도 해제되지 않도록 명시적 선택 상태를 기존 직렬 저장 큐에서 처리한다. 저장 실패 시 이전 상태로 복구하고 오류를 안내한다.

교체·만료된 안내와 종료된 화면의 되돌리기를 차단한다. 화면 전환 중 Snackbar가 여러 Scaffold에 표시되는 동작도 검증해, 내용의 GlobalKey를 제거하고 안내 종료 이벤트로 수명을 관리했다. 구매 보유권·상품 키·가격·앨범 데이터는 수정하지 않았다.

제품 변경은 다음 6개 파일이다. 시작 시점의 해시와 비교해 나머지 815개 Dart 제품 파일은 동일함을 확인했다.

- `lib/core/utils/context_extensions.dart`
- `lib/core/templates/catalog_favorites.dart`
- `lib/shared/widgets/catalog_favorite_widgets.dart`
- `lib/features/store/presentation/widgets/library_design_tile.dart`
- `lib/features/store/presentation/views/material_catalog_screen.dart`
- `lib/features/social/presentation/widgets/social_comment_widgets.dart`

## 검증

관련 테스트·캡처 시나리오 **70개 통과**, 새 화면 **30장**을 생성했다. 무거운 실행은 모두 직렬로 진행했다. 수정한 제품 파일 6개와 테스트 파일 5개 정적 분석 결과는 `No issues found!`다. 독립 코드 검토에서 최종 차단 이슈는 없었다.

| 검증 범위 | 통과 |
| --- | ---: |
| 라이트·다크 오류 안내 대비 | 2 |
| 단독·복합 필터 복구 | 2 |
| 되돌리기·저장 실패·동시 재추가·안내 수명·화면 종료 | 8 |
| 댓글 기본·큰 글자·가로·답글 배치와 콜백 | 4 |
| 기존 즐겨찾기 저장·복구 | 12 |
| 기존 제작·편집기 즐겨찾기 | 22 |
| 소재 목록·가격 필터·페이지 처리 | 4 |
| 댓글·답글·멘션 연결 | 7 |
| 실제 피드·보관함·알림 화면 시나리오 | 9 |

기존 제작 목록 테스트 1개는 예전 진입 동선을 사용해 실패했다. 현재의 디자인 목록 열기 버튼으로 진입하고, 선택 후 바뀌는 툴팁 대신 안정적인 키를 사용하도록 갱신했다. 제작 목록에서 해제할 때 되돌리기가 표시되지 않는 것도 확인했다.
