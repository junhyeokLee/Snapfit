# 첫 사용 안내와 다음 초대 개선 — 2026-11-12

[직전 전체 검토](../next-ux-audit-2026-11-12/README.md)에서 확인한 개선 2건을 반영했다. 사용자 요청에 따라 [용량 정리](../storage-cleanup-2026-11-12/README.md)를 먼저 완료했다.

## 바뀐 동작

- 첫 홈의 큰 팝업을 월간 기록 안의 인라인 안내로 교체했다. `오늘 기록하기`를 우선하고 `앨범 바로 만들기`도 바로 선택할 수 있다. 안내는 달력/진행률 위에 겹치지 않으며 닫을 수 있다.
- 유효한 기록 화면에서만 첫 안내를 소비한다. 로딩·오류·숨겨진 탭/목록 하단에서는 소비하지 않는다. 설정에서 다시 보기를 요청하면 안내 위치로 스크롤하고, 자동 첫 안내는 기존 스크롤을 이동시키지 않는다.
- 소개 2장은 오늘 사진을 모으거나 디자인으로 앨범을 바로 만드는 두 출발점을 설명한다.
- 초대 성공 화면에 `새 링크 만들기`를 추가했다. 현재 편집/보기 권한을 유지하며 새 링크를 발급한다. 대기 중에는 중복 발급·공유·복사를 차단하고 실패 시 기존 재시도로 복구한다. 작은 화면에서는 링크 아래에 새 링크 행동을 배치한다.

큰 앨범과 작은 선택 목록의 크기, 사진 비율, 달력 크기, 1,000P·당일 사진 인정 정책은 이 작업에서 변경하지 않았다. 첫 안내가 있는 동안 내용은 안내 높이만큼 아래로 흐른다. 320×568에서는 달력 전체를 보려면 스크롤해야 한다.

## 검증

안내의 최초 노출·닫기·재요청·숨은 탭/route·대형 글씨/회전, 유효 상태가 되기 전 안내 미소비, 스크롤이 남은 상태의 다시 보기, EDITOR/VIEWER 새 링크·연타·대기·실패 복구를 포함한다. 초대 관련 기존 수락·공유·계정 격리 회귀 검사도 통과했다.

첫 홈 golden은 변경 화면을 직접 확인한 뒤 갱신했고, 자동 갱신을 끈 새 실행에서도 비교가 통과했다. 의도한 새 동작이 없어서 실패한 RED 로그와 최종 통과 로그를 [logs](logs)에 보관했다. 전체 판정 및 파일 해시는 [verification.json](verification.json)에 있다.

전체 앱 빌드·실기기·실제 서버 초대는 실행하지 않았다. 임시 테스트 커널은 검증 완료 후 다시 삭제했다.
