# 2026-09-10 카탈로그 반영

사용자가 승인한 `shared-seasons` 종이 질감 리비전 3을 보존한다.
무료 컬렉션 37종, 기존 유료 컬렉션 7종, 신규 컨셉 컬렉션 7종,
프레임·종이·스티커·문구와 편집기 연동, 오늘의 편집·인쇄 운영 작업을 함께 저장한다.
열쇠나 흰 문구판을 재도입하지 않고 최신 24쪽 구성을 유지했다.

## 가격과 판매 상태

| 구분 | 수량 | 가격 | 서버 상태 |
| --- | ---: | ---: | --- |
| 기존 무료 템플릿 | 37 | 0P | 활성 |
| 기본 꾸밈 재료 | 12 | 0P | 활성 |
| 유료 꾸밈 재료 | 71 | 100~400P | 활성 |
| 기존 유료 컬렉션 | 7 | 2,500P | 판매 대기 |
| 신규 컨셉 컬렉션 | 7 | 1,800P | 판매 대기 |

37개 무료 템플릿은 최근 유료 재료 없이 사용할 수 있는지 세 규격으로 검사한다.
유료 템플릿 가격은 컬렉션 단위이며 표지와 세 규격을 포함한다.
2,500P 그룹은 제공되는 기본판·확장판 전체, 1,800P 그룹은 내지 24쪽 기준이다.
확장판이 없는 기존 컬렉션도 있어 쪽수만으로 가격을 결정하지 않는다.
가격은 출시 가설이며 할인율·경쟁사 우위·시장 검증을 주장하지 않는다.

## 실제 반영

- 대상 프로젝트: `rrbhxdtriummqpztpjrk` (SnapFit).
- 가격 리비전: `2026-09-10-catalog-5`.
- 적용 전 상품 8행을 백업했다. `template:lightbound`의 기존 700P는
  무료 컬렉션 정책에 맞게 0P로 변경했다.
- 명시된 134개 상품만 트랜잭션으로 적용했다. 스키마·지갑·구매 내역은 변경하지 않았다.
- 134개 상품의 키·가격·활성 상태 및 `get_point_shop_access` 응답을 재조회하여
  전부 일치함을 확인했다. 실제 사용자 포인트 차감이나 앱마켓 결제는 실행하지 않았다.
- 적용 자료: `output/pricing/catalog-2026-09-10/`의 `before.json`,
  `application.json`, `apply-prices.sql`, `verify-prices.sql`, `verified.json`.
- `application.json`의 `prepared-not-executed`는 내보내기 도구가 생성하는 계획 상태다.
  실행 여부는 별도 `verified.json`의 `applied-and-read-verified`로 기록한다.

## 판매 대기 사유

유료 템플릿 구매 시 실제 포함된 유료 재료까지 계정에 제공하는 정책은 유지한다.
원본 전달·버전별 포함 명세·원자적 차감과 권한 지급·구매 복원 검증이 끝나지 않았으므로
14개 템플릿은 관리자에서도 활성화할 수 없도록 제한한다. 가격 등록을 판매 개시로
표시하지 않는다. 신규 앱 배포나 인쇄 실물 검수도 이번 작업에서 수행하지 않았다.

## 검증과 남은 항목

- 서버 상품 134행과 접근 RPC 응답을 검증했다.
- 디자인·단위·인쇄·재료/관리자 위젯 묶음에서 1,133개 통과, 1개 건너뜀.
  즐겨찾기 정렬 후 스크롤 위치를 고려하지 못한 테스트 2건은 수정 후 각각 통과했다.
  따라서 이 묶음의 1,135개 테스트는 분할 실행 및 재실행 기준 통과했다.
- 승인된 사진/지면은 바꾸지 않고 카탈로그 개수, 프레임 외곽 기대값,
  즐겨찾기 후 재정렬을 반영한 테스트를 수정했다. 편집기/스토어 사진 픽셀 일치 검사는 유지했다.
- 미리보기 웹 릴리스 빌드 성공. Playwright에서 390×844, 844×390, 1440×900의
  표지·내지·문구 편집·샘플 사진 토글·즐겨찾기·14종 목록을 검증했다.
- 전체 정적 분석: 오류·경고 없음, 기존 테스트의 info 수준 lint 3건 남음.
- 전체 테스트가 모두 성공한 것은 아니다. 전체 실행에서 발견한 아래 13건은
  이번 가격/카탈로그 정리에서 수정하거나 골든 이미지를 덮어쓰지 않았다.
  앱 전체 배포 승인 전 별도 해결이 필요하다.
