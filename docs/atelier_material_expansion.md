# 프레임과 편집 가능한 문구 확장

2026-09-09. 기존 템플릿과 재료는 유지하고 신규 재료 36종을 추가했다.
최근 재료 작업실은 기존 28종을 포함해 64종을 보여 준다.
이는 앱 전체의 모든 기존 꾸밈 재료 수를 의미하지 않는다.

## 구성

- 프레임 12종: 세 겹 단차, 양문 폴리오, 키홀 아치, 교차 리본,
  네거티브 스트립, 봉투, 옥스퍼드 체크, 해안선, 종이 직조,
  아르데코 계단 창, 아코디언, 접힌 코너.
- 문구 조합 16종: 청첩장, 서약, 리본, 탑승권, 노선도, 엽서,
  다이어리, 색인, 인장, 첫돌, 첫 순간, 주말, 기념일, 산책, 컷페이퍼, 시네마.
- 조합용 장식 8종: 이중 압인판, 실크 라벨, 탑승 반권, 우편 띠,
  접힌 모눈지, 타원 인장, 컬러 종이, 네 귀퉁이 홀더.

이번 배치는 색상 복제나 PNG 프레임 덧씌우기 대신 코드 기반의 사진 창과
장식 렌더를 추가한다. 사진은 교체와 크롭 가능한 한 개의 원본 레이어다.
아코디언도 한 사진이 이어져 보이는 세 창이며 독립 사진 세 칸이 아니다.
인쇄·에디터·템플릿 미리보기에서 동일한 렌더 경로를 사용한다.

문구 조합은 제목, 보조 문구, 날짜/숫자, 장식이 각각 별도 레이어다.
한 번 삽입과 한 번 실행 취소/다시 실행으로 전체 조합을 다룰 수 있다.
삽입 후에는 일반 레이어이므로 내용·폰트·색을 바꿀 수 있다. 영구적인
그룹 객체나 자동 날짜 계산 기능을 추가한 것은 아니다. 예시의 도시,
날짜, 기념일 숫자는 편집 가능한 샘플이며 사용자 정보를 자동 추론하지 않는다.

## 유료 템플릿의 다음 기준

재료가 64종이 되었다는 이유만으로 유료 품질을 통과한 것으로 보지 않는다.

1. 주제마다 주력 프레임 2~3종과 보조 장식을 선정한다. 모든 재료를 한 페이지에
   넣지 않는다. 문구·프레임·사진이 같은 컨셉을 전달해야 한다.
2. 24~36쪽 전체에서 전면 사진, 기록 페이지, 강조 펼침면, 여백 페이지의 리듬을
   확인한다. 동일 레이아웃의 사진만 교체한 페이지는 새 디자인으로 세지 않는다.
3. 세로 인물, 가로 풍경, 단체 사진처럼 피사체가 다른 사진으로 교체하여
   얼굴/중요 피사체 잘림을 점검한다. 봉투와 특수 창은 가려지는 영역을 명확히 한다.
4. 문구를 한국어 이름·긴 제목으로 바꾸고, 정사각·가로·세로 앨범에서 가독성을
   확인한다. 현재 조합은 샘플 문구 기준으로 피팅되며 임의의 긴 문구를 입력한 뒤
   전체 조판을 자동 재배치하는 기능은 별도다.
5. 표지는 큰 사진 중심, 내지는 서로 다른 조합으로 구성한다. 의미 없는 영문,
   중복된 감성 단어, 주제와 관계없는 장식을 분량 채우기에 사용하지 않는다.
6. 판매 전 실제 출력물과 폰트의 상업 이용 범위를 검수한다. 이번 화면 검증은
   실물 인쇄 품질 인증이나 경쟁 서비스보다 우수하다는 비교 검증이 아니다.

## 구매 연결 상태

신규 재료는 기존 포인트 상품 관리자에서 각각 식별된다. 문구는
`phrase:collage-atelier-*`, 프레임은 `frame:atelier*`, 조합 장식은
`sticker:atelier*` 키를 사용한다. 즐겨찾기는 기존 공통 저장소를 사용한다.
이번에는 가격·운영 DB·지갑·소유권을 변경하지 않았다. 현재 미설정 재료는
기존 무료 접근 정책을 따른다.

템플릿 구매 시 실제 포함 유료 재료 재사용 권한을 제공하자는 이전 제안은 유지한다.
프레임·종이 사용 목록은 기존 export에서 추출할 수 있다. 문구 조합은 삽입 뒤
일반 레이어가 되므로, 판매용 포함 권한을 자동 지급하기 전 승인 명세에 원본 문구
상품 ID를 명시적으로 연결해야 한다. 글씨 내용을 보고 상품을 역추정하지 않는다.

## 검증 자료

`output/materials/atelier-36/`에 Flutter 네이티브 렌더 이미지와 프레임·문구·종이
모음을 생성한다. 검증 완료 결과는 아래에 기록한다.

- Flutter 회귀 테스트 222개 통과: 3개 앨범 규격, 문구 개별 편집과 저장 왕복,
  세트 실행 취소/다시 실행, 실제 편집 패널의 구매 확인·즐겨찾기,
  새 프레임 12종의 편집기/미리보기 픽셀 일치와 기존 인쇄 테스트 포함.
- 관련 Dart 파일 16개 정적 분석에서 문제 없음. 웹 릴리스 빌드 성공.
- 브라우저 390x844, 844x390, 1440x900에서 필터, 즐겨찾기, 프레임·문구 확대,
  스티커·문구 삽입 확인. 화면 24장과 `browser/report.json` 보관.
  JavaScript 오류, 누락 에셋, 구매·AI 생성 API 요청 없음.
- 가격 활성화, 운영 소유권 지급, 실물 출력물 검수는 수행하지 않았다.
