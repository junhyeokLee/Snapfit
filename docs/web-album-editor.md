# 웹 앨범 편집 조작

웹의 표지와 내지 편집은 같은 문서 좌표와 변형 컨트롤을 사용한다.
모바일 터치 편집과 인쇄 미리보기에는 웹 컨트롤을 적용하지 않는다.

레이어·레이아웃·템플릿·꾸미기·배경은 중앙의 큰 선택 창에서 사용한다.
창 상단의 탭으로 도구를 전환할 수 있으며, 요소 선택이나 적용을 마치면
편집 화면으로 돌아온다. 레이어 순서를 드래그로 바꿀 때는 창을 유지한다.
오른쪽 영역은 선택한 사진·글의 위치·크기·각도와 사진 구도 등 속성 조정에 사용한다.

| 작업 | 웹 조작 |
| --- | --- |
| 선택·이동 | 요소 클릭 후 드래그 |
| 사진·글 크기 | 모서리 핸들을 드래그. 가로·세로 비율을 유지하고 반대쪽 모서리는 고정 |
| 회전 | 선택 테두리 위 회전 핸들을 드래그. Shift를 누르면 15° 간격 |
| 정밀 입력 | 오른쪽 속성에서 X/Y, 가로/세로, 각도 입력. Enter 또는 다른 필드로 이동하면 적용 |
| 입력 취소 | 필드에서 Escape |
| 사진 구도 | 기존 사진 구도 도구로 프레임 안 사진 위치와 확대를 조절 |
| 글 내용 | 글을 더블클릭하거나 기존 글 편집 도구 사용 |
| 화면 배율 | 작업 영역 하단의 확대·축소 또는 Ctrl/⌘+휠 |
| 확대 화면 이동 | Space+드래그 또는 마우스 가운데 버튼으로 드래그 |
| 화면 맞춤 | 작업 영역 하단 화면 맞춤 |
| 실행 취소 | Ctrl/⌘+Z 또는 상단 실행 취소 |

화면 배율 100%는 현재 작업 영역에 페이지를 맞춘 상태다. 화면 배율이나
화면 이동은 저장되는 사진·글의 크기, 사진 구도, PDF 규격을 바꾸지 않는다.

속성의 크기는 회전 전 요소의 표시 크기다. 위치는 기존 문서 모델의 기준
좌표이며, 페이지 너비 500을 기준으로 한 편집 좌표를 쓴다. 인쇄 mm와 다르다.
크기 조절은 기존 문서의 균일 배율(30~300%)을 사용하므로 사진과 글을 왜곡하지 않는다.

드래그 중에는 화면 상태만 갱신하고 조작을 끝낼 때 문서를 한 번 갱신한다.
따라서 한 번의 크기 조절·회전은 한 번의 실행 취소로 복원된다. 좌표 변환은
캔버스의 전역 변환을 역으로 계산해 화면 배율에 관계없이 같은 문서 위치를 가리킨다.

결제·발주 설정은 이 편집 기능과 무관하며 실제 결제 개방을 포함하지 않는다.
