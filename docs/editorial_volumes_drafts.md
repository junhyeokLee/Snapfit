둘 다 세로형 14.5×19.4, 정사각형 20×20, 가로형 19.4×14.5를 지원한다.
규격별로 원형 사진의 실제 크기와 일부 배치를 조정했다.
사진·텍스트·종이·장식은 분리된 편집 레이어다. 완성 페이지를 이미지 한 장으로 굳히지 않는다.
표지를 포함한 사진 자리는 여행 25개, 일상 26개다. 글 전용 내지는 각각 3쪽과 4쪽이다.

## 여행의 결

1. 출발의 문장: 짧은 인사 / 항구 도착 사진
2. 창밖의 시간: 기차 창 / 경로 기록
3. 낯선 골목: 세로 풍경 / 비대칭 사진쌍
4. 바다의 여백: 느린 풍경 / 아치형 물빛
5. 오래 앉은 자리: 카페 사진 / 메뉴처럼 쓴 기억
6. 시장에서 고른 것: 데클 프레임 / 원형 감각 기록
7. 주머니 속 조각: 즉석사진·티켓·테이프 / 감각의 목록
8. 길 위의 색: 사진 팔레트 / 서로 다른 시간의 두 장면
9. 다시 걷고 싶은 길: 큰 해안 사진 / 다시 올 장소
10. 보내지 않은 엽서: 액자형 사진 / 편지
11. 돌아오는 창가: 기차 사진 / 작은 기념품
12. 여행 다음의 날: 귀가 후 장면 / 편집 가능한 마지막 기록

## 작은 날의 기록

1. 오늘의 기분: 원형 사진과 문장 / 책상 정물
2. 아침을 차리는 일: 식탁 / 아침의 순서
3. 책상 위의 취향: 세로 사진 / 물건 두 장
4. 잠깐의 쉼: 아치형 독서 자리 / 조용한 글 페이지
5. 꽃을 사는 산책: 타원형 산책 / 종이 사진과 압화
6. 함께 먹는 오후: 피크닉 / 티켓형 작은 사진
7. 우리의 얼굴: 원본 3:2 단체사진 / 다음 약속
8. 계절의 맛: 과일 정물 / 감각의 기록
9. 다정한 습관: 두 개의 작은 행동 / 캡슐형 산책 사진
10. 한 달의 작은 기록: 두 장의 사진 / 세 문장
11. 좋아하는 것들: 원형·스티커 사진 / 오래 머무는 자리
12. 내일도 이만큼: 다음 아침 / 편집 가능한 마지막 메모

## 미리보기와 원본

- 개발 화면의 ‘시안 선택’에서 기존 웨딩과 두 신규 컬렉션을 선택한다.
- 목차에서 각 스프레드로 이동하고, 전체 펼침 보기·확대·규격 변경을 사용할 수 있다.
- 여행지 또는 계절, 기록 기간, 기록한 사람, 마지막 기록을 수정할 수 있다.
- 문구는 세 규격 모두의 실제 텍스트 높이로 검사한다. 초과 시 적용을 막고 안내한다.
- 이 개발 화면의 수정은 현재 화면의 메모리 상태이며 저장·결제·AI 요청은 실행하지 않는다.
- 샘플 사진을 숨겨 빈 슬롯도 확인할 수 있다. 앨범 준비 경로에서는 사진만 비우고 프레임과 배치는 유지한다.
- 새 샘플 사진 4장은 내장 이미지 생성 도구로 제작한 가상의 장면이다.
  원본·프롬프트는 `assets/templates/original_editorial/editorial_volumes_provenance.json`에 기록했다.
- 기존 샘플 사진은 소재로 재사용하지만, 기존 완성 템플릿의 좌표나 페이지 JSON을 복제하지 않았다.

## 추가 완성 조건

- 샘플은 크롭과 조판을 보여 주기 위해 여러 페이지에 재사용된다. 실제로 사진 6~7장만 넣는 완성 상품이라는 뜻이 아니다.
- 실제 사용자의 방향·밝기·얼굴 위치가 다른 사진으로 교체하는 사용성 검수
- 적은 사진/많은 사진 구성 선택안, 추가 표지 선택안
- 물리 인쇄 규격에 맞춘 도련·제본·유효 해상도, 교정쇄 확인
- 폰트·사진·장식의 배포 범위 검수. 현재 두 무료 컬렉션에 결제는 붙이지 않는다.

자동 테스트 통과는 심미성 평가나 인쇄·판매 승인과 같지 않다.
