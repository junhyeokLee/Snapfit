# 빛으로 엮은 우리: 무료 기본 컬렉션

2026-09-07. 사용자의 결정으로 최신 디자인을 무료 기본 컬렉션으로 채택했다.
앱 앨범 생성 목록에 무료 번들(-9301)로 연결했다. 실시간 AI 생성 결과나 유료 상품이 아니다.
인쇄 및 권리 검수까지 완료한 판매 상품이라는 뜻은 아니다. [현재 기준](free_template_baseline.md).

## 이번 범위

- 표지 1개 + 내지 24쪽, 총 12스프레드. 원본 문서 버전 2.
- 승인된 표지와 대표 8쪽의 조판을 유지하고 새 16쪽을 사이에 연결했다.
  첫 4쪽은 그대로, 기존 보관함 양면은 9–10쪽, 마무리 양면은 23–24쪽에 있다.
- 세로형 14.5 × 19.4, 정사각형 20 × 20, 가로형 19.4 × 14.5 규격 비율.
- 가로형 표지는 사진과 글을 좌우로 다시 조판했다. 장면 기록과 소품 목록도
  규격에 맞게 위치, 사진 높이, 글 상자의 폭을 개별 조정했다.
- 제목과 본문은 편집 가능한 텍스트, 사진은 교체 가능한 이미지 레이어다.
- 원본은 `lib/core/templates/authored_lightbound.dart`에 있다.
  기존 `_Sheet` 그리기 도구와 소재만 공유하며 기존 완성 문서를 복제하지 않는다.
- 기존 웨딩 샘플 6장에 서약·가족·가까운 인물·케이크 4장을 새로 생성해 추가했다.
  일상 장면에는 기존 책·책상·과일 샘플 3장을 사용한다. 일부 샘플은 반복되며,
  실제 사진 24장을 AI가 자동으로 구성한 결과라는 뜻이 아니다.
- 새 사진은 built-in `image_gen`으로 생성한 가상 인물·장면이다.
  [원본 경로와 전체 생성 프롬프트](../assets/templates/original_editorial/lightbound_provenance.json)를
  별도로 기록했다. 원본 PNG를 수정 없이 프로젝트에 복사했다.

## 한 권의 흐름

| 구성 | 의도 |
| --- | --- |
| 표지 | 선명한 인물 사진과 한글 제목. 읽기 어려운 사진 위 글자 겹침 제외 |
| 01–02 서로에게 닿은 날 | 여백이 있는 인사말과 큰 인물 사진의 대비 |
| 03–04 시간의 결 | 준비·기다림·자리·여운을 다른 크기의 사진으로 연결 |
| 05–06 작은 약속 | 서약 장면과 문장, 원형 반지 프레임 |
| 07–08 둘의 초상 | 아치형 가까운 인물 사진과 높이가 다른 두 사진 |
| 09–10 작은 보관함 | 찢어진 종이 프레임과 작은 압화, 반지·베일의 기록 |
| 11–12 함께한 얼굴들 | 원본 3:2 비율의 단체 사진과 감사의 문장 |
| 13–14 축하의 자리 | 테이블과 케이크의 큰 사진으로 축하 장면 연결 |
| 15–16 저녁의 온도 | 짙은 녹색 바탕의 인물 페이지와 여백 있는 기록 |
| 17–18 기억의 기록 | 편집한 이름·기념일을 반영하는 기록과 세 문장 |
| 19–20 우리의 평범한 날 | 책상·책·과일의 일상 장면으로 이야기를 확장 |
| 21–22 오래 지킬 마음 | 타원형 인물 사진과 함께 지킬 세 가지 약속 |
| 23–24 다음의 우리 | 함께 앉은 사진과 독립적인 편지 페이지로 마무리 |

Eulyoo 한글 명조를 주요 문장과 편지에, NotoSans를 날짜·캡션·쪽수에 사용한다.
장식 수를 늘리는 대신 사진 크기, 여백, 문장의 밀도가 바뀌는 흐름에 집중한다.
양면을 하나의 큰 사진으로 가로지르게 하지 않아 주요 인물이 제본 중앙에 걸리지 않는다.

## 미리보기

기존 개발 서버의 `/?collection=lightbound`에서 연다.
미리보기 첫 화면에서 바로 열리며, 상단 선택 메뉴의 `빛으로 엮은 우리`로도 진입한다.

- 한 장 보기, 가로 화면의 양면 보기, 전체 펼침 보기, 페이지 확대.
- 목차 메뉴에서 표지 또는 12개 장면에 바로 이동. 페이지 수는 표지와 내지를 따로 표시한다.
- 이름·기념일·편지 편집 및 취소. 세 규격 모두에 들어가는 문구만 적용한다.
- 샘플 사진 숨기기와 복원. 사진을 빼고 구성 자체를 살펴볼 수 있다.
- 문구는 현재 미리보기 세션에만 반영된다. 저장·결제·AI API 호출은 하지 않는다.

## 검수와 한계

- `test/design/lightbound_wedding_test.dart`: 표지 포함 25쪽의 레이어 경계,
  텍스트끼리 및 텍스트·사진의 겹침, 긴 한글 이름과 편지의 높이,
  사진 교체 후 비율·프레임 보존, 저장 직렬화, 편집 적용/취소를 검수한다.
- 가족 사진의 슬롯 비율은 세 규격 모두 원본과 같은 3:2로 검증한다.
  모든 사용자 단체 사진의 구도까지 자동으로 보장하는 것은 아니다.
- 기존 무료 레이아웃과의 기하 구성이 동일하지 않은지 확인한다.
  자동 검사가 독창성이나 심미성을 보증하는 것은 아니다.
- `tool/template_studio/verify_lightbound.cjs`: 실제 Flutter Web에서 3규격 × 3화면의
  전체 페이지 이동, 좌우 정렬, 사진 픽셀, 펼침 보기, 확대, 문구 폼을 확인한다.
- 출력 이미지: `output/template-preview/lightbound/`. 폰트가 로딩된 실제 앱 렌더러로 만든다.
  규격별 `all-spreads.png`는 12스프레드를 모은 검수용 이미지다.
- 미리보기 이미지 디코딩은 페이지의 긴 변과 화면 배율을 반영해 세로 크롭이
  작은 디코딩 이미지를 다시 확대하지 않도록 보강했다. 일반 보기 2배, 확대 보기 4배이며
  문서 미리보기에서는 디코딩 폭을 최대 2048픽셀로 제한한다. 원본 해상도를 생성하는 기능은 아니다.
- 사진 좌우 여백은 페이지 폭의 최소 6%다. 쪽수와 이름은 별도 바깥 여백을 쓴다.
  이 수치는 인쇄소의 도련·제본 규격을 확정한 인쇄 합격 기준이 아니다.
- 긴 문구를 맞추려고 본문을 무조건 축소하지 않는다. 입력 상한 이내라도 줄바꿈이
  과도해 실제 높이를 넘으면 적용을 막고 안내한다.

## 남은 상품화 작업

1. 전체 24쪽 리뷰와 추가 표지 선택안 제작. 분량 완성은 출시 승인과 다르다.
2. 실제 사진 세트로 교체해 다양한 얼굴 위치·사진 방향·저조도 크롭 검수.
3. 판매용 사진·폰트·장식의 이용 범위 확인과 세 규격 교정쇄 검수.
4. 실제 편집기 저장·복원, 유료 권한·결제 동선 검증 후 별도 신규 상품 등록.

현재 무료 컬렉션 3종과 기존 사용자 앨범은 변경하지 않는다.
`publicationStatus: draft`, `catalogPublishable: false`, `aiGenerated: false`를 명시하며,
출시 검수와 운영 등록을 하지 않은 상태에서 유료 카탈로그에 넣지 않는다.
