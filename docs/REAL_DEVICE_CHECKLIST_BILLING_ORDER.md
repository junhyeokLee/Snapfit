# Real Device Checklist (Point Billing + Order History)

테스트 대상은 SnapFit 프로젝트 `rrbhxdtriummqpztpjrk` 및 그 프로젝트에 연결된 앱입니다. 먼저 [운영 키 안내](ORDER_PAYMENT_KEYS.md), [배포 절차](POINT_PAYMENTS_AND_PUSH_RELEASE.md)를 확인합니다. 포인트 구매는 스토어 sandbox/라이선스 테스트 계정으로 출시 전에 검증합니다. 외부 실물 주문 결제는 퇴역했으며 대체 checkout은 없습니다. 기존 주문 조회·배송 알림은 회귀 검증합니다. Android 콘솔 준비는 [별도 점검표](ANDROID_POINT_PURCHASE_CHECKLIST.md)를 확인합니다.

## 1) 포인트 충전 성공

1. 앱 실행 → 마이페이지 → `포인트 충전` 진입.
2. 상품명·금액·통화가 기기의 실제 스토어 상품 조회 결과와 일치하는지 확인.
3. 포인트 상품을 선택하면 Google Play 또는 App Store의 기본 결제창이 열리는지 확인.
4. 성공 후 서버 `iap-verify` 검증이 끝나면 잔액과 포인트 내역이 정확히 한 번 증가하는지 확인.
5. 앱을 다시 실행하고 다른 기기로 같은 앱 계정에 로그인해 같은 잔액이 표시되는지 확인.
6. 같은 상품을 다시 구매할 수 있는지 확인. 앞선 거래의 재전달은 중복 지급하지 않아야 함.
7. 포인트 충전이 저장 용량 플랜이나 다른 멤버십 권한을 바꾸지 않는지 확인.

## 2) 포인트 결제 실패·취소·승인 대기

1. 결제창 진입 후 취소 또는 sandbox 실패 흐름 진행.
2. 취소/실패 안내가 표시되고 잔액은 바뀌지 않는지 확인.
3. 결제 버튼이 다시 활성화되고 재시도가 가능한지 확인.
4. 승인 대기 거래에는 포인트가 지급되지 않으며, 스토어 승인 완료 후 검증 및 지급되는지 확인.

## 3) 미완료 구매 복구와 계정 보호

1. 결제 승인 직후 네트워크를 끊거나 앱을 종료하여 서버 확인이 지연되는 상황을 만든다.
2. 같은 계정으로 앱 재실행·복귀 또는 `구매 복원` 실행 후 미완료 거래가 검증되는지 확인.
3. 포인트 지급은 한 번만 수행되고, 서버 검증 전 스토어 거래를 완료/소비하지 않는지 확인.
4. 확인 중 화면을 떠나도 앱 전역 구매 처리가 유지되는지 확인.
5. 미완료 구매가 있는 상태에서 다른 앱 계정으로 전환하면 그 계정에 포인트가 지급되지 않는지 확인. 원래 구매 계정으로 돌아오면 정상 복구되어야 함.
6. 과거에 판매한 포인트 상품의 미완료 거래도 원래 구매 계정으로 복구되는지 확인.
7. sandbox에서 검증된 환불/취소를 환불 대사가 반영하며, 재실행해도 회수는 한 번만 수행되는지 확인. 이미 사용한 포인트의 회수분이 사라지지 않아야 함.

## 4) 외부 결제 퇴역 확인

1. 앨범 제작과 주문 화면에 외부 결제 시작·재시도·결제 확인 버튼이 노출되지 않는지 확인.
2. 과거 결제 복귀 링크를 열어도 외부 결제 확인·주문 결제 완료·제작 시작이 발생하지 않는지 확인.
3. 구버전 앱의 checkout/확인 요청이 퇴역 응답을 받고 주문 상태를 바꾸지 않는지 확인.
4. 기존 주문과 배송 기록은 조회할 수 있으며, 퇴역 조치로 삭제되거나 과거 상태가 바뀌지 않는지 확인.

## 5) 주문 상세 UX

1. 주문 카드 탭 → 상세 바텀시트 노출.
2. 주문번호 복사 / 송장 복사 버튼 동작 확인.
3. 송장번호가 있으면 `배송 조회` 버튼으로 외부 조회 페이지 열림 확인.
4. 상세에서 주소/수령인/타임라인(결제완료, 인쇄접수, 배송시작, 배송완료) 노출 확인.
5. 이미 배송완료된 주문에 과거 결제 복귀 링크를 열어도 상태가 제작중으로 되돌아가지 않는지 확인.

## 6) 알림/상태 동기화

1. 주문 상태 변경 후 주문 내역 새로고침 없이도 앱 복귀 시 반영되는지 확인.
2. 마이페이지 주문현황 숫자가 서버 주문상태와 일치하는지 확인.
3. 다른 계정으로 같은 기기에 로그인했을 때 이전 사용자의 주문 알림이 표시되지 않는지 확인.
4. 주문 알림을 눌렀을 때 본인의 해당 주문 상세가 열리는지 확인.
5. 푸시 권한 또는 주문 알림 설정을 끄면 기기 발송이 중단되고, 인앱 알림함의 본인 기록은 정상 조회되는지 확인.

## 7) 회귀 체크

1. 앨범 편집/저장/삭제 동작 영향 없는지.
2. 스토어/템플릿 상세/사용하기 동작 영향 없는지.
3. 로그인/로그아웃 후 프로필 이미지 유지되는지.
4. AI 템플릿 제작에서 포인트 부족·정상 차감·다시 충전 흐름이 정상 동작하는지.
