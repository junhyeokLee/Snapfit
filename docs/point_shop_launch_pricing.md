# SnapFit 출시 가격 기준

2026-09-09 사용자가 가격 책정을 위임했다. 이 문서와
`point_shop_launch_pricing.dart`를 앞으로의 재료·템플릿 제작 기준으로 사용한다.
과거의 '가격 미확정' 제안은 아래 출시 책정가로 대체한다.
**2026-09-10 사용자의 전체 반영 요청에 따라 연결 운영 DB에 가격을 적용했다.**
책정 완료와 실제 판매 활성화는 별개다. 유료 템플릿 14종은 가격을 저장했지만
원본 제공·포함 재료 이용권 지급 검증 전까지 판매 비활성을 유지한다.

## 가격표

| 상품 | 출시 책정가 | 판단 기준 |
| --- | ---: | --- |
| 기존 무료 템플릿 37종 | 무료 | 승인된 무료 기준 유지, 세 규격 포함 |
| 기본 기록지·모눈지·라벨·홀더 | 무료 | 사용자의 기본 꾸미기 작업에 필요한 재료 |
| 컨셉형 종이·세부 장식 | 100P | 접지, 인쇄, 기록 구조가 있는 보조 재료 |
| 실사 질감 오브젝트 | 200~300P | 실루엣과 질감의 디테일, 재사용 범위 |
| 사진 교체 가능한 프레임 | 200~400P | 사진 창 구조, 겹침, 제본·장식의 복잡도 |
| 편집 가능한 문구 조합 | 300~400P | 독립 조판, 제목·날짜·장식의 편집 가능성 |
| 첫 유료 템플릿 7종 | 각각 2,500P | 기본판·확장판·세 규격을 묶은 컬렉션 이용권 |
| 신규 컨셉 템플릿 7종 | 각각 1,800P | 내지 24쪽과 표지·세 규격, 확장판 미포함 |

최근 재료 83종은 무료 12종, 유료 책정 71종이다. 실크 매듭(300P), 바다 유리(200P),
코발트 연필(200P)에 이어 코튼 보닛(300P), 체크 천(200P), 집 열쇠(300P),
직조 공(300P)을 추가했다. 반복 장식 개선으로 새 소품 8종(200~300P)과
기록지 4종(각 100P)을 더했다. 상세 목록은 `life_material_variety.md`에 있다.
컨셉 확장 템플릿 7종의 가격은 1,800P로 확정했다. 전체 앱의 무료 재료를
12종으로 줄인다는 뜻이 아니다. 명시된 134개 상품만 적용하고 과거 재료와
목록 밖 운영 상품은 변경하지 않는다. 기존 무료 컬렉션은 0P로 통일했다.
개별 134개 상품의 이유와 가격은 `output/pricing/launch-2026-09-09/PRICES.md`,
구조화된 자료는 같은 폴더 `prices.json`에 있다.
현재 가격표 리비전은 `2026-09-10-catalog-5`이다. 기존 내보내기 경로는 유지한다.

쪽수·장식 수를 가격에 기계적으로 곱하지 않는다. 24쪽만 있는 컬렉션도
편집 구성이 좋으면 가치가 있으며, 반복된 36쪽에 자동으로 높은 가격을 주지 않는다.
첫 7종은 복잡한 요금 구분 없이 동일 가격으로 시작한다. 향후 3,900P 이상 상품은
독립 제작 재료, 지면별 조판, 실물 출력 검수가 현재 컬렉션과 명백히 달라질 때
새로 검토한다. 아직 그런 가격의 상품을 등록한 것은 아니다.

## 실제 포인트 단가

연결 프로젝트 `rrbhxdtriummqpztpjrk`의 `point_products`를 2026-09-09 읽기 검증했다.

| 충전 팩 | 서버 설정 금액 | 2,500P 비례 환산 |
| --- | ---: | ---: |
| 2,500P | 2,200원 | 2,200원 |
| 8,000P | 5,900원 | 약 1,844원 |
| 18,000P | 11,900원 | 약 1,653원 |

1P를 1원으로 표시하지 않는다. 비례 환산은 그 금액만 결제할 수 있다는 뜻이
아니며, 실제 앱마켓 결제는 스토어에서 조회한 지역별 금액이 우선한다.
위 금액은 원가나 순이익이 아니다. 앱마켓 수수료, 세금, 환불, 운영비,
실제 팩 구매 비율을 검증하기 전 수익성이 확정되었다고 표현하지 않는다.

[미리캔버스 공식 요금제](https://www.miricanvas.com/ko/pricing)는 템플릿과 기능을
함께 제공하는 구독 상품이다. SnapFit의 단일 컬렉션 재사용 이용권과 동일 상품처럼
가격 비교하지 않는다. 이번 가격은 합리적인 출시 가설이지 시장 검증된 최적가가 아니다.
다음 검토는 상세 조회→구매 전환, 실제 적용 완료, 반복 사용, 환불·문의, 결제 팩 비율로 한다.
거래가 소수일 때 가격을 자주 바꾸지 않으며, 비교 실험은 가격 변경 전에 기준을 정한다.

## 앞으로의 제작 절차

1. 컨셉에 필요한 프레임·타이포·장식을 먼저 적는다. 맞는 재료가 없으면 새로 만들고,
   기존 재료의 색만 바꾼 것을 별도 유료 상품으로 세지 않는다.
2. 실제 편집기 삽입·크롭·텍스트 수정·저장 복원·인쇄 렌더로 확인한다.
   24~36쪽 앨범에서 전면 사진, 기록 지면, 강조 펼침면의 리듬도 검수한다.
3. 기본 재료로 충분하면 무료. 유료 후보는 개별 가격과 이유를 명시한다.
   가격표에 없는 새 ID는 '미검토'이며 접두사로 자동 과금하지 않는다.
4. 테마 팩은 실제 포함 목록·기보유 할인 규칙을 만든 뒤 가격을 정한다.
   아직 없는 팩에 임의 정가나 할인율을 붙이지 않는다.
5. 원본 생성 기록, 사진·폰트의 배포 권리, 실제 출력 품질을 확인한 뒤 판매한다.

## 템플릿과 포함 재료

권장 정책은 유지한다: 템플릿 구매 시 실제 포함된 유료 재료도 같은 계정의
다른 앨범에 재사용할 수 있도록 제공한다. 해당 컨셉 팩 전체를 지급하지 않는다.
구매한 템플릿 편집 중 포함 재료를 다시 결제하게 하지 않는다.

이용권 지급은 아직 구현 완료가 아니다. 출시 전 서버가 신뢰하는 버전별 포함 명세,
원자적 포인트 차감·권한 지급, 재시도 중복 차감 방지, 환불 시 지급 출처,
계정 변경과 구매 복원을 검증해야 한다. 문구는 글씨 내용으로 상품 ID를 역추정하지 않는다.
기존 무료 이용자가 저장한 앨범의 편집·출력 권한도 보존해야 한다.

## 구현 범위와 검증

- 관리자 목록에 출시 책정가를 현재 운영 가격과 분리해서 표시한다.
- '책정가 입력'은 입력값만 채운다. 별도 저장 전 서버 요청은 없으며 현재 값도
  화면을 열었다는 이유로 덮어쓰지 않는다. 0P도 명시적으로 입력한다.
- 14개 유료 템플릿은 출시 대기이며 관리자 판매 활성화 제한을 유지한다.
- 가격표 export 자체는 서버에 쓰지 않는다. 별도의 `export_price_application.dart`는
  명시된 134개 키만 대상으로 트랜잭션 SQL과 재조회 검증 SQL을 만든다.
- 적용 전 상품 8행을 백업했다. `template:lightbound`의 이전 700P 설정도
  이번에 승인된 무료 37종 기준에 맞춰 0P로 수정했다.
- 연결 프로젝트 `rrbhxdtriummqpztpjrk`에 명시적으로 SQL을 실행한 뒤 134행의
  키·가격·활성 상태와 `get_point_shop_access` 응답을 모두 재조회 검증했다.
  무료 49종(템플릿 37+재료 12), 판매 중 유료 재료 71종, 판매 대기 템플릿 14종이다.
- 적용 전 자료, SQL, 재조회 결과는 `output/pricing/catalog-2026-09-10/`에 있다.
- 실제 앱마켓 결제, 고객 청구, 포함 재료 권한 지급은 실행하지 않았다.

초기 검증: 가격표 71개 키·무료 12종·기존 가격 분리, export,
관리자 가로/세로 입력, 취소·저장, 계정 변경·중복 요청·구매 확인 회귀 테스트
32개 통과. 관련 Dart 파일 8개 정적 분석에서 문제 없음.
관리자 변경은 위젯 테스트로 검증했으며 새 앱 배포나 실결제는 수행하지 않았다.
