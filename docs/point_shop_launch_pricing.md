# SnapFit 템플릿·소재 가격과 판매 등록 기준

## 현재 정책 — 2026-10-25

사용자는 제작 완료한 템플릿과 소재를 무료·유료로 구분하고 가격을 책정하여,
실제 스토어에 등록·활성화하는 작업까지 위임했다. 새 완성 상품을
`판매 준비 중`으로 남기지 않는다. 이전 문서의 유료 템플릿 판매 보류 지침은
이 정책으로 대체한다. 출시가 끝나지 않은 초안은 완성 상품으로 보고하지 않는다.

## 가격 기준

| 상품 | 책정가 | 기준 |
| --- | ---: | --- |
| 무료 템플릿·기본 소재 | 0P | 기존 무료 구분 보존, 무료 동아리 템플릿의 소재 포함 |
| 스토리·컨셉 템플릿 | 1,800P | 표지·내지 24쪽·세 규격의 편집 구성 |
| 프리미엄 확장 컬렉션 | 2,500P | 기본판·확장판과 세 규격 |
| 아틀리에·스튜디오 에디션 | 2,800P | 독립 표지·내지 32쪽과 세 규격 |
| 컨셉 종이·기록지 | 100P | 사진과 함께 인쇄하는 접지·기록 구조 |
| 독립 장식·오브젝트 | 200~300P | 주제에 맞는 실루엣·재질·편집 품질 |
| 사진 교체용 프레임 | 200~400P | 사진 창·절개·겹침·제본 구조 |
| 편집 가능한 제목·문구 조합 | 300~400P | 제목·날짜·장식을 개별 편집 |

현재 스토리 에디션의 전용 소재는 종이 100P, 장식 200P, 제목 조합 300P이며
무료 에디션의 전용 소재는 각각 0P다. 쪽수나 장식 수에 비례해 가격을 높이지
않으며, 새 상품은 구성·독창성·사진과 실물 출력의 조화를 보고 이유를 기록한다.
다른 템플릿에서 쓴 사진이나 기존 소재의 단순 색상 변경을 새 유료 상품의
품질 근거로 삼지 않는다.

## 제작부터 판매 완료까지

1. 표지·내지·전용 소재를 완성하고 세 규격, 사진 교체, 문구 편집, 저장 복원과
   미리보기를 검수한다. 배포 가능한 사진·폰트의 출처도 기록한다.
2. 앱의 공개 카탈로그·미리보기·상세 문서에 포함하고 상품 키를 고정한다.
   `point_shop_launch_pricing.dart`에 무료 0P 또는 유료 가격과 이유를 명시한다.
3. 완성한 유료 상품의 개별 키를 `point_shop_catalog_release.dart`에 반영한다.
   `validatePointShopCatalogRelease`로 공개 템플릿·스토리 전용 소재의 누락,
   비활성 상태, 가격 미설정, 무료/유료 충돌, 중복 키와 상품 식별자 오류를 검사한다.
   이 검사는 출시 자료 내보내기 전에 실행되며 앱의 진입·스크롤에는 추가되지 않는다.
4. 기존 운영 가격과 상태를 조회한 뒤 새 상품의 가격을 등록하고 판매 활성화한다.
   활성화 전용 SQL은 기존 유료 가격을 보존하고 무료/유료 충돌 시 중단한다.
   기존 지갑·보유권·저장 앨범은 변경하지 않는다.
5. 운영 DB 재조회, 익명 조회와 `get_point_shop_access`, 앱 목록·검색·무료/유료
   구분·미리보기 노출을 확인하고 검증 기록을 남긴다. 별도 판매 요청을 기다리지 않는다.

가격표와 SQL 파일을 만드는 것만으로 운영 서버가 바뀌지는 않는다.
`export_price_application.dart`의 `prepared-not-executed`와 `remoteVerified: false`는
내보낸 파일의 상태다. 실제 등록 완료는 서버 실행 후 별도로 검증한다.
운영 연결이 없으면 그 사실과 남은 작업을 알리고 등록 완료로 표현하지 않는다.

## 가격과 권한의 기준

앱에 포함된 가격표는 제작·관리용이다. 실제 구매 가격, 활성 상태와 이용권은
서버의 구매 조회·처리 응답을 따른다. 고객의 앱 실행이나 스토어 진입을 계기로
가격을 자동 등록하거나, 미등록 유료 상품을 무료로 표시하지 않는다.
운영 중인 가격을 새 상품 등록 때문에 일괄 덮어쓰지 않는다.

템플릿 구매 시 포함 소재를 다른 앨범에서도 재사용할 수 있게 자동 지급하는
정책은 별도 서버 구현·검증이 필요한 사항이다. 이번 가격 등록이 포함 소재
이용권 지급까지 구현했다는 뜻은 아니다. 실결제·포인트 차감도 검증 목적으로
실행하지 않는다.

과거 2026-09-10의 134개 상품 등록 자료는 `output/pricing/catalog-2026-09-10/`에
보존한다. 그때의 상품 수·판매 보류 상태와 충전 팩 설정은 현재 판매 정책이나
최신 결제 금액의 근거로 사용하지 않는다.
