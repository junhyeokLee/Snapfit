## 이전 시안의 처리

- 꽃처럼 피어난 날(-9201), 낯선 곳의 조각들(-9202), 좋아하는 순간들(-9203)을 신규 선택 목록에서 제거한다.
- 초기 섬/제주/휴식 시안과 AI 테스트 문서도 일반 미리보기의 선택 목록에서 제거한다.
- 구 ID 또는 구 원본 ID가 포함된 캐시 문서가 다시 합쳐져도 선택 목록에 나타나지 않게 한다.
- 서버 상품, 구 생성 JSON, 캐시의 제목이나 ID와 무관하게 활성 레지스트리 37종 외에는 공개하지 않는다.
- 스토어·홈 추천·검색·생성·편집기 목록은 같은 활성 컬렉션을 사용한다.
- 구 스토어의 서버 병합·하드코딩·생성 JSON 폴백 경로를 공개 카탈로그에서 제거한다.
- `retiredAuthoredCollections`는 저장 문서·프레임 회귀 검수용 아카이브다. 활성 카탈로그가 아니다.
- 사진과 소재 중 최신 템플릿 및 사용자 앨범이 사용하는 파일은 삭제하지 않는다.
- 이미 저장된 사용자 앨범의 페이지·문구·사진은 변경하거나 삭제하지 않는다.
- 서버 레코드와 원본 파일의 물리 삭제는 하지 않는다. 업데이트된 앱의 공개 목록에서 제거한다.
- 무료 컬렉션의 좋아요는 기기에서 계정별로 저장한다. 서버 동기화 기능은 아니다.

## 유료 가치의 기준

심플한 디자인도 유료 가치가 있을 수 있다. 그러나 기존 3종에 더해 바람을 수집한 여행도
사용자 판단으로 무료 기본 수준이다. 정돈된 레이아웃, 전용 일러스트, 표지 3안과
32쪽 구성까지 갖추어도 유료로 선택할 강한 이유를 증명한 것은 아니다.
‘프레임이 더 많음’, ‘색상 변경’, ‘페이지 수 늘림’을 유료 차별점으로 삼지 않는다.

| 무료에서 기본 제공 | 유료에서 추가로 증명해야 할 가치 |
| --- | --- |
| 읽기 좋은 한글 조판과 여백 | 컬렉션 전용 제목 구성, 장면에 맞는 원문, 사진과 문장이 함께 만드는 독립 구성 |
| 편집 가능한 사진·문구·프레임 | 해당 컬렉션만을 위해 제작한 사진 프레임·종이·일러스트 소재군 |
| 완결된 24/32쪽, 표지 선택안과 세 규격 | 사진 수·문장 길이가 달라도 유지되는 서사와 타이포그래피 |
| 사진 교체와 기본 레이아웃 유지 | 다양한 실제 사진을 넣어도 무너지지 않는 크롭·조판 검수 |
| 기본 앨범 편집 흐름 | 실물 제본·색감·해상도까지 확인한 인쇄 결과와 사용 편의 |

새 유료 컬렉션은 현재 무료 컬렉션의 색상이나 장식만 바꿔 만들지 않는다.
대표 스프레드만 보아도 ‘이 디자인으로 내 이야기를 남기고 싶다’는 구체적인 이유가
있어야 하며, 전체 책과 실제 사진 교체 결과로 그 이유를 뒷받침해야 한다.
장식을 과밀하게 넣는 것을 고급 디자인의 대체물로 사용하지 않는다.

## 다음 유료 기획의 출발점

다음은 미제작 후보이며 판매 상품이 아니다.

- 여행 기록물 컬렉션: 여행자 자신의 장소·날짜를 반영하는 티켓, 지도형 기록,
  접지·엽서 구성을 전용 소재와 일관된 편집 체계로 설계한다.
- 성장 기록 컬렉션: 월령·첫 경험·편지 등 실제 기록 목적에 맞는 독자적인
  그림과 사진 구성을 만든다. 범용 아이콘을 늘어놓는 방식은 제외한다.
- 기념 아트북 컬렉션: 특정 사진과 이야기의 호흡을 살리는 조판, 종이 선택과
  실제 인쇄 결과를 함께 검수한다.

대표 2~3스프레드 승인 → 전용 소재 제작 → 전체 책 구성 → 실제 사진 교체 검수
→ 인쇄·권리 확인 → 상품 조건 확정의 순서로 진행한다. 현재 유료 출시는 하지 않는다.
