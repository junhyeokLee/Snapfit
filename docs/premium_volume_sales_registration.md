# 유료 템플릿 판매 등록

최신 가격 적용일: 2026-09-10. 디자인 승인과 판매 개시는 별개로 관리한다.

첫 7종 2,500P와 신규 컨셉 7종 1,800P를 운영 DB에 저장하고 재조회 검증했다.
14종 모두 `is_active=false`로 유지한다. 아래 원본 내보내기 내역은
2026-09-09 첫 7종의 등록 패키지이며, 신규 컨셉 7종의 고객용 전달까지
완성되었다는 뜻이 아니다. 상세 적용 결과는
[9월 10일 카탈로그 반영](catalog_release_2026-09-10.md)을 따른다.

## 추천 판매가

첫 7종의 **컬렉션별 출시 책정가를 2,500P**로 정했다. 2026-09-09 사용자가
가격 책정을 위임했으며, [출시 가격 기준](point_shop_launch_pricing.md)을 따른다.
실제 `point_price`는 2,500으로 저장했고 `is_active`는 `false`로 유지한다.
2,500P는 초기 구매 부담을 낮추려는 출시 가설이며 시장 검증된 적정가가 아니다.
할인 전 가격이나 할인율은 근거 없이 표시하지 않는다.

| --- | --- | --- | --- | --- |
| 약속을 묶은 책 | 웨딩 | 24쪽 | 32쪽 | 2,500P |
| 둘만의 여행 | 여행 | 24쪽 | 36쪽 | 2,500P |

| 산책하고 낮잠 | 반려동물 | 24쪽 | 없음 | 2,500P |

쪽수는 표지를 제외한다. 제안하는 구매 범위는 같은 계정에서 해당 컬렉션의
기본판·확장판·세로·정사각·가로 규격을 모두 사용하는 것이다. 권한 키는
`template:<collection-id>` 하나로 통일한다. 규격이나 쪽수별 중복 결제를
요구하지 않는 구성이며, 아직 고객용 선택·전달 화면에 연결된 기능은 아니다.
실물 앨범 제작비·배송비는 포함하지 않는다.

## 가격 근거

2026-09-09 연결된 Supabase 프로젝트의 `point_products` 읽기 결과:

| 포인트 | 서버 설정 금액 | 2,500P의 비례 환산 금액 |
| --- | --- | --- |
| 2,500P | 2,200원 | 2,200원 |
| 8,000P | 5,900원 | 약 1,844원 |
| 18,000P | 11,900원 | 약 1,653원 |

뒤 두 값은 묶음 포인트의 비례 계산이지 그 금액만 결제할 수 있다는 뜻이 아니다.
1P는 1원 고정이 아니다. 실제 앱마켓 결제 금액은 스토어에서 받은 가격이
우선하며, 위 금액은 실결제 화면에서 확인한 가격이 아니다.

[미리캔버스 요금제](https://www.miricanvas.com/ko/pricing)는 여러 템플릿과
기능을 제공하는 구독 상품이다. 단일 앨범 템플릿 영구 이용권과 직접 동일한
가격 기준으로 비교하지 않는다. 출시 후 상품별 상세 조회→구매 전환,
실제 템플릿 적용 완료, 환불·문의, 반복 사용을 확인한 뒤 다음 신상품 가격을
조정한다. 아직 이 지표를 수집·검증했다는 의미는 아니다.

## 구현된 등록 범위

- `pendingPremiumVolumeProducts`: 7종의 고유 상품 키, 한글 이름, 미적용 운영 가격.
- 관리자 목록에 출시 대기 상태와 내지 쪽수·규격 표시. 가격 초안 저장 가능.
- 출시 대기 상품은 관리자 앱의 판매 활성화가 비활성화된다. 서버 접근은
  기존 RLS와 구매 RPC를 유지한다. UI 잠금은 서버 보안 정책의 대체가 아니다.
- `export_premium_registration.dart`: 36개 원본 문서와 직접 참조하는 로컬
  이미지·폰트 목록, 제안 가격, 출시 점검 상태, 등록 SQL을 생성한다.
- SQL은 7종만 `null/false`로 INSERT하며 충돌 시 기존 행을 덮어쓰지 않는다.
  고객 잔액·구매 권한·기존 상품 가격은 변경하지 않는다.
- 고객용 스토어·생성·편집 메뉴의 기존 37종 허용 목록은 그대로다.

```sh
/Users/devsheep/flutter/bin/flutter test --no-pub \
  --dart-define=EXPORT_REGISTRATION=true \
  test/unit/premium_volume_registration_test.dart
```

생성 위치: `output/premium-registration/2026-09-09/`.
`manifest.json`은 로컬 생성 명세이지 서버 등록 성공 증명은 아니다.
대상 프로젝트를 확인한 뒤 `register-drafts.sql`만 실행하며, 기존 운영
템플릿 일괄 게시 스크립트를 실행하지 않는다.

## 판매 개시 전 남은 작업

1. 출시 책정가 2,500P는 결정됨. 포함 재료의 정확한 이용권 명세와 지급 구현 확인.
2. 고객 스토어의 7종 노출, 상세의 기본·확장판 선택, 생성·편집의 동일 상품
   권한 확인과 전체 원본 전달 연결. 설정 누락을 무료로 간주하는 기존
   fallback이 이 유료 상품을 무상 제공하지 않도록 별도 확인.
3. 실제 기기의 구매→적용→재진입, 계정 변경, 오프라인, 중복 결제 차단 검증.
4. 포인트 충전 실결제 확인. `PAYMENT_PUSH_DEPLOYMENT_STATUS.md`의
   2026-09-08 기록상 Android/iOS 설정 미완료. 이번 작업에서 실제 앱마켓
   구매를 실행하거나 최신 readiness를 인증 사용자로 재검증하지 않았다.
5. 참조하는 폰트·이미지·장식의 템플릿 배포 범위와 필요한 고지 확인.
   생성 이미지 provenance만으로 모든 폰트·소재의 상업 배포 권리를 승인하지
   않는다. 인벤토리는 직접 참조 항목이며 모든 renderer 의존성의 법률 검토를
   대신하지 않는다.

기존 컬렉션 `template:lightbound`는 확인 당시 700P·활성 상태였다.
과거 무료 분류와 다르지만 기존 관리자 설정일 수 있어 이번 작업에서 변경하지
않는다. 나머지 기존 상품도 재가격 설정하지 않는다.

## 실행 기록

- 대상 프로젝트: `rrbhxdtriummqpztpjrk`. 연결된 CLI로 기존 상품과 충전
  설정을 읽은 후 생성 SQL을 실행했다. INSERT 결과 7행을 확인했다.
- 별도 읽기 검증에서 7종 모두 `point_price=null`, `is_active=false`,
  `get_point_shop_access`의 `available=false`, `is_free=false`를 확인했다.
- 기존 `template:lightbound`는 700P·활성 상태 그대로 유지됐다.
- 등록 명세에는 7개 상품, 기본·확장판과 세 규격을 합한 36개 문서,
  표지를 포함한 총 1,044개 네이티브 페이지가 들어 있다. 참조 로컬 이미지의
  파일 존재도 확인했다. 문서 전달 경로를 실제 앱에 연결한 것은 아니다.
- 상품 키·초안 SQL·문서 패키지·기존 37종 노출·관리자 가격 편집·구매 확인·
  계정 변경·기존 템플릿 적용 테스트 25개 통과. 별도 볼륨 구성·승인 상태
  회귀 테스트 1개 통과. 대상 파일 정적 분석과 `git diff --check` 통과.
- 관리자 변경은 소스와 위젯 테스트에서 검증했다. 이번 작업에서는 새 앱
  바이너리를 배포하거나 실제 기기에서 결제하지 않았다. 미리보기 서버의
  기존 앨범 디자인은 변경하지 않았다.
