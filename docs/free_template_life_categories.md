# 일상의 관계를 담는 무료 카테고리 확장

2026-09-08. 사용자가 성장·육아, 가족·친구, 커플·기념일, 반려동물을 각 5종씩
추가하도록 선택했다. 기존 무료 15종을 유지하고 20종을 추가해 총 35종으로 확장한다.
퇴출 템플릿과 저장된 사용자 앨범은 변경하지 않는다.

## 분류 원칙

- 주제: 웨딩, 여행, 일상, 성장·육아, 가족·친구, 커플·기념일, 반려동물.
- 분위기: 미니멀, 에디토리얼, 내추럴, 로맨틱, 필름, 스크랩북, 컬러풀을 검색 태그로 분리.
- 빈 카테고리를 먼저 공개하지 않는다. 모든 주제에 무료 5종이 실제로 연결되어 있다.
- 카테고리는 스토어에서 줄바꿈 배열로 모두 보인다. 길어진 이름을 가로 스크롤 뒤에 숨기지 않는다.
- 스토어와 편집기의 주제 순서는 `template_catalog_categories.dart`를 공유한다.
- '아기', '첫돌', '우정', '데이트', '강아지', '고양이' 등 생활 언어로도 검색할 수 있다.

주제와 스타일을 구분하는 참고 사례는 [Shutterfly의 포토북 스타일 분류](https://www.shutterfly.com/t/photo-book-styles/)다.
가족·성장·기념일 같은 기록 목적을 다루되, 아래 이름과 페이지 구성은 SnapFit에서 새로 설계했다.
이 참고 자료는 경쟁사 대비 우위나 판매 성과를 입증하는 자료가 아니다.

## 제작과 편집

20개의 표지 구도를 별도로 작성하고, 240개 스프레드의 제목·문장·캡션·사진 순서를
주제에 맞춰 작성했다. 새 조판 5종(성장 기록표, 사진 쌍, 스크랩 배치, 관찰 노트, 초상 에세이)을
기존 레이어 조판 도구에 추가했다. 제목만 바꾼 복제 문서나 퇴출 디자인 복원이 아니다.

사진, 프레임, 문구, 종이, 테이프, 리본은 독립 편집 레이어다. 스토어, 앨범 생성의 사진 넣기,
편집기의 템플릿 목록에 동일한 문서가 사용된다. 기본 3종과 이전 무료 12종의 ID와 디자인은 유지한다.

## 사진 자산

내장 ImageGen 도구로 샘플 사진 20장을 새로 생성했다. 앱의 실시간 AI 생성 API를 호출한
템플릿이 아니라, 개발 중 제작한 교체 가능한 샘플 사진을 사용하는 사전 제작 무료 템플릿이다.
각 템플릿은 여러 사용자 사진을 받으며, 미리보기에서는 주제별 샘플 사진을 여러 슬롯에 사용한다.

- 최종 파일: `assets/templates/original_editorial/images/{growth,family,couple,pet}_*.png`
- 전체 프롬프트와 원본 경로: `assets/templates/original_editorial/life_photos_provenance.json`
- 본문 사진 외의 기존 정물·풍경 자산과 검증된 종이·리본 소재도 함께 사용한다.
- 단체 사진은 원본 구도를 유지한다. 자동 얼굴 인식이나 모든 사용자 사진의 크롭 보장을 의미하지 않는다.

## 검증과 배포 범위

새 20종은 3규격 × 25쪽으로 1,500쪽이며, 이전 무료 확장 12종을 합쳐 2,400쪽을
실제 Flutter 렌더러로 검수한다. 좌표·텍스트 넘침·레이어 ID·파일 존재·프레임 보존·저장 복원을 검사한다.
검수 이미지: `output/template-preview/free-expansion/`.

최종 결과:

- 관련 Flutter 테스트 440개 통과. 32개 확장 컬렉션의 2,400쪽 렌더링과 기존 기본 3종의 회귀 검수를 포함한다.
- 스토어 브라우저: 35종 검색 + 퇴출 이름 검색 + 7개 주제 필터를 390×844, 844×390, 1440×900에서 확인. 총 129건 통과.
- 대표 새 주제 4종의 세 규격·목차 23~24쪽·문구 폼을 같은 세 화면에서 확인. 총 36조합 통과.
- 정적 분석, 웹 릴리스 빌드, `git diff --check` 통과. 웹 검증에서 이미지 HTTP 오류와 AI API 요청 없음.
- 브라우저 전체 35종×3규격×3화면 전수 매트릭스 대신, 전수 네이티브 검수와 위 브라우저 표본을 최종 검수 범위로 삼았다.
- 결과 JSON: `output/template-preview/published-store/report.json`, `output/template-preview/free-expansion/browser/report.json`.
- 전체 35종 표지: `output/template-preview/free-expansion/catalog.png`.

대표 브라우저 검수 실행 예:

```sh
TEMPLATE_PREVIEW_TITLES='알록달록 자라는 날|우리의 좋은 사이|둘이 모은 조각|우리 집 작은 가족' node tool/template_studio/verify_free_catalog.cjs
```

`TEMPLATE_PREVIEW_TITLES`를 생략하면 전체 35종 매트릭스를 실행한다.

반영 범위는 앱 코드와 로컬 웹 미리보기다. 네이티브 앱 배포와 서버 게시를 수행하지 않는다.
실물 인쇄와 최종 배포용 자산 권리 검토는 별도이며 `printVerified: false`,
`catalogPublishable: false`를 유지한다. 샘플 사진을 실촬영 사진으로 표시하지 않는다.
