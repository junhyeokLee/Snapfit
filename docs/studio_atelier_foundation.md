# 소재 스튜디오 1차 확장

2026-09-08. 기존 35개 컬렉션은 무료로 유지한다. 유료 상품 등록이나 운영 서버 변경은 하지 않는다.

## 추가한 소재

- 사진 프레임 6종: 이중 매트, 사진 코너, 타원 매트, 린넨 매트, 에어메일 엽서, 우표 인화지.
- 원본 이미지 8종: 올리브 압화, 로즈 실크 리본, 해안 마을 우표, 아카이브 태그,
  구아슈 케이크, 페이퍼 로제트, 꽃잎 블루 수제지, 글라신 종이봉투.
- 한글 문구 28종: 웨딩·여행·일상·성장/육아·가족/친구·커플/기념일·반려동물마다 4종.
- 문구 스타일 4종: 여백의 명조, 선명한 제목, 작은 기록, 다정한 헌사.

현재 스튜디오 프레임은 20종, 종이/스티커/테이프는 21종이다. 기존 장식의 숫자는 합산하지 않는다.
문구는 28개의 편집 가능한 카피이며, 독립 폰트나 전체 템플릿 28종으로 세지 않는다.

프레임과 문구는 Flutter 원본이다. 8개 래스터 소재는 내장 ImageGen으로 새로 제작했다.
앱의 AI 템플릿 생성 API를 호출하거나 기존 상품을 AI 결과로 반환한 것은 아니다.
전체 프롬프트와 생성 원본 경로: `assets/sticker/studio/atelier_provenance.json`.
앱에서 사용하는 파일은 같은 디렉터리의 PNG이며 1145~1448px 폭, 실제 알파 채널을 갖는다.
글라신 봉투는 종이 질감 이미지다. 표면 자체가 반투명하게 투과되는 기능으로 표시하지 않는다.

## 편집 연결

- 사진 프레임 선택창의 스튜디오 목록에 새 6종을 먼저 배치한다.
- 꾸미기 > 새 컬렉션에 네 소재 계열 필터를 추가한다. 기존 장식은 별도 탭에 유지한다.
- 글쓰기 도구의 문구 아이콘에서 주제별 카피를 고른 뒤 내용, 글꼴, 색, 크기, 정렬을 수정한다.
- 문구 편집 후 저장은 기존 텍스트 레이어/실행 취소 경로를 사용한다.
- 새 PNG는 사진 슬롯이 아닌 스티커 레이어다. 사진 교체/초기화 대상에 포함하지 않는다.
- 저장된 프레임/장식 키는 삭제하거나 다른 그림으로 덮어쓰지 않는다.

미리보기: `http://127.0.0.1:4323/?studio=atelier#/atelier`
네 세트의 실제 Flutter 레이어 조합, 세 규격, 사진 교체, 프레임/소재 변경,
문구 선택 및 직접 수정 기능을 제공한다. 여기서 고른 변경은 개발용 미리보기의 임시 상태다.
스토어에 신규 완성 템플릿으로 추가하지 않는다.

  28개 문구의 세 규격 저장 왕복, 주제 선택, 문구 편집 및 키보드 전환, 무료 카탈로그 유지.

## 유료 기준

경쟁사의 소재 개수를 따라잡는 것보다 **사용자 사진으로 완성한 한 권의 앨범**에서 차별화한다.
편집 가능한 문구와 사진 프레임 자체는 경쟁사도 제공하는 기본 기능이다.
공식 [텍스트 가이드](https://help.miricanvas.com/hc/ko/articles/360021768372)와
[프레임 가이드](https://help.miricanvas.com/hc/ko/articles/360021771772)를 참고했다.
경쟁사의 유료 결과물 전체를 직접 대조한 상태는 아니므로 우월성을 달성했다고 평가하지 않는다.

다음 유료 후보는 새 상품 ID와 독립 아트디렉션으로 대표 표지 + 4스프레드부터 제작한다.
무료 컬렉션의 색상이나 이름만 바꿔 판매하지 않는다.

1. 원본 아트디렉션: 컬렉션 전용 그림, 종이, 제목 체계와 페이지 역할이 하나의 책으로 이어질 것.
2. 사진 내성: 같은 사진을 넣어도 얼굴/주 피사체를 자르지 않고, 저조도·셀피·단체·적은 사진에 대안을 제공할 것.
3. 조판: 짧은 이름, 긴 한글 문장, 날짜 변경 시에도 위계와 여백을 유지할 것.
4. 규격: 정사각/세로/가로를 단순 확대하지 않고 스프레드와 제본 여백까지 개별 검수할 것.
5. 편집: 사진 교체, 크롭, 문구 수정, 되돌리기, 저장/재진입을 실기기에서 검증할 것.
6. 실물: 배치 크기의 유효 해상도, 도련과 안전영역, 원본/폰트 이용 범위를 확인하고 교정쇄를 볼 것.
7. 비교: 동일한 사진·문구·규격으로 만든 결과를 브랜드 없이 비교하고 개선 이유를 기록할 것.

이번 소재와 미리보기는 위의 모든 출시 조건을 통과한 유료 상품이 아니다.
상세 검수 점수와 출시 차단 조건은 `premium_template_release_plan.md`를 따른다.
