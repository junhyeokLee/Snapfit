# 컨셉 확장: 완성형 24쪽 시안

기존 승인 컬렉션과 무료 스토어 37종은 수정하지 않는다. 이전 3종의 디자인 승인 후
성장·가족·커플·반려동물 4종을 추가했다. 각 권은 표지 1쪽과 내지 24쪽이며,
세로·정사각형·가로 규격을 지원한다. 총 7종, 네이티브 문서 21개, 렌더링 525쪽이다.
새 템플릿은 자동 AI 생성 결과가 아니라 독립 조판한 디자인 검토 후보이다.
원본 장식 PNG만 이미지 생성 도구로 만들고 사진·문구·장식은 개별 레이어로 보존했다.

승인 원본으로 보존하며, 9개 문서의 아트워크가 변경되지 않았는지 테스트한다.
디자인 승인은 판매 승인이 아니다. 새 4종은 검토 대기이며 모두 자동 판매를 막는다.

## 제작 원칙

- 표지에는 큰 사진 1장과 제목·날짜·이름을 둔다. 완성 페이지를 이미지로 굳히지 않는다.
- 모든 사진은 교체 가능한 슬롯, 문구는 편집 가능한 텍스트, 장식은 독립 레이어이다.
- 펼침면 12개를 각각 작성한다. 색·사진만 바꿔 24쪽으로 늘리는 반복 생성기를 사용하지 않는다.
- 큰 사진 면, 문구 중심 면, 기록 카드, 사진 묶음의 밀도를 번갈아 배치한다.
- 장식의 원래 비율을 보존하고 카드 문구는 실제 배치된 종이 영역을 기준으로 조판한다.
- 기존 샘플 사진은 실제 교체 슬롯을 보여주기 위한 예시다. 템플릿과 배포 소재의 상업적
  이용 권리는 별도 검수해야 하며, 이미지 생성 성공이 배포 권리 확인을 의미하지 않는다.

## 새 재료와 가격

`conceptWaveDecorations`의 19종은 실제 편집기 꾸미기·즐겨찾기·레이어 목록·저장 복원과
동일 카탈로그를 사용한다. 15종은 투명 원본 PNG, 4종은 네이티브 종이 재료이다.
생성한 PNG는 수정하지 않고 저장했다.
생성 프롬프트와 출처: `assets/sticker/studio/concept_wave_provenance.json`.
추가 4종의 기록: `assets/sticker/studio/life_concept_provenance.json`.
반복 개선용 8종의 기록: `assets/sticker/studio/life_variety_provenance.json`.
네이티브 기록지 4종과 배치 변경 상세: `docs/life_material_variety.md`.

책정가는 실크 매듭 300P, 바다 유리·연필 각각 200P이다. 이번 재료는 보닛 300P,
체크 천 200P, 열쇠 300P, 직조 공 300P이다. 가격표만 갱신하며
운영 DB 가격·소유권·고객 과금은 변경하지 않는다. 신규 컬렉션 가격은 디자인 승인 뒤
기존 2,500P 출시 기준과 완성도를 비교해 확정한다. 승인 전 판매 상품으로 등록하지 않는다.
