# Snapfit AI 앨범 만들기 — 고기능 테마 큐레이션 기획

## 결론

Snapfit AI 앨범 만들기는 사용자가 사진을 하나하나 고르는 기능이 아니라, **사용자가 큰 주제만 정하면 AI가 허용된 사진 안에서 날짜별/이야기별로 선별하고 앨범 초안을 자동 구성해주는 경험**으로 간다.

핵심은 다음이다.

```text
사용자: “여행 앨범 만들래요” 정도만 선택
Snapfit AI: 날짜/시간/반복도/품질/주제 적합도/페이지 흐름을 정리
사용자: 결과를 확인하고 마음에 안 드는 사진만 수정
```

AI는 “사진 추천 버튼”이 아니라 **앨범 편집 큐레이터**처럼 보여야 한다.

---

## 제품 경험 정의

> 사진첩을 뒤지는 일은 Snapfit이 대신하고,  
> 어떤 이야기로 남길지는 사용자가 정한다.

사용자가 고르기 어려운 부분:

- 어떤 사진이 좋은지
- 비슷한 사진 중 무엇을 남길지
- 날짜별로 어떻게 나눌지
- 몇 장을 넣을지
- 어떤 템플릿이 어울릴지
- 앨범의 시작/중간/마지막을 어떻게 구성할지

이 부분을 AI가 처리한다.

사용자가 직접 결정해야 하는 부분:

- 큰 주제
- 추천 결과가 마음에 드는지
- 빼고 싶은 사진/추가하고 싶은 사진
- 최종 생성 여부

```text
주제만 골라주세요. 사진 흐름은 Snapfit이 정리할게요.
```

대안:

- `AI가 먼저 골라주는 앨범`
- `주제별 AI 앨범 만들기`
- `AI 큐레이터로 시작하기`

피해야 할 이름:

- `AI 자동 완성`
- `사진첩 전체 분석`
- `GPT 앨범 생성`
- `얼굴/감정 분석 앨범`

## 전체 UX Flow

```text
새 앨범 만들기
→ 시작 방식 선택
→ AI 앨범 초안 만들기
→ 큰 주제 선택
→ 사진 범위/권한 확인
→ AI 큐레이션 진행
→ 추천 결과 리뷰
→ 세부 수정
→ 앨범 초안 생성
→ 기존 에디터 진입
```

기존 수동 만들기는 반드시 병렬로 둔다.

```text
[AI가 먼저 골라주는 앨범]
주제만 고르면, 어울리는 사진과 흐름을 먼저 정리해드려요.
CTA: AI로 시작하기

[직접 구성하기]
제목, 비율, 사진을 하나씩 정하며 시작해요.
CTA: 직접 만들기
```

## 큰 주제 선택

사용자는 큰 주제만 고른다.

MVP 주제:

- `커플`
- `여행`
- `가족`
- `아기/성장`
- `생일/기념일`
- `친구`
- `일상 기록`
- `직접 입력`

화면 카피:

```text
어떤 앨범을 만들까요?
사진은 아직 고르지 않아도 괜찮아요.
주제에 맞는 장면을 먼저 찾아볼게요.
```

테마 카드 카피:

```text
커플
둘의 시간과 표정을 중심으로

여행
날짜와 장소 흐름이 보이도록

가족
함께 있는 장면과 따뜻한 순간 중심

아기/성장
성장과 작은 표정을 놓치지 않게

생일/기념일
축하 장면과 하이라이트 중심

일상 기록
평범하지만 남기고 싶은 하루들

직접 입력
원하는 주제를 짧게 적기
```

## 사진 범위/권한

AI가 고기능처럼 보여도, 개인정보 불안은 낮춰야 한다.

카피:

```text
사진 접근 권한이 필요해요.
Snapfit은 허용한 사진 안에서만 앨범 초안을 준비해요.
전체 사진첩이 부담스럽다면 일부 사진만 선택할 수 있어요.
```

범위 선택:

- 최근 30일
- 날짜 선택
- 앨범 선택
- 직접 고르기
- OS 제한된 사진만 사용

중요 원칙:

```text
사용자가 허용하지 않은 사진은 보지 않는다.
추천 결과 확인 전에는 앨범이 만들어지지 않는다.
원본 서버 업로드는 기본값이 아니다.
```

## AI 큐레이션 진행 UX

사용자는 “정말 AI가 정리하고 있다”는 느낌을 받아야 한다.  
하지만 무섭거나 감시처럼 보이면 안 된다.

진행 문구:

```text
주제에 어울리는 장면을 찾고 있어요.
날짜별 흐름을 정리하고 있어요.
비슷한 사진은 대표 장면만 남기고 있어요.
앨범의 시작과 마지막 장면을 고르고 있어요.
사진에 어울리는 템플릿을 맞춰보고 있어요.
```

피해야 할 진행 문구:

```text
얼굴을 인식하고 있어요.
감정을 분석하고 있어요.
전체 사진첩을 스캔하고 있어요.
서버로 업로드하고 있어요.
GPT Vision이 분석 중이에요.
```

## 주제별 큐레이션 기준

### 여행

AI가 해야 할 일:

- 날짜별 흐름을 우선 구성
- 첫날/중간/마지막 날의 대표 장면 선택
- 풍경, 장소, 음식, 이동, 인물 컷 균형
- 같은 장소/같은 포즈 반복 컷 줄이기
- 표지는 장소감이 강한 컷 우선

앨범 흐름:

```text
표지
→ 출발/도착
→ 장소 분위기
→ 함께한 순간
→ 음식/거리/디테일
→ 하이라이트
→ 마지막 장면
```

### 커플

AI가 해야 할 일:

- 둘이 함께 있는 컷 우선
- 표정/거리감/분위기 좋은 컷 우선
- 음식, 손, 거리, 뒷모습 같은 디테일 컷 섞기
- 과하게 비슷한 셀카 반복 줄이기
- 따뜻하고 여백 많은 템플릿 추천

앨범 흐름:

```text
표지
→ 둘의 대표 장면
→ 데이트 장소
→ 자연스러운 표정
→ 작은 디테일
→ 조용한 여백
→ 마지막 대표 사진
```

### 가족

AI가 해야 할 일:

- 함께 있는 장면 우선
- 특정 한 사람만 반복되지 않게 균형
- 밝고 안정적인 사진 우선
- 행사/일상/식사/외출 장면을 섞기

### 아기/성장

AI가 해야 할 일:

- 날짜순 변화가 느껴지게 구성
- 표정, 손발, 장난감, 가족과 함께 있는 장면 포함
- 흐림/어두운 사진은 낮은 우선순위
- 작은 디테일 컷을 중간 여백 페이지로 사용

### 생일/기념일

AI가 해야 할 일:

- 준비 → 축하 → 케이크/선물 → 단체/대표 컷 → 마무리 순서
- 하이라이트 컷을 표지 후보로 추천
- 같은 순간의 연사/중복 컷 줄이기

### 일상 기록

AI가 해야 할 일:

- 반복되는 컷보다 변화 있는 장면 우선
- 소소한 디테일과 인물/공간 컷 균형
- 과한 이벤트 느낌보다 담백한 템플릿 추천

## 추천 결과 리뷰 화면

AI가 끝나면 바로 생성하지 않는다. 먼저 리뷰 화면을 보여준다.

헤더:

```text
이런 앨범 초안을 준비했어요
```

요약 카드:

```text
주제: 여행
기간: 7월 12일 ~ 7월 15일
추천 사진: 24장
추천 분량: 16쪽
추천 템플릿: 따뜻한 여행 기록
```

AI 설명:

```text
날짜별 흐름을 살리고, 비슷한 장면은 대표 사진만 남겼어요.
마음에 들지 않는 사진은 빼거나 바꿀 수 있어요.
```

리뷰 항목:

- 표지 후보
- 날짜별 사진 묶음
- 페이지 흐름 미리보기
- 제외된 사진 요약
- 추천 템플릿 1~3개
- 페이지 수/비율 추천

CTA:

```text
이 구성으로 시작하기
사진 바꾸기
주제 다시 고르기
직접 만들기
```

## 고기능 AI처럼 느끼게 하는 포인트

겉으로 AI를 과시하지 않는다. 대신 결과의 디테일로 고기능을 느끼게 한다.

좋은 표현:

```text
비슷한 사진 38장은 접어두었어요.
날짜별 흐름이 자연스럽도록 4개 묶음으로 나눴어요.
여행 시작과 마지막 장면이 잘 보이도록 배치했어요.
커플 앨범에 어울리는 따뜻한 여백 템플릿을 골랐어요.
```

결과 화면에서 보여줄 “AI가 한 일”:

- 날짜별 그룹 생성
- 대표 사진 선정
- 제외 사진 이유 요약
- 주제별 템플릿 선택
- 페이지 흐름 구성
- 표지 후보 추천

## AI 구현 단계

### 1단계: 온디바이스 고기능처럼 보이는 큐레이션

실제 내부 구현:

```text
photo_manager asset 수집
→ 사용자가 허용한 범위만 후보화
→ 날짜/시간 클러스터링
→ 중복/연사 후보 감점
→ 해상도/비율/스크린샷 여부 scoring
→ 주제별 가중치 적용
→ 페이지 흐름 슬롯 생성
→ 템플릿/제목/분량 추천
→ 리뷰 화면 반환
```

이 단계만으로도 사용자에게는 “주제에 맞춰 앨범을 구성해줬다”는 경험을 줄 수 있다.

### 1.5단계: 온디바이스 경량 이미지 품질 분석

가능할 때 추가:

- blur score
- brightness score
- face/person 여부 정도
- 너무 어두운 사진 제외
- 대표 사진 후보 정확도 개선

### 2단계: 선택형 서버 Vision 고급 추천

명확한 동의 후에만 사용한다.

```text
정밀 추천 사용하기
→ 일부/선택 사진 업로드 동의
→ Supabase Storage 임시 업로드
→ Edge Function queue
→ Vision 분석
→ 분석 후 원본/임시 파일 삭제 정책 적용
```

서버 Vision이 할 일:

- 장면 종류 분류
- 분위기/색감 분석
- 표정/인물/풍경 균형 판단
- 제목/문장 추천
- 템플릿 매칭 정확도 향상

## 디자인 가드레일

- main/read/home 완성형 화면에는 큰 AI 배너를 넣지 않는다.
- AI 기능은 앨범 생성 flow 내부에서만 노출한다.
- AI는 네온/로봇/마법 그라디언트가 아니라 편집자의 메모처럼 표현한다.
- 사진/앨범 표지가 주인공이어야 한다.
- 모든 추천 결과는 사용자가 수정 가능해야 한다.
- 기존 에디터의 template/layer/layout/photo/text/cover/sticker/background controls는 절대 줄이지 않는다.
