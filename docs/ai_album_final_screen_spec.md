# Snapfit AI 앨범 고기능 테마 큐레이션 — 최종 화면 명세

역할: Songi / Snapfit Design Director  
범위: 실제 구현 전 개발자 핸드오프용 UX/UI 명세  
전제: 코드 수정 없음, 기존 main/read 시각 기준 유지, 기존 앨범 에디터 모든 컨트롤 유지

---

## 0. 최종 방향

Snapfit AI 앨범 만들기는 사용자가 사진을 하나씩 고르는 기능이 아니라, **큰 주제만 고르면 Snapfit이 허용된 사진 안에서 날짜·이야기·디테일 흐름을 먼저 정리해주는 큐레이션 경험**이다.

사용자는 다음만 결정한다.

1. 어떤 종류의 앨범인지
2. Snapfit이 어떤 사진 범위 안에서 추천할지
3. 추천안이 마음에 드는지
4. 초안으로 만들지 여부

Snapfit AI는 다음을 조용히 대신한다.

- 사진 촬영 날짜/시간 흐름 정리
- 비슷한 사진/연속 촬영 후보 접어두기
- 테마별 대표 장면 추천
- 표지 후보 추천
- 페이지 수/책 비율/템플릿 톤 추천
- 시작·중간·마무리 흐름 구성

제품 언어는 `분석`, `자동 완성`, `스캔`이 아니라 **골라봤어요 / 정리했어요 / 배치했어요 / 잠시 빼두었어요**이다.

---

## 1. 전체 화면 순서

```text
A. 새 앨범 만들기 시작 방식 선택
→ B. AI 테마 선택
→ C. 사진 접근/범위 동의
→ D. 큐레이션 진행
→ E. 추천 결과 리뷰
→ F. 세부 조정 상태
→ G. 생성 직전 확인
→ H. 앨범 초안 생성
→ 기존 Snapfit 에디터 진입
```

분기:

```text
새 앨범 만들기
├─ AI로 시작하기
│  ├─ 테마 선택
│  ├─ 사진 범위/권한
│  ├─ 큐레이션 진행
│  ├─ 추천 리뷰/수정
│  └─ 초안 생성 후 기존 에디터
└─ 직접 만들기
   └─ 기존 수동 만들기 Step1/Step2/Step3 유지
```

중요: AI 흐름은 기존 수동 만들기를 대체하지 않는다. 시작점에서 병렬 선택지로만 추가한다.

## 2. 공통 비주얼 시스템

### 2.1 톤

- Warm Paper / Quiet Editorial / Book Atelier
- 따뜻한 오프화이트 배경
- 종이 카드처럼 낮은 대비의 면
- 잉크 브라운/먹색 계열 텍스트
- 딥 그린 또는 브라운 계열의 절제된 CTA
- 얇은 라인, 낮은 그림자, 넓은 여백
- 사진과 앨범 프리뷰가 항상 주인공

### 2.2 금지 방향

- 네온 AI 그라디언트
- 로봇/마법봉/스캔 라인 중심 연출
- `AI Vision`, `GPT`, `얼굴 인식`, `감정 분석` 노출
- main/read/home에 큰 AI 배너 추가
- 기존 에디터 컨트롤 축소
- 사용자가 보기 전 자동 생성 완료

### 2.3 기본 spacing 기준

모바일 390px 폭 기준.

- 화면 좌우 padding: 20px
- 상단 safe area 아래 여백: 12~16px
- 타이틀 아래 설명 간격: 8px
- 섹션 간격: 24~32px
- 카드 내부 padding: 18~20px
- 카드 간격: 12px
- 그리드 카드 간격: 10~12px
- 하단 sticky CTA 영역 padding: 16px 좌우, 12px 상하
- CTA 높이: 52~56px
- 모서리 반경: 카드 20~24px, 칩/라벨 999px 또는 12px
- 라인: 1px, 따뜻한 베이지/브라운 10~18% 불투명도

### 2.4 타입 계층

정확한 폰트 토큰은 현재 앱 기준을 따른다. 시각 계층만 고정한다.

- Screen title: 22~24sp / bold / ink
- Section title: 17~18sp / semibold
- Body: 14~15sp / regular / warm gray-brown
- Caption/memo: 12~13sp / regular
- CTA: 15~16sp / semibold

한국어 줄바꿈이 390px에서 안전해야 한다. 긴 보조 문장은 2줄까지 허용하되 버튼/칩 라벨은 한 줄 유지.

## 3. Screen A — 새 앨범 만들기 시작 방식 선택

### 목적

사용자가 `AI로 시작하기`와 `직접 만들기`를 같은 레벨의 선택지로 이해한다. AI는 조금 더 추천되는 선택지처럼 보이지만 과하게 광고처럼 보이면 안 된다.

### 화면 구조

```text
Scaffold
└─ SafeArea
   └─ Column
      ├─ TopBar
      │  ├─ BackButton
      │  └─ optional small title: 새 앨범
      ├─ HeaderBlock
      │  ├─ Title: 새 앨범 만들기
      │  └─ Subtitle: 어떻게 시작할까요?
      ├─ StartOptionList
      │  ├─ OptionCard.ai
      │  └─ OptionCard.manual
      ├─ Spacer
      └─ FooterNote
```

### 컴포넌트 명세

#### HeaderBlock

- 좌우 padding: 20px
- 상단 여백: 20~24px
- 타이틀과 서브 간격: 8px

Copy:

- `새 앨범 만들기`
- `어떻게 시작할까요?`

#### OptionCard.ai

- 높이: 내용 기준 최소 156px
- padding: 20px
- radius: 24px
- 배경: 따뜻한 종이색보다 아주 조금 진한 크림
- border: 브라운/그린 계열 12~16%
- 우상단 작은 라벨 허용: `추천`
- 내부 장식은 작은 책갈피/메모 라인 정도. 큰 AI 아이콘 금지.

Copy:

- 제목: `AI가 먼저 골라주는 앨범`
- 설명: `주제만 고르면, 어울리는 사진과 흐름을 먼저 정리해드려요.`
- 보조: `추천안은 만들기 전에 직접 확인하고 고칠 수 있어요.`
- CTA/버튼 텍스트: `AI로 시작하기`

#### OptionCard.manual

- ai 카드보다 덜 강조하되 같은 폭/같은 선택 레벨 유지
- 기존 수동 플로우로 이동

Copy:

- 제목: `직접 구성하기`
- 설명: `제목, 비율, 사진을 하나씩 정하며 시작해요.`
- CTA/버튼 텍스트: `직접 만들기`

#### FooterNote

Copy:

- `언제든 에디터에서 사진과 문구를 다시 바꿀 수 있어요.`

### 인터랙션

- AI 카드 탭 또는 `AI로 시작하기` → Screen B
- 직접 만들기 카드 탭 또는 `직접 만들기` → 기존 Step1
- 뒤로가기 → 이전 화면

## 4. Screen B — AI 테마 선택

### 목적

사용자가 사진 선택 전에 큰 주제만 고르게 한다. 이 화면에서 제목, 페이지 수, 비율, 템플릿을 묻지 않는다.

### 테마 목록

최종 MVP 테마는 7개다.

1. 커플
2. 여행
3. 가족
4. 아기
5. 생일
6. 일상
7. 직접입력

`친구`는 이번 최종 승인 방향에 포함하지 않는다. 추후 확장 가능 테마로만 남긴다.

### 화면 구조

```text
Scaffold
└─ SafeArea
   └─ Column
      ├─ TopBar
      ├─ HeaderBlock
      │  ├─ Title
      │  └─ Subtitle
      ├─ ThemeGrid/List
      │  ├─ ThemeCard.couple
      │  ├─ ThemeCard.travel
      │  ├─ ThemeCard.family
      │  ├─ ThemeCard.baby
      │  ├─ ThemeCard.birthday
      │  ├─ ThemeCard.daily
      │  └─ ThemeCard.custom
      ├─ CustomThemeInput conditional
      └─ BottomCTA
```

### Copy

Header:

- `어떤 앨범을 만들까요?`
- `사진은 아직 고르지 않아도 괜찮아요. 주제에 맞는 장면을 먼저 찾아볼게요.`

ThemeCard copy:

- `커플`  
  `둘의 시간과 표정을 중심으로`
- `여행`  
  `날짜와 장소 흐름이 보이도록`
- `가족`  
  `함께 있는 장면과 따뜻한 순간 중심`
- `아기`  
  `성장과 작은 표정을 놓치지 않게`
- `생일`  
  `축하 장면과 하이라이트 중심`
- `일상`  
  `평범하지만 남기고 싶은 하루들`
- `직접입력`  
  `원하는 주제를 짧게 적기`

CTA:

- 비활성: `주제를 선택해주세요`
- 활성: `사진 범위 정하기`

직접입력 placeholder:

- `예: 제주 가족여행, 돌잔치, 우리의 봄`

직접입력 helper:

- `20자 안팎으로 적으면 추천 흐름을 잡기 쉬워요.`

### 레이아웃

- 2열 그리드 권장. 390px 기준 카드 폭 약 169px.
- 카드 높이: 104~116px
- 직접입력은 2열 카드 중 하나로 두되 선택 시 하단 입력 영역 표시
- 선택 카드: 배경을 살짝 진하게, border 1.5px 또는 shadow 1단계 상승
- 선택 해제/변경은 즉시 가능

### 인터랙션

- 테마 카드 탭 → 선택 상태 반영, CTA 활성
- 직접입력 카드 탭 → 입력 필드 focus, 텍스트가 1자 이상일 때 CTA 활성
- CTA → Screen C

### 접근성

- 카드 전체가 버튼 역할
- 선택 상태는 색뿐 아니라 체크/라벨로도 표시: `선택됨`
- 직접입력은 한국어 IME 조합 중 CTA 상태가 깜빡이지 않게 처리

## 5. Screen C — 사진 접근/범위 동의

### 목적

권한 요청을 기능적이고 투명하게 설명한다. 사용자가 “Snapfit이 허용한 사진만 본다”는 사실을 명확히 이해해야 한다.

### 화면 구조

```text
Scaffold
└─ SafeArea
   └─ Column
      ├─ TopBar
      ├─ HeaderBlock
      ├─ PrivacyMemoCard
      ├─ RangeSelector
      │  ├─ 최근 30일
      │  ├─ 날짜 선택
      │  ├─ 앨범 선택
      │  ├─ 직접 고르기
      │  └─ OS에서 선택한 사진만 사용
      ├─ PermissionStatusCard conditional
      └─ BottomCTA
```

### Copy

Header:

- `추천할 사진 범위를 정해주세요`
- `Snapfit은 허용한 사진 안에서만 앨범 후보를 찾아요.`

PrivacyMemoCard:

- `촬영 날짜, 사진 방향, 비슷한 사진 여부처럼 앨범 구성에 필요한 정보만 사용해요.`
- `기본 추천은 기기 안에서 처리되며, 원본 사진을 서버로 보내지 않아요.`
- `추천 결과를 확인하기 전에는 앨범이 만들어지지 않아요.`

CTA:

- 권한 전: `사진 선택하기`
- 권한 후/범위 선택 후: `이 사진들로 추천받기`

보조 링크:

- `사진은 나중에 더 추가할 수 있어요.`

RangeSelector labels:

- `최근 30일`
- `날짜 선택`
- `앨범 선택`
- `직접 고르기`
- `선택한 사진만 사용`

제한 권한 상태:

- 제목: `선택한 사진만 볼 수 있어요.`
- 설명: `더 많은 사진으로 추천받고 싶다면 사진을 추가로 선택해주세요.`
- CTA: `사진 더 선택하기`

사진이 적을 때:

- 제목: `추천을 만들기엔 사진이 조금 적어요.`
- 설명: `최소 12장 이상 선택하면 더 자연스러운 흐름을 만들 수 있어요.`
- Primary: `사진 더 선택하기`
- Secondary: `이대로 계속하기`

권한 없음/거부:

- 제목: `사진을 선택해야 추천할 수 있어요.`
- 설명: `허용한 사진만 사용하며, 언제든 권한을 바꿀 수 있어요.`
- Primary: `사진 선택하기`
- Secondary: `직접 만들기`

### 레이아웃

- PrivacyMemoCard는 종이 메모 톤. 경고 박스처럼 보이지 않게 한다.
- RangeSelector는 리스트형 또는 칩형. 복잡한 필터 패널 금지.
- 기본 추천 범위는 플랫폼 권한 흐름에 맞춰 `직접 고르기` 또는 `선택한 사진만 사용`을 안전한 기본값으로 둔다.

### 인터랙션

- CTA 클릭 시 OS 권한 요청/사진 picker 호출
- 권한 완료 후 선택 사진 수 표시
- 충분한 사진 수일 때 → Screen D
- 사진 수 부족 시 부족 상태 노출 후 사용자가 계속 가능

## 6. Screen D — 큐레이션 진행

### 목적

실제로 정리하고 있다는 신뢰를 주되, 감시/분석 느낌은 없앤다.

### 화면 구조

```text
Scaffold
└─ SafeArea
   └─ CenterColumn
      ├─ PaperStackPreview
      ├─ Title
      ├─ ProgressMessage
      ├─ StepCaption
      └─ CancelButton
```

### Copy

Title:

- `앨범 초안을 정리하고 있어요`

ProgressMessage 순환:

1. `사진의 촬영 흐름을 살펴보는 중이에요.`
2. `비슷한 사진은 한 장만 남겨보고 있어요.`
3. `주제에 어울리는 장면을 먼저 고르고 있어요.`
4. `표지로 어울릴 사진을 찾고 있어요.`
5. `처음부터 끝까지 자연스럽게 배치하고 있어요.`
6. `확인하기 쉬운 추천안으로 정리하고 있어요.`

Footer:

- `원하지 않으면 언제든 취소할 수 있어요.`
- Button: `취소`

### 모션/비주얼

- 종이 카드 3~4장이 아주 천천히 정렬되는 느낌
- 과한 회전/빛/스캔 라인 금지
- progress bar가 필요하면 얇은 라인형으로만 사용
- 실제 진행률을 알 수 없으면 퍼센트 숫자 금지

### 취소 상태

취소 탭 시 dialog/bottom sheet:

- 제목: `추천을 멈출까요?`
- 설명: `아직 앨범은 만들어지지 않았어요.`
- Primary: `계속 정리하기`
- Secondary: `멈추기`

## 7. Screen E — 추천 결과 리뷰

### 목적

생성 전 리뷰 화면이다. AI가 고른 결과를 신뢰할 수 있게 보여주고, 사용자가 수정할 수 있음을 명확히 한다.

### 화면 구조

```text
Scaffold
└─ Column
   ├─ TopBar
   ├─ ScrollView
   │  ├─ ReviewHeader
   │  ├─ SummaryCard
   │  ├─ RecommendedTitleCard
   │  ├─ CoverRecommendationCard
   │  ├─ StoryFlowSection
   │  ├─ TemplateRecommendationSection
   │  ├─ PhotoSelectionSection
   │  ├─ ExcludedPhotoSection
   │  └─ EditAssuranceNote
   └─ StickyBottomCTA
```

### Header copy

- Title: `먼저 이렇게 골라봤어요`
- Subtitle: `마음에 드는 사진만 남기고 앨범 초안으로 만들 수 있어요.`

### SummaryCard

필드:

- `주제` / 선택 테마명
- `추천 사진` / 예: `42장`
- `분량` / 예: `24쪽`
- `흐름` / 예: `날짜순 이야기 구성`
- `템플릿` / 예: `따뜻한 여행 기록`

예시 copy:

```text
주제        여행
추천 사진   42장
```

- `선택한 사진만 서버로 전송돼요.`
- `전송된 사진은 앨범 추천을 만드는 데만 사용돼요.`
- `추천이 끝난 뒤 원본 처리 파일은 정해진 보관 기간 후 삭제돼요.`
- `동의하지 않아도 기본 추천은 계속 사용할 수 있어요.`

체크박스:

- `선택한 사진을 고급 추천 처리에 사용하는 것에 동의해요.`

CTA:

- Primary: `고급 추천 받기`
- Secondary: `기본 추천으로 계속하기`

금지:

- 명시 동의 없는 서버 Vision 호출
- 전체 사진첩 자동 분석 암시
- 보관/삭제 정책 없는 업로드 UX

## 13. 구현 주의사항

### 13.1 범위 제한

- 구현 변경은 앨범 생성 flow 내부에 한정한다.
- main/read/home baseline은 건드리지 않는다.
- AI 기능을 앱 홈에 큰 배너로 노출하지 않는다.

### 13.2 데이터/상태 모델 권장

이름은 개발자가 기존 컨벤션에 맞게 조정 가능하나 역할은 분리한다.

- `AlbumTheme`: 커플/여행/가족/아기/생일/일상/직접입력
- `PhotoCandidate`: 권한 내 사진 후보와 기본 메타 정보
- `PhotoCluster`: 날짜/시간/유사 장면 묶음
- `StorySection`: 시작/중간/하이라이트/마무리 섹션
- `AlbumRecommendationDraft`: 추천 제목, 표지, 페이지 수, 비율, 템플릿, 사진 배치
- `ExcludedPhotoReason`: 비슷한 사진/흐림/어두움/스크린샷/주제 거리

### 13.3 추천 생성 원칙

MVP는 서버 Vision 없이 시작한다.

```text
photo_manager 후보 수집
→ 사용자가 허용한 범위만 후보화
→ 촬영 날짜/시간 그룹핑
→ 중복/연속 촬영 후보 감점
→ 해상도/비율/스크린샷 여부 scoring
→ 테마별 가중치 적용
→ StorySection 슬롯 생성
→ 표지/템플릿/제목/분량 추천
→ 리뷰 화면 반환
```

### 13.4 copy/표현 주의

권장:

- `골라봤어요`
- `정리했어요`
- `배치했어요`
- `잠시 빼두었어요`
- `흐름을 잡았어요`
- `추천 초안`
- `앨범 흐름`
- `추천 이유`

금지:

- `전체 사진첩 분석 중`
- `얼굴 인식 중`
- `감정 분석 중`
- `GPT Vision 처리 중`
- `완벽한 앨범을 만들었어요`
- `AI가 자동으로 완성했어요`

### 13.5 에디터 연결 주의

- AI 추천 확정 후에도 생성되는 것은 `완성본`이 아니라 `초안`이다.
- 기존 에디터 진입 후 모든 편집 기능을 사용할 수 있어야 한다.
- 추천안에서 제외한 사진도 나중에 추가할 수 있는 경로를 막지 않는다.
- 기존 Supabase/storage/rendering/background 관련 보호 로직을 우회하지 않는다.

### 13.6 플랫폼 권한 주의

- iOS limited photo access는 정상 상태로 디자인한다. 오류처럼 보이면 안 된다.
- Android selected photos도 정상 상태로 처리한다.
- 권한이 제한된 경우 copy는 `선택한 사진 안에서만 추천했어요.`로 통일한다.
- 사용자가 허용하지 않은 사진을 보거나 본 것처럼 암시하지 않는다.

### 13.7 테스트/검증 기준

개발 완료 후 확인해야 할 사용자 경험 기준:

- 첫 행동은 사진 선택이 아니라 테마 선택이다.
- 커플/여행/가족/아기/생일/일상/직접입력이 모두 표시된다.
- 사진 권한 전 `허용한 사진 안에서만 추천`이 명확히 보인다.
- 큐레이션 진행 중 금지 문구가 없다.
- 추천 리뷰에서 생성 전 확인/수정이 가능하다.
- 추천 이유가 최소 3개 이상 노출된다.
- `잠시 빼둔 사진`을 확인하고 다시 넣을 수 있다.
- 초안 생성 전 확인 sheet가 나온다.
- 초안 생성 후 기존 에디터 컨트롤이 줄어들지 않는다.
- main/read/home 화면 시각 baseline에 변경이 없다.

## 14. 개발 착수용 최종 acceptance criteria

1. AI 흐름은 앨범 만들기 시작점의 한 갈래로 추가된다.
2. 사용자는 AI 흐름에서 테마만 먼저 고른다.
3. 테마는 `커플/여행/가족/아기/생일/일상/직접입력`으로 고정한다.
4. 사진 접근 화면은 허용 범위와 온디바이스 기본 추천을 명확히 설명한다.
5. 큐레이션 진행 화면은 조용한 종이/편집실 톤으로 보인다.
6. 추천 결과 리뷰는 표지, 이야기 흐름, 추천 사진, 빼둔 사진, 템플릿, 페이지 수를 보여준다.
7. 사용자는 사진 포함/제외, 표지, 제목, 페이지 수, 템플릿을 초안 생성 전에 조정할 수 있다.
8. 사용자가 확인하기 전 앨범 초안은 생성되지 않는다.
9. 초안 생성 후 기존 Snapfit 에디터로 진입하며 모든 편집 컨트롤이 유지된다.
10. AI는 고기능처럼 느껴지지만 감시/분석/업로드 느낌을 주지 않는다.

## 15. Songi 최종 디자인 판단

이번 기능은 “AI를 보여주는 화면”이 아니라 **사진 선택 피로를 덜어주는 조용한 편집실**이어야 한다.

사용자가 느껴야 하는 문장은 이것이다.

> “여행이라고만 고르면 먼저 정리해주네.  
> 그래도 만들기 전에는 내가 보고 고칠 수 있네.”

이 균형을 해치지 않는 선에서만 AI의 고기능감을 표현한다. 결과의 디테일은 풍부하게, 화면의 태도는 차분하게 유지한다.
