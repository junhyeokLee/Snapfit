# Snapfit Template Layout Creative Director Guide

## Non-negotiable target

Snapfit templates must surpass marketplace-style previews by making **image, layout, decoration, crop, typography, and page role** feel intentionally art-directed together.

A page is not complete because it has an image slot and text. It is complete only when the image subject, crop, title position, caption, motif, decoration, whitespace, and page-to-page rhythm support one emotional story.

## Core promise

> “My real photo becomes something a designer would sell.”

Every layout decision should make the user's image feel more premium, more emotional, and easier to understand.

## Image + layout integration rules

### 1. Design around the image subject

Before placing text or decoration, identify the image subject:

- person from behind / silhouette
- hands / food / object detail
- room / table / street context
- couple / family / friend interaction
- wide scene with human trace

Then choose the layout role:

- **Hero:** large image, clear focal subject, minimal text, strong title block.
- **Editorial split:** one dominant image + one supporting image, with caption/rule line.
- **Detail card:** object/hands image with generous margin and small metadata.
- **Timeline/route:** repeated small moments connected by dots/lines.
- **Quote page:** quiet photo with large whitespace for emotional sentence.
- **Contact sheet:** multiple small memories, intentionally imperfect rhythm.
- **Closing:** one calm image + final line, no clutter.

### 2. Crop with intention

Good crops should feel like a designer chose them, not that the image was randomly filled.

- Put faces out of frame or use back views/silhouettes for safety and relatability.
- Keep hands/objects away from text overlays.
- Leave negative space where the title or caption will sit.
- Use close crops for detail pages, wider crops for opening/closing pages.
- Avoid putting important subjects under decorative stickers, route lines, or cards.

### 3. Decorations must be concept tools

Decorations should explain the template theme, not just fill space.

Allowed examples:

- Travel: route lines, dots, boarding pass cuts, ticket cards, postcard borders, date/location labels.
- Wedding: thin gold rules, arch masks, invitation cards, serif labels, flower/ring detail frames.
- Babybook: milestone chips, soft rounded cards, blanket/toy labels, month markers.
- Family: note cards, checklist marks, date stamps, paper texture, picnic labels.
- Film diary: film strip, contact sheet, tape, grain, timestamp labels.
- Scrapbook: tape, paper scraps, hand-placed photo frames, memo labels.

Rejected:

- Random stickers unrelated to the story.
- Decoration covering the image subject.
- Repeated motif on every page without variation.
- Heavy effects hiding weak composition.

### 4. Typography must have a job

Each page should have no more than 1–2 text priorities.

- Title: emotional hook or page role.
- Caption: context, date, place, short memory.
- Metadata: small label, issue/date/route/page number.

Korean text must be readable at phone size. If text is cramped, shorten the copy before shrinking the font too much.

### 5. Page rhythm must feel like a complete product

A 12-page template should not repeat the same grid. Use rhythm:

1. Cover / sales image
2. Opening hero
3. Split story
4. Detail card
5. Map/timeline/milestone
6. Object/caption page
7. Quote/letter page
8. Collage/contact sheet
9. Full-bleed image
10. Triptych or sequence
11. Quiet emotional page
12. Closing page

The exact order can change by theme, but every page needs a distinct role.

## Per-template layout direction

### 제주의 기록
Image set: real travel snapshots. Layout language: route magazine.

- Use route dots/lines only where they connect actual travel moments.
- Ticket/postcard pages should hold cafe, ticket, car-window, or market-detail images.
- Beach/ocean images should include people, hands, or travel objects where possible.
- Closing page should use a human silhouette or photo-taking moment, not empty sunset.

### Wedding Editorial
Image set: intimate wedding moments. Layout language: cream editorial album.

- Use large quiet crops for veil/hands/couple backs.
- Gold rules and arch frames should guide the eye, not decorate randomly.
- Ring/bouquet/stationery images belong on detail-card pages.
- Avoid overly dense captions; wedding pages need calm space.

### SAVE THE DATE
Image set: announcement and couple details. Layout language: premium date card.

- The date area must be the focal point on cover/key pages.
- Couple/hand/stationery images should leave negative space for numbers.
- Use minimal decoration; date typography is the design object.

### 소프트 베이비북
Image set: baby detail and parent touch. Layout language: soft milestone book.

- Prefer hands/feet/blanket/toy closeups over full baby faces.
- Rounded cards and pastel chips should feel gentle and spacious.
- Milestone labels must be readable and not cover the baby detail.

### 가족의 주말
Image set: ordinary warm family scenes. Layout language: weekend memory notes.

- Use layouts that feel like a family album, not advertising.
- Keep small messiness: table, toys, picnic objects, child drawings.
- Checklist/date-stamp motifs should support “today's memory.”

### 필름 다이어리
Image set: analog photo dump. Layout language: film/contact sheet.

- Use film strips and tape around printed-photo or camera images.
- Allow asymmetric placement and slight rotation, but keep hierarchy clear.
- Dark pages need high-contrast captions.

### 화이트 에디토리얼
Image set: quiet lifestyle with human trace. Layout language: white-space magazine.

- Large whitespace is allowed only when image/caption placement feels deliberate.
- Use thin rules, object rhythm, and precise typography rather than stickers.
- Photos should feel like calm daily life, not empty architecture.

### 우리의 기념일
Image set: everyday couple anniversary. Layout language: intimate date keepsake.

- Cake/flower/gift/hand images belong on detail-card pages.
- Couple backs or silhouettes work best for hero/closing pages.
- Decoration should feel like a saved memory, not a generic romantic sticker pack.

### Scrapbook
Image set: messy-curated memory board. Layout language: hand-assembled collage.

- Use layered paper/tape/photo frames with controlled messiness.
- Hands arranging photos are excellent cover/detail images.
- Avoid overfilling pages; collage still needs visual hierarchy.

## Visual QA checklist

Before a template can be called “above MiriCanvas quality,” answer yes to all:

- Does the cover make a user want to tap before reading the title?
- Does each inner page have a different role?
- Does every image naturally fit the layout and page role?
- Are decorations motivated by the theme?
- Is the main subject never covered by text or decoration?
- Are Korean title/caption sizes readable on a phone?
- Does the sample image set feel like one story?
- Would replacing sample images with user photos still look premium?
- Are logo/text/brand/face/AI-artifact risks removed?

If any answer is no, keep refining.
