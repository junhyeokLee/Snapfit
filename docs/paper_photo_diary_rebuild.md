# 겹쳐진 순간: 새 디자인 방향

2026-09-08. 사용자가 사진 인화지와 메모지 중심의 시안을 유치하다고 판단하여, 그 시안을 확장하지 않고 디자인 자체를 다시 구성했다. 기존 `luminous-edition` 식별자와 미리보기 주소는 유지한다.

## 현재 범위

현재 후보는 **표지와 첫 펼침면, 총 3면**이다. 이전 13면을 완성된 상품처럼 노출하지 않는다. 전체 앨범 완성이 아니라 디자인 방향을 다시 검토하는 단계다.

- 표지: 큰 사진 한 장과 제목, 이름, 날짜만 남긴다. 작은 사진 단편과 임의의 부제, 소장본 표기, 붉은 인쇄선은 제거했다.
- 1쪽: 짙은 바탕, 큰 카페 장면과 사진 띠를 확대했다. 커다란 빨간 `오후`와 장식용 문단/메모를 없앴다.
- 2쪽: 밝은 바탕의 엇갈린 사진 조각은 유지한다. `멈춰 둔` 빨간 라벨, `빛, 온도, 그리고 취향.`과 하단의 설명 문구를 없애고 사진을 키웠다.
- 내지에는 이름과 날짜, 쪽수만 작은 크기로 남긴다. 현재 후보에는 붉은 글씨나 붉은 배경 장식이 없다.
- 꽃과 과일 스티커, 반복 폴라로이드 테두리, 손글씨 메모 카드 중심 구성을 사용하지 않는다.
- 모든 사진과 문구는 각각 교체 가능한 레이어다. 완성 화면을 한 장의 이미지로 합치지 않는다.
- 세로, 정사각형, 가로 규격 모두 같은 시안으로 검수한다.

Paper 작업은 사진 조각을 수집하고 겹치는 구성의 참고다. [menguiny의 공개 작업](https://www.lemon8-app.com/@menguiny/7417926513725751813?region=us), [Paper Collage 소개](https://medium.com/wetransfer/paper-unlocks-creative-expression-with-collage-8f1bf498a467). 참고 작업의 사진과 장식을 제품에 복사하지 않았다. 새 시안의 사진은 프로젝트의 기존 예시 에셋이며, 새 AI 이미지 생성이나 API 호출은 하지 않았다.

## 보존

- 공개 스튜디오 꾸밈 재료 44종, 신규 프레임 9종, 꾸민 문구 7종은 그대로 보존한다.
- 실제 편집기 연결과 기존 즐겨찾기 키를 유지한다.
- 후보 자체의 즐겨찾기는 `template:luminous-edition`을 사용한다. 이전에 저장한 꾸민 문구의 즐겨찾기를 덮어쓰지 않는다.
- 무료 37종과 무료 전환 앨범은 변경하지 않는다.
- 이번에 확보한 [Nanum Pen Script](https://github.com/google/fonts/tree/main/ofl/nanumpenscript) 원본 서체도 편집기에서 사용할 수 있게 보관한다. 원본 TTF를 수정하지 않았고 SIL OFL 파일을 `assets/fonts/NanumPenScript-OFL.txt`에 보관/번들링한다. 현재 아트북 후보의 본문과 제목은 기존 NotoSans, 을유명조, RiaSans, Poppins 서체를 사용한다.

## 출시 상태

`accessTier: unassigned`, `catalogPublishable: false`, 사용자 검토 대기. 가격 설정이나 판매 상품 등록은 하지 않았다. 현재 시안으로 유료 판매 가치나 경쟁 제품보다 우수함을 입증한 것은 아니다.

## 검수

- 3면 × 3규격 실제 Flutter 렌더링.
- 레이어 범위, 글자 잘림, 중복 ID, 저장 복원, 사진 교체 슬롯 검증.
- 사진 위 문구는 불투명 종이가 글자 영역을 덮고 사진보다 위, 글자보다 아래인 경우만 의도된 겹침으로 허용.
- 이번 후보는 사진 위 문구를 없앴다. 표지 사진이 정확히 한 장이며, 지적된 문구와 빨간 강조가 다시 들어오지 않는지도 검증한다.
- 문구 수정, 사진 확대, 무료 비교, 보존된 꾸밈 재료/즐겨찾기 회귀 테스트.

시안 관련 27개 테스트 통과. 실제 Flutter 렌더로 표지와 첫 펼침면의 구성을 확인했다. 기존 편집 재료 테스트는 앞선 동일 작업에서 통과했으며, 이후 재료 구현은 변경하지 않았다.

현재 문서의 `cover`와 `pages`가 렌더할 페이지 목록의 기준이다. 이전 내보내기 디렉터리에 남은 파일은 현재 후보 페이지가 아니다.
