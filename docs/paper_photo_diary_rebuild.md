# 둘만의 여행: 차분한 여행 수집 콜라주

> 2026-09-09 보관본. 아래는 기존 20쪽 작업 기록이다. 사용자 피드백에 따라 원본 문서와 빌더를 보존하고, 현재 후보는 [펼침면 구조 연구](travel_spread_contrast_study.md)로 분리했다. 좌표가 달라도 큰 사진+작은 사진+종이를 반복하면 시각적으로 같은 페이지처럼 보인다는 점을 다음 작업에 반영한다.

2026-09-09. 사용자가 승인한 방향은 사진 수가 아니라 **컨셉에 맞는 재료의 겹침으로 밀도를 만드는 것**이다. 승인한 표지와 첫 펼침면을 유지하며 내지 20쪽으로 확장했다. 식별자 `luminous-edition`, 기존 미리보기 주소와 즐겨찾기 키를 유지한다.

## 한 권의 구성

**표지 1면 + 내지 20쪽, 10개 펼침면**. 사진은 표지 1장, 내지마다 2장으로 총 41개의 교체 가능한 사진 슬롯이다. 사진을 늘려 맥시멀한 효과를 내지 않는다.

| 쪽 | 목차 | 주요 재료 |
| --- | --- | --- |
| 1–2 | 여행에서 모은 것들 | 지도, 여행 승차권, 우표, 소인, 글라신 봉투 |
| 3–4 | 짐을 내려놓고 | 숙소 키 태그, 여행 노트, 보관지, 수하물 라벨 |
| 5–6 | 골목과 시장 | 지도·등고선, 시장 영수증, 엽서 |
| 7–8 | 카페에 머문 시간 | 카페 영수증, 종이 코스터, 노트 |
| 9–10 | 해변을 따라 | 해안 등고선, 지도, 우표와 인화 사진 |
| 11–12 | 작은 발견들 | 시장 영수증, 상품 태그, 노트, 피크닉 수집물 |
| 13–14 | 둘이 남긴 사진 | 사진 모서리, 보관지, 엽서, 작은 태그 |
| 15–16 | 해가 지는 시간 | 엽서, 등고선, 종이 보관지, 소인 |
| 17–18 | 돌아오는 길 | 수하물 라벨, 지도, 노트와 귀가 후 사진 |
| 19–20 | 여행을 꺼내 보는 날 | 노트, 인화지, 사진 보관지, 마지막 봉투 |

- 표지: 단일 사진이 전체를 덮는다. 하늘 영역의 을유명조 제목, 하단의 이름·날짜를 유지한다.
- 첫 펼침면의 사진, 배치, 색, 재료는 그대로 유지했다.
- 추가한 18쪽은 각각 좌표를 지정한 별도 구성이다. 사진과 장식만 바꾼 동일 레이아웃 반복으로 생성하지 않는다.
- 기본 색은 바다색과 잿빛 녹색. 카페는 종이색, 저녁은 옅고 차가운 잉크색으로 조정한다. 밝은 빨강, 큰 꽃·금속 장식, 무관한 장식용 문단은 추가하지 않았다.
- 세로·정사각형·가로 규격 모두 같은 흐름을 제공한다. 종이와 티켓은 정해진 영역 안에서 원래 종횡비를 보존한다.
- 사진, 제목, 날짜, 재료는 독립 편집 레이어다. 티켓·태그 자체의 인쇄 표식은 재료 그림의 일부이며, 앨범의 제목·날짜는 텍스트 레이어다.
- 폴더에 남은 과거 파일이 아니라 문서의 `cover`와 `pages`가 실제 페이지 목록의 기준이다.

Paper는 수집과 겹침의 참고다. [menguiny의 공개 작업](https://www.lemon8-app.com/@menguiny/7417926513725751813?region=us), [Paper Collage 소개](https://medium.com/wetransfer/paper-unlocks-creative-expression-with-collage-8f1bf498a467). 다른 제작자의 디자인이나 장식을 복제하지 않았다.

## 새 재료 9종

직전 공유 재료 47종을 보존하고 9종을 추가해 **56종**이다. 앞서 만든 여행 지도·승차권·소인도 유지했다.

| 저장 키 | 표시 이름 |
| --- | --- |
| travelStayTag | 숙소 키 태그 |
| travelCafeReceipt | 카페 영수증 |
| travelMarketReceipt | 시장에서 받은 영수증 |
| travelCafeCoaster | 종이 코스터 |
| travelPostcard | 여행 엽서 뒷면 |
| travelLuggageLabel | 수하물 라벨 |
| travelNotebook | 떼어 둔 여행 노트 |
| travelPhotoSleeve | 반투명 사진 보관지 |
| travelContourSlip | 해안 등고선 종이 |

Flutter CustomPainter로 종이 재단면, 코스터 테두리, 태그 구멍, 절취선과 잉크 표식을 그린다. 확대/저장 시에도 같은 결정적 질감을 사용한다. 태그·코스터의 바깥 여백과 보관지의 반투명도를 유지한다. 실제 교통·숙박 증빙이나 안내도가 아닌 장식용 도안이다.

모두 실제 편집기 꾸밈 목록의 '여행 기록'과 후보 미리보기의 '꾸밈 재료'에 연결된다. 동일한 등록 키로 삽입, 실행 취소/다시 실행, 즐겨찾기 및 저장·복원을 사용한다. 기존 프레임 9종, 꾸민 문구 7종, 무료 37종은 변경하지 않았다.

## 사진과 출시 범위

현재 사진은 레이아웃 검증용 프로젝트 에셋이며, 이번 확장에 AI 이미지 API 호출은 없다. 숙소의 책 사진과 노을 사진은 기존 여행 샘플을 사용한다. `scrapbook/images/sources/sunset_pair.png`는 원본 README에서도 레이아웃 검증용으로 안내하는 사진이므로 **검토 미리보기에서만 사용**한다.

한 권 분량의 디자인은 구성했지만 **판매 등록본은 아니다**. `accessTier: unassigned`, `catalogPublishable: false`, 사용자 검토 대기를 유지한다. 실제 유료 공개 전에는 샘플 사진의 권리 확인 또는 교체, 사용자 사진 교체 결과, 인쇄 실물 검수, 가격·등록 승인이 필요하다. 자동으로 유료 스토어에 노출하거나 기존 무료 템플릿을 유료 전환하지 않는다.

## 검수

- 21면 × 3규격 실제 Flutter 렌더링과 10개 펼침면 내보내기.
- 페이지 수, 목차 10개, 좌우 페이지, 펼침면 번호, 사진 슬롯 및 개별 구도의 유일성.
- 각 내지에 꾸밈 재료 8개 이상. 모든 재료의 원래 종횡비 유지.
- 레이어 범위, 글자 잘림, 중복 ID, 저장·복원 및 사진 교체 슬롯 검사.
- 표지 위 텍스트는 명시적으로 참조한 사진의 하늘/하단 안전 영역만 허용한다.
- 새 재료의 픽셀 렌더, 코스터 여백, 소인 투명도와 전체 재료의 선택기/편집기/템플릿 렌더 일치.
- 새 숙소 키 태그의 즐겨찾기·확대, 기존 재료와 무료 비교·탐색 회귀 검증.

관련 Flutter 테스트 **175개 통과**. 노을 사진을 원본 비율에 맞춰 마지막 보정한 뒤 디자인 테스트 30개도 다시 통과했다. 태양과 인물이 잘리지 않도록 인화지 안쪽 사진 비율이 세 규격에서 7:6으로 유지되는지 검증한다. 변경한 Dart 파일의 정적 분석에서도 문제가 없었다.

Chrome Playwright에서 390×844, 844×390, 1440×900 화면 각각에 대해 앨범 3규격과 전체 10개 펼침면을 검증했다. 목차 이동, 페이지 확대, 제목 수정, 재료 즐겨찾기, 무료 비교와 무료 시안 이동, 캔버스 픽셀·리소스 오류 검사 모두 통과했다. 최종 노을 사진 보정 후에는 8번째 펼침면을 같은 화면 크기·앨범 규격 조합으로 재검증했다. 전체 결과는 `output/template-preview/luminous-edition/browser/report.json`, 최종 부분 검수는 `browser-focus/report.json`에 남긴다.
