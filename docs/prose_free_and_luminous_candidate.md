# 무료 완성판과 별도 유료 후보

최신 후보는 [맥시멀 스크랩북](luminous_maximalist_study.md)으로 변경했다.
아래 새 후보 표와 검증 기록은 이전 미니멀 시안의 이력이다. 무료 전환 결정은 그대로 유지한다.

2026-09-08 사용자 결정: 「함께여서 좋은 날」의 수준은 무료 기준이다.
이전의 유료 승인 대기 판단을 대체한다. 무료 품질을 낮추거나 회수하지 않는다.

## 함께여서 좋은 날

- 기존 문서 ID와 프레임 키, 즐겨찾기 키를 유지한다. 번들 ID는 -9305.
- 표지 + 내지 24쪽, 세 규격. 기존 표지와 1~5쪽은 보존하고 기존 6쪽 마무리는 24쪽으로 이동했다.
- 아침·대화·산책·취향·사진 밖의 기억·기념일·다음 계절로 이어지는 18쪽을 새로 작성했다.
- 커플·기념일 카테고리. 앱 번들 스토어 및 생성 카탈로그는 무료 37종이다.
- 사진 교체, 텍스트 편집, 세 규격 원본, 로컬 즐겨찾기 지원. 세 매트도 무료 프레임 선택기에 공개한다.
- 로컬 번들 반영이며 원격 서버 배포나 결제 상품 등록이 아니다. 실물 인쇄 검수 완료를 뜻하지 않는다.
- 프리뷰: http://127.0.0.1:4323/?collection=our-prose#/our-prose

## 가장 빛나던 우리

유료 후보의 표지와 대표 3펼침만 별도로 작성했다. 무료에서 제목·가격만 바꾼 문서가 아니다.
공개 스토어와 프레임 선택기에서는 노출하지 않으며, accessTier는 unassigned다.

| 구분 | 무료 완성판 | 새 후보의 설계 |
| --- | --- | --- |
| 제목 | 패턴을 채운 명조 표제 | 속이 빈 윤곽 글자와 채운 글자를 교차하는 단계적 조판 |
| 문구 | 사진 곁의 짧은 기록 | 펼침을 건너 이어지는 큰 문구, 세로 캡션과 작은 기록의 대비 |
| 사진 창 | 아치·사각 매트 중심 | 하나의 사진을 세 창으로 이어 보여주는 연속 트립틱 |
| 종이 외곽 | 직선 외곽의 여백 | 굴곡 있는 외곽과 얇은 안쪽 선이 분리된 매트 |
| 작은 사진 | 모서리를 잘라낸 매트 | 오목한 어깨와 양끝 홈이 있는 카메오 창 |
| 편집 | 사진과 텍스트 분리 | 동일 원칙 유지. 윤곽선도 이미지를 굽지 않고 글자로 저장 |

프레임은 Native Flutter의 Path/CustomPainter로 구현한다. 윤곽 글자는 공유 스타일 함수를
편집기와 미리보기에 적용한다. 외곽선 두께, 창 간격, 매트 너비는 프레임·글자 크기에 비례한다.
샘플 사진은 프로젝트에 있는 기존 시연 이미지다. 이 차수에서 AI 생성이나 유료 API 호출은 없다.
전체 앨범이 AI 자동 생성되었다고 표시하지 않는다.

프리뷰: http://127.0.0.1:4323/?collection=luminous-edition#/luminous-edition
무료 비교는 이제 무료 「함께여서 좋은 날」과 새 후보의 원본 구성을 먼저 보여준다.
별도의 '같은 사진으로 비교' 모드에서 동일 사진 묶음을 배정해 프레임을 비교할 수 있다.
사진 칸 수와 문서 구조는 유지하므로 같은 사진 모드에서는 사진이 반복될 수 있다.
비교 화면은 기본 문구이며 읽기 전용이다. 원본 문서나 편집 중인 사진을 덮어쓰지 않는다.

## 유료 승인 조건

1. 가격표·샘플 사진을 가려도 타이포그래피와 사진 창만으로 차이가 구별되어야 한다.
2. 좋은 샘플 사진뿐 아니라 인물 좌우 배치·단체·풍경·어두운 사진에서도 얼굴과 장면을 보존해야 한다.
3. 줄바꿈·글자 대비·프레임 선·제본 여백·저장 후 원본 일치에 실패하면 유료 승인을 보류한다.
4. 시각적 승인 뒤 전체 원고를 확장한다. 장수와 장식 수로 유료 가치를 대신하지 않는다.
5. 실기기·실물 교정쇄·폰트와 사진의 상품 배포 권리를 검수한다.

자동 테스트 통과는 유료 가치나 경쟁사 대비 우위의 증거가 아니다. 새 후보는 아직 심미적 승인 전이다.

## 검증 기록

- 관련 회귀 테스트 234개 통과. 무료 37종 노출, 카탈로그·생성 플로우, 사진 교체와 저장,
  프레임 마스크, 윤곽 글자 렌더링, 즐겨찾기를 포함한다.
- 마지막 쪽번호 정렬과 비교 모드 수정 뒤 디자인/UI 테스트 21개 재통과.
  무료 25면과 후보 7면을 세 규격에서 렌더링하고 텍스트·레이어 경계를 검사했다.
- 변경 파일 정적 분석 및 웹 release 빌드 통과. 미리보기 서버의 빌드 파일을 갱신했다.
- 무료 완성판은 390×844, 844×390, 1440×900 브라우저에서 문구 편집·갤러리 복귀·
  즐겨찾기 유지·규격 전환을 확인했다.
- 새 후보도 같은 세 화면 크기에서 7면·세 규격, 윤곽 글자 편집, 즐겨찾기,
  원본/같은 사진 비교 전환, 편집 내용 유지, 무료 완성판 복귀를 검증했다.
  브라우저 예외·실패한 요청·AI 및 백엔드 API 요청은 없었다.
  결과는 `output/template-preview/luminous-edition/browser/report.json`에 기록한다.
- 실기기 성능, 실물 인쇄, 상품용 폰트·샘플 사진 배포 권리는 아직 검증 완료가 아니다.
