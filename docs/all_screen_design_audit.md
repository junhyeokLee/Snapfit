# SnapFit 전체 화면 디자인 점검

## 2026-10-15 앨범 목록·확대 보기·컬렉션 개선

- 홈의 햄버거 연결 화면은 `HomeAlbumTabScreen`이다. 과도한 둥근 카드/겹친 그림자와
  화면 너비 기반 글자 확대를 없애고, 실제 책등 재질의 표지와 제목·진행·날짜를 분리했다.
  전체/작업 중/완성본/즐겨찾기/공유, 즐겨찾기 변경과 상세 관리 경로는 유지한다.
  세로는 표지 서가, 가로는 표지와 정보를 나란히 배치하는 지연 생성 목록이다.
- 홈 스와이프의 매 프레임 `setState`를 무대 위치 알림으로 분리했다. 움직이는 동안
  표지 레이어 파싱/하단 서가/상단바를 다시 만들지 않는다. 이웃 표지만 마운트하고,
  커버 객체가 드래그 중 동일함을 테스트했다. 크기·실물 비율·부유 주기/진폭·책등 및
  홈에서 리더로 이어지는 원점은 유지한다. 정적 테스트는 실제 기기의 FPS 증명이 아니다.
- 페이지 크게 보기는 리더의 배경과 실제 종이 비율을 사용하는 별도 갤러리로 정리했다.
  양방향 이동/쪽수/기존 편집 메뉴를 유지하며 더블 탭·핀치 확대/확대 중 팬을 지원한다.
  확대 중에는 페이지 스와이프와 충돌하지 않게 하고 버튼 이동은 가능하다. 회전해도
  같은 페이지 컨트롤러와 스크롤 상태를 유지한다. 리더의 BookFlip 무대는 수정하지 않았다.
- 스토어 상단은 첫 유료 상품 하나를 고정하던 형태 대신 서로 다른 주제 최대 4종의
  컬렉션 선택으로 바꿨다. 선택한 실제 표지와 첫 내지 스프레드를 함께 배치한다.
  혼합 카탈로그에서는 무료 시작점도 포함하고, 기존 포인트 가격/소유권 배지를 그대로
  사용한다. 개인화/실판매 인기순이라고 주장하지 않는다. 나머지 목록의 지연 생성과
  필터·즐겨찾기·검색·스크롤 상태는 유지한다.
- 보관함 상단의 동일 상품 중복 미리보기를 줄이고 보유 템플릿/소재 수와 실제 목록을
  연결했다. 표지에는 홈과 같은 재질, 소재에는 원본에 맞는 배경과 비율을 사용하며
  제목/종류/보유 상태와 즐겨찾기의 정보 위계를 정돈했다. 구매/재사용 권한은 변경 없다.

### 검증 범위

- 통합 152개 테스트 통과: 신규 디자인·홈 재질/스와이프·보관함·스토어 구매 동선·
  기존 홈·BookFlip·스토어 탭 상태 보존. 이후 가로 앨범 목록 조정은 신규 12개를 다시
  실행해 통과했다. 두 실행은 중복되므로 164개의 고유 테스트라고 합산하지 않는다.
- 변경 화면/테스트 11개 파일 정적 분석 오류 없음. 최종 가로 목록 포함 테스트 캡처는
  `output/discovery-refinement-qa/`에 보관한다. 이는 실기기 화면이 아닌 네이티브 위젯
  렌더링이며 실제 계정/결제/서버 주문 성공을 증명하지 않는다.
- 성능용 첫 Android 빌드는 같은 프로젝트의 다른 테스트와 자원이 겹쳐 중단했다.
  기존 앱 PID의 과거 성능 로그를 새 버전의 측정치로 사용하지 않는다. 성능 회귀의
  정량 비교는 보류하며, 로컬 측정 도구 `tool/qa/home_swipe_profile.dart`를 준비했다.

## 2026-10-15 실기기 통합 확인

갤럭시 S23+ (`SM-S916N`, Android, 1080×2340)에 arm64 디버그 APK를
`adb install -r`로 업데이트했다. 삭제/데이터 초기화 없이 로그인·기존 앨범·임시저장을
유지한 상태에서 UI를 직접 조작했다. 증거는 `output/device-journey-qa/2026-10-15/`에
보관한다. 이 폴더에는 실제 기기의 개인 사진과 계정 정보가 포함될 수 있으므로 외부에
공개하지 않는다. 기존 `all-screens-qa`의 테스트 자료 기반 캡처와 구분한다.

### 실제로 확인한 범위

- 제작: 시작 → 직접 만들기 → 제목/규격 → 표지 도구 → 전체 확인. 새 앨범 저장은
  실행하지 않고 테스트 입력은 저장 없이 종료했다.
- AI: 분위기 입력 → 요청 확인/예상 포인트. 실제 AI 생성 요청/포인트 적용은 하지 않았다.
- 템플릿: 목록/무료·유료 구분 → 표지와 내지 선택 → 소재 이용 범위 → 구매 확인창.
  최종 구매는 취소했다. 이미 보유한 템플릿으로 설정 → 사진 채우기 → 실제 사진첩
  선택창까지 연결되는 것도 확인했다. 사진 선택/업로드/저장은 실행하지 않았다.
- 소재: 원본/적용 예시 → 구매 확인창 취소. 무료 소재로 실제 내 앨범 목록 → 적용할
  페이지 선택창까지 이동한 뒤 취소했다. 원본 앨범을 저장하거나 변경하지 않았으며
  선택 과정의 임시 편집 잠금은 취소 경로에서 해제한다.
- 개인 컬렉션: 보관함의 실제 보유 템플릿 2종, 마이의 내 앨범/보유 디자인,
  내 앨범 목록과 진행/완료 구분, 주문 내역의 빈 상태를 확인했다.
- 리더: 현재 표지, 표지에서 내지로 넘김, 세로→가로 전환, 더보기 → 완성 확인 →
  인쇄 미리보기의 연결을 확인했다. 홈 무대·책등·크기·부유와 리더의 책/넘김/컨트롤
  디자인은 변경하지 않았다.
- 위 경로의 주요 화면을 세로와 가로에서 각각 캡처해 버튼·목록·미리보기·안전 영역을
  비교했다. 모든 가능한 권한/네트워크/운영 주문 상태를 실행했다는 의미는 아니다.

### 실기기에서 발견해 보완한 부분

- 낮은 가로 화면에서 실제 Samsung 키보드가 열리면 제목 입력란이 지나치게 좁아졌다.
  가로 입력 중 단계 안내를 숨기고, 높이가 부족한 작업 공간은 입력에 집중한다.
  키보드를 닫으면 표지와 진행 버튼을 복원하며 입력/포커스/표지 선택 상태를 보존한다.
- 프레임 원본이 가로 상세/구매창에서 옆으로 늘어났다. 프레임 미리보기의 기준 캔버스를
  카탈로그와 같은 정사각형으로 고정했다. 편집 중 사진 프레임의 가변 비율은 변경하지 않는다.
- 가로 주문 필터의 `내 앨범 주문` 제목이 부자연스럽게 줄바꿈되어 `내 주문`으로 축약했다.
- 주문 준비로 이어지는 완성 확인창의 화면 너비 기반 글자 확대를 없애고, 제한 너비와
  스크롤 본문으로 작은 가로/큰 글자를 지원한다. 리더의 책 표면/넘김 배치는 그대로다.
- 완성 화면에 전달되던 요약 앨범에는 비율/표지 레이어가 빠져 정사각형이 세로 사진처럼
  보였다. 현재 읽던 규격·표지 레이어·재질을 미리보기용으로만 전달한다. 서버 저장은 없다.

  테스트 자료 기반 자동 검증을 실주문 검증으로 대신 표기하지 않는다.

  통과한 것으로 볼 수 없다. 실제 원본 접근과 판매 준비 상태의 별도 점검이 필요하다.
- 실제 구매/포인트 차감/AI 생성/결제/주문 제출/제작 요청은 수행하지 않았다.
  원본 실패나 미확정 판매가를 우회해 주문을 진행하지 않는다.

## 2026-10-15 마이 → 보관함·내 앨범 → 주문 확인 · 통합 개편

남은 세 묶음 중 **3번 개인 컬렉션/주문 여정**을 앱에 반영했다. 마이의 메뉴 나열을

묶음 모두 코드/네이티브 QA 단계에 도달했으며, 다음 종료 조건은 실기기 통합 확인과

## 우선 해결할 문제

### 1. 완성 확인 화면: 가로에서 안내와 버튼이 잘림

근거: `album_frozen_screen.dart`의 `_buildAlbumCard`는 앨범 인자를 사용하지

버튼을 스크롤 없는 `Column`에 쌓는다. 844×390에서는 아래로 **608px** 넘치는
배치 오류가 라이트/다크 양쪽에서 재현됐다.

- 실제 완성한 표지를 원래 비율로 보여 주고 FREEZE 배지/별빛/임시 모형을 제거.
- 가로는 표지와 완료 정보/작업을 나누고, 세로는 안전 영역 안의 자연스러운 완료 구성.
- ‘보관함으로’가 실제로는 이전 화면으로 복귀하는 경로임을 문구와 맞춤.
- 주문 결제 준비 중 안내는 유지. 완료 디자인만 바꾸어 주문 가능한 것처럼 보이지 않게 함.

### 2. 다크 대비: 알림 제목·마이 닉네임·잔액이 거의 안 보임

근거: `notification_screen.dart`의 제목/행과
`my_point_balance_card.dart:35`, `my_page_screen.dart`의 프로필 제목은
고정된 `ExperienceStyle.ink`를 쓴다. 화면 배경은 다크로 바뀌어 검정에 가까운
글자가 검정 바탕에 남는다. 새 캡처에서 확인했다.

- 화면 배경과 헤더, 제목, 요약, 구분선에 같은 테마 인식 규칙 적용.
- 사진/인쇄 종이/앨범 무대는 의도된 밝은 표면을 유지. 모든 흰색을 일괄 반전하지 않음.
- 알림 불러오기 실패에 재시도 추가. 읽음 처리나 알림 진입 계약은 유지.
- 문의/포인트/스토어 같은 흰색 고정 화면의 일부 아이콘·시트도 같은 기준으로 후속 점검.

### 3. 주문 상세: 저장된 책 규격과 다른 규격을 표시

근거: `order_history_screen.dart:423`은 주문 상품과 무관하게
`200×200mm 소프트커버`를 붙인다. 검토 주문의 저장된 규격은
`REDP_250X200_SOFT`, 250×200mm지만 상세에는 200×200mm가 나온다.

- `order.printProductLabel` 등 이미 있는 저장 스냅샷 기반 표시 사용.
- 규격을 모르면 모른다고 표시하며 임의의 정사각형으로 대체하지 않음.
- 상세 시트는 고정 글자 크기, 제한 너비, 충분한 높이와 스크롤로 구성.
- 결제/제작/배송/수령 정보를 그룹화하고 복사 버튼은 좁을 때 줄바꿈 허용.

## 구현 순서

1. 완성 확인 가로 배치, 알림/마이 다크 대비, 주문 상세 규격 표시를 먼저 수정.
2. 실제 앨범 중심의 완성 확인과 초대 화면을 정돈. 링크 준비/실패/권한을 함께 설계.
3. 인쇄 미리보기와 주문 상세를 책 중심·검수 중심 화면으로 구성.
4. 나의 기록/공유 목록과 작은 선택 시트를 현재 스타일로 통일.
5. 구매 확인/완료, 약관/문의, 접힌 마이 정보를 정돈. 포함 소재 재사용 정책은 서버와 함께 구현.
