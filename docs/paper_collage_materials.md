# Paper 콜라주 참고와 꾸밈 재료 연결

이 문서는 재료 공개 및 첫 펼침면 수정 시점의 기록이다. 현재 다시 디자인 중인 후보는 [겹쳐진 순간](paper_photo_diary_rebuild.md)을 참고한다. 아래의 공개 재료는 모두 유지한다.

2026-09-08. 사용자의 요청에 따라 지금까지 제작한 재료를 실제 편집기에 연결했다.
유료 후보 앨범의 출시는 별개이며 `luminous-edition`은 여전히 미출시 디자인 연구다.

## 실제 사용 경로

- 표지/내지 편집 → 스티커 → 새 컬렉션: 오브젝트 콜라주, 그래픽 페이퍼, 빛나는 스크랩북 컬렉션을 추가했다. 종이·스티커·테이프 분류에서도 동일한 재료를 찾는다.
- 신규 공개 재료 23종: zine 13종 + luminous 10종. 기존 21종을 유지하여 스튜디오 재료는 총 44종이다. 예전 장식 탭은 그대로 둔다.
- 사진 선택 → 프레임 → 스튜디오: zine 3종 + edition 6종, 총 9종을 추가했다. 저장된 프레임 키와 사진 크롭을 바꾸지 않는다.
- 스티커 → 꾸민 문구: 볼드 컷아웃, 티켓 라벨, 손글씨 밑줄, 겹인쇄 스티커, 리본 문구, 레이스 메달 문구, 아웃라인 명조 7종.
- 문구는 종이와 텍스트를 각각 수정 가능한 레이어로 삽입한다. 하나의 이미지로 합치지 않는다. 삽입 1회가 실행 취소 1회이며, 이후 글자·종이는 각각 이동/크기 변경/삭제할 수 있다. 묶음 변형 기능을 새로 구현한 것은 아니다.
- 즐겨찾기는 미리보기와 실제 선택기에서 같은 키를 쓰고 최근 즐겨찾기가 먼저 나온다. 별표를 누르는 동작은 재료 삽입이나 구매를 실행하지 않는다.
- 기존 상품 접근 확인을 모두 유지한다. 이 변경은 관리자 상품 선택 목록에 식별자를 추가할 뿐, 서버에 가격·상품·구매를 쓰지 않는다. 실제 가격/소유권은 기존 서버 정책을 따른다.

## 참고 작업에서 확인한 것

요청한 Pinterest 검색은 이 환경에서 열리지 않아, 공개된 Paper 사용자 게시물을 대신 확인했다.

[menguiny의 Paper 스크랩북](https://www.lemon8-app.com/@menguiny/7417926513725751813?region=us)의 3번째 이미지에서 사진 중심의 촘촘한 콜라주를 확인했다. 큰 사진과 작은 카페 사진, 사진부스 스트립, 작은 손글씨가 겹쳐 있다. 작성자의 사진이나 장식을 내려받아 제품 재료로 사용하지 않았다.

[WeTransfer의 Paper Collage 소개](https://medium.com/wetransfer/paper-unlocks-creative-expression-with-collage-8f1bf498a467)도 여러 이미지를 오리고 겹쳐 구성하는 방향의 참고 자료다.

이를 바탕으로 세운 디자인 기준:

1. 사진이 주인공이다. 큰 제목이 한 면의 1/3을 차지하는 포스터 구성을 반복하지 않는다.
2. 큰 인화 사진, 세로 스트립, 작은 사물 사진의 크기 차이로 밀도를 만든다.
3. 테이프는 사진 가장자리에, 메모는 날짜나 장소처럼 맥락이 있는 곳에 놓는다.
4. 모든 스티커를 한 면에 모으지 않는다. 한 펼침면 안에서 재료의 색과 역할이 연결되어야 한다.
5. 얼굴과 핵심 문구가 가려지지 않는 겹침, 인쇄 규격별 여백, 사진 교체 뒤에도 유지되는 마스크가 필요하다.

## 이번 시안 반영 범위

기존 URL/컬렉션을 유지하고 첫 펼침면(1–2쪽)을 수정했다. 면마다 사진을 2장에서 5장으로 늘리고, 세 칸의 세로 사진 스트립과 겹친 인화지를 구성했다. 제목은 하단의 짧은 문구로 줄였다. 장식은 기존에 직접 제작한 재료, 사진은 프로젝트의 기존 예시 에셋을 사용한다.

표지와 다른 4개 내지는 이번 사진 중심 구성을 검토하기 위한 비교 대상으로 유지한다. 전체를 Paper 스타일로 재설계했다고 주장하지 않는다. 무료 37종과 무료 전환 앨범은 변경하지 않았다.

## 검증 범위

- 실제 `DecoratePanel` → `AlbumEditorViewModel` 삽입: 세로/가로, 이미지 스티커와 꾸민 문구, 접근 확인, 즐겨찾기, 실행 취소.
- 7종 문구 × 3가지 앨범 비율: 텍스트 범위, 레이어 ID, 저장 복원, 글자 수정, 실행 취소/다시 실행.
- 편집기와 저장 미리보기에서 문구가 종이 위에 같은 위치로 그려지는지 확인.
- 새 재료를 포함한 스티커/프레임 선택기와 실제 렌더링 비교, 기존 즐겨찾기/접근 확인 회귀 테스트.
- 후보 7면과 무료 완성본 25면의 세 규격 범위/텍스트 충돌/저장 복원 테스트.

서버 구매나 실제 인쇄 주문은 실행하지 않았다. 기기 설치 검증과 인쇄 실물 색상/질감 검수는 별도다.
