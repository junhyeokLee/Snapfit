# 생활 컨셉 4종 내지 재설계

> 아래 내용은 editorial-life-2 보관본이다. 이후 '같이 사는 계절'만
> [종이와 문구 조화 재설계](shared_seasons_paper_refinement.md)로 다시 수정했다.
> 나머지 3종은 이 버전을 유지한다.

2026-09-10. 장식 종류만 늘린 수정본이 무료 템플릿처럼 보인다는 사용자 피드백에
따라 내지 구조까지 바꾼다. 같은 미리보기와 컬렉션 ID를 유지한다.
디자인 차별화를 위한 검토본이며 유료 가치가 입증되었거나 판매 승인을 받았다는 뜻은 아니다.

## 바뀐 방향

| 컬렉션 | 시각 언어 | 펼침면 구성 |
| --- | --- | --- |
| 같이 사는 계절 | 자주색 제본 면, 라일락 메모, 초록 식탁 | 집의 첫 장, 장보기 전표, 단골 카페의 두 자리, 사진이 붙은 편지 |
| 너의 작은 옷장 | 블루 코튼, 봉제선, 버터색 기록 면 | 옷장 목록, 손 사진과 기록지, 성장 치수, 첫해의 보관물 |
| 일요일의 피크닉 | 짙은 초록, 자연스러운 붉은 포인트, 메뉴 인쇄물 | 초대장, 준비 목록, 도시락 메뉴, 단체사진, 가져온 기억 |
| 작은 동거인 | 청록, 코발트 놀이 면, 옅은 노랑 색인 | 입주 소개, 프로필 카드, 장난감 표본, 창가 관찰, 생활 습관 |

표지의 큰 사진과 제목은 그대로 둔다. 각 권 24쪽, 총 내지 96쪽을 다시 조판했다.
색만 바꾸는 공통 페이지 생성기는 쓰지 않고 각 지면을 별도로 작성한다.
큰 사진 면, 타이포가 주인공인 면, 기록지·사진이 겹치는 면을 섞어 밀도 차이를 만든다.
여러 사진을 작은 사각형으로 나누는 것이 맥시멀 디자인을 대신하지 않도록 한다.

## 구현

- 서로 다른 판지색, 이중 테두리, 분리된 캡션 띠로 사진 보드를 조합했다.
  구조를 구성하는 사각형·사진·글씨는 각각 편집 가능한 네이티브 레이어이다.
- 봉제선은 독립 도형, 기록 목록은 텍스트와 줄, 사진 위 문구는 불투명 종이와
  텍스트 레이어로 구성한다. 사진이 바뀌어도 라벨 글씨의 대비를 유지한다.
- 의도한 사진/문구 겹침만 `photoOverlayTextIds`에 명시한다.
  일반 텍스트/사진 충돌 검사는 유지하고, 허용한 문구 바로 아래에 불투명 종이가
  있는지 별도로 검증한다.
- 문구용 종이는 실제 비율로 배치한 사각형을 반환한다. 집게를 그 모서리에 붙여
  정사각형·세로·가로 규격에서 떨어져 보이지 않게 한다.
- 이전에 만든 재료 12종과 즐겨찾기·저장·출력 연결은 유지한다.
  기존 장식의 권당 2회 제한도 유지한다. 이번에는 재료 가격을 바꾸지 않는다.
- 새 문서/미리보기의 내용 리비전만 2로 올린다. 기존 승인 3종은 1을 유지한다.

## 보존과 검증

바로 전 수정본의 4종 x 3규격 문서를
`tool/template_studio/archives/life-material-variety`에 보존했다.
기존 `life-before-material-variety` 보관본도 지우지 않는다.
이번 사용자 요청에 따라 '내지 배치 동일' 검사를 '표지·목차·쪽 연결 보존 및 내지
사진 구성 재설계' 검사로 바꿨다. 무의미하게 예전 레이아웃을 고정하지 않는다.

- 실제 사진 배치가 바뀐 내지: 성장 20쪽, 피크닉 22쪽, 커플 22쪽, 반려 21쪽.
  사진이 없는 기록 지면도 별도로 재설계했다.
- 관련 디자인·꾸미기·가격 회귀 테스트 229개 통과.
- 마지막 집게/테이프 보정 후 문서·레이아웃·원본 보존 테스트 26개 재통과.
- 525쪽의 세 규격 렌더, 글씨 높이, 사진/글씨 충돌, 재료 비율, 사진 교체,
  저장 복원, 기존 승인 3종과 무료 스토어 37종 보존을 확인했다.
- 검수 문서/이미지: `output/template-preview/concept-wave`.
- 관련 Dart 파일 9개 정적 분석과 포맷 검사 통과, 최종 릴리스 웹 빌드 성공.
- Playwright: 390x844, 844x390, 1440x900에서 7종 x 3화면, 총 21개 조합 통과.
  표지·첫/중간/마지막 펼침면, 제목 변경, 사진 숨김/복원, 즐겨찾기, 목록 이동을 확인했다.
  총 105개 화면을 촬영했고 페이지 오류, 누락 자산, 외부 AI/구매 API 요청이 없었다.
  실제 웹 화면에서도 새 조판을 확인했다.
  결과: `output/template-preview/concept-wave/browser/report.json`.

인쇄 교정, 이미지·폰트의 배포 권리 검수, 디자인 승인, 유료 판매 활성화는 별도다.
운영 DB, 실제 구매, 포인트 차감, 무료 카탈로그를 변경하지 않았다.
