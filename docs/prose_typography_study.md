# 함께여서 좋은 날: 타이포그래피 승인 시안

**현재 결정:** 사용자의 후속 지시에 따라 표지 + 내지 24쪽 무료 컬렉션으로 전환했다.
[무료 완성판과 새 후보 기록](prose_free_and_luminous_candidate.md)을 우선한다.
아래 승인 대기·무료 36종 등의 내용은 이전 차수의 이력이다.

제작일: 2026-09-08. 표지 1안 + 내지 6쪽(대표 펼침 3개).
기존 무료 36종을 유지하며, 이 시안은 공개 상품 목록이나 유료 상품에 등록하지 않는다.

## 3차 수정: 문구와 사진 프레임

사용자가 표지 제목과 4·6쪽 원고에 아쉬움을 표했다. 같은 주소와 문서 ID를 유지한다.

- 표제는 **함께여서 좋은 날**. 패턴을 채운 수정 가능한 텍스트를 유지한다.
- 4쪽 **나란히 앉은 오후**: 큰 약속문 대신 인물 사진과 반지 사진을 한 쌍으로 배치한다.
  기본 기록은 "나란히 앉아, / 별것 아닌 이야기로 / 오래 웃었던 오후."다.
- 6쪽 **다음에도, 이렇게.**: 큰 장식 글자를 없애고 사진을 주인공으로 두었다.
  가로 규격에서는 사진과 문구를 좌우로, 다른 규격에서는 위아래로 조판한다.
- 사진용 새 매트 3종: 이중 선과 절단면이 있는 아치 창, 아래 여백이 두꺼운 비대칭
  플로팅 매트, 안쪽 모서리를 잘라낸 매트. 사진을 덮는 광택이나 검은 코너는 쓰지 않는다.
- 매트 여백과 선 두께는 레이어의 짧은 변에 비례한다. 앱 편집기와 프리뷰가
  `StudyPhotoFrame`을 공유하며, 사진은 교체 가능한 별도 레이어다.
- 새 프레임은 시안 문서에서만 사용한다. 공개 프레임 선택기나 무료 36종을 바꾸지 않는다.
- 4쪽 기록과 6쪽 마무리를 각각 편집할 수 있다. 전체 문구를 세 규격에서 검사해
  넘치는 상태로 적용하지 않는다.

3차 프레임은 Flutter로 직접 그린 벡터 구성이다. 이 차수에서 생성 이미지를 추가하지 않았다.
아래 1·2차 내용은 제작 이력이며 현재 구성은 이 절을 우선한다. 여전히 시각적 승인 대기이고,
유료 출시나 경쟁사보다 높은 품질이 검증된 상태로 표기하지 않는다.

3차 검증: 관련 Flutter 테스트 106개 통과, 변경 Dart 파일 분석 오류 없음.
새 매트 3종을 세로·가로 레이어에 적용해 실제 편집기와 프리뷰의 픽셀 일치를 확인했다.
매트 비율·윤곽 확대, 프레임 변경·사진 교체·되돌리기·저장 왕복과 무료 36종 유지도 검사했다.
Chrome 390×844, 844×390, 1440×900에서 표지 세 규격, 내지 펼침, 4·6쪽 표시와 문구 편집,
비교·확대·사진 숨김·최근 즐겨찾기·보존을 확인했다. 페이지·리소스 오류와 외부 AI API 호출은 없었다.
네이티브 실기기와 실물 인쇄는 이번 검수에 포함되지 않았다.

## 2차 수정: 무료와 구별되는가

사용자가 1차 시안은 무료와 충분히 다르지 않다고 평가했다. 1차안은 유료 승인에
도달하지 못한 것으로 기록한다. 같은 `our-prose` 주소에서 구성을 다시 작업했다.

- 새 목판화풍 면지와 짙은 글자용 패턴을 분리했다. 밝은 장식 때문에 글자의 획이
  사라져 보이지 않도록 글자용 이미지는 어두운 잉크색으로 제작했다.
- 표지, 장의 시작, 마지막 헌사에 수정 가능한 패턴 채움 글자를 적용했다.
  별도 글꼴을 새로 그린 작업은 아니며 기존 북크명조의 네이티브 텍스트다.
- 첫 펼침은 작은 장면·장 번호·문구와 아치형 사진으로 구성했다.
- 두 번째 펼침은 여러 사진을 수집한 구성과 이름·날짜가 들어간 약속문이다.
- 마지막 펼침은 줄 간격에 맞춘 편지지와 사진·헌사를 함께 배치했다.
- 앱의 이미지 채움 글자와 프리뷰가 같은 중앙 크롭을 쓰도록 공용 셰이더를 수정했다.
- 패턴용 스티커의 `rasterCover`만 영역을 채운다. 기존 스티커는 contain을 유지한다.

하단의 **무료와 비교**에서 `빛으로 엮은 우리`와 나란히 볼 수 있다. 내지 비교에는
같은 사진 묶음을 배정하며, 각 템플릿의 사진 칸 수는 유지한다. 표지는 사진형과
문자형 각각의 구성을 그대로 비교한다. 사진 숨김·세 규격·펼침 확대를 지원한다.
비교 화면은 기본 문구를 쓰며, 읽기 전용이다. 비교를 닫아도 편집하던 시안은 유지된다.

2차안 역시 승인 대기다. 장식과 구성 차이는 만들었지만 그것만으로 사용자가
지불할 가치나 경쟁 우위를 입증한 것은 아니다. 공개 무료 템플릿의 품질·혜택은 낮추지 않는다.

2차 검증: 관련 Flutter 테스트 134개 통과. 이후 긴 제목의 크기 대응을 추가하고
시안 테스트 11개를 재검증했다. Chrome 세 화면 크기에서 비교·확대·사진 숨김,
문구 편집·취소·즐겨찾기를 확인했다. 글자용 PNG의 종이색 대비 최솟값은 약 4.75:1이며,
이를 앱 전체의 접근성 인증이나 인쇄 검증으로 간주하지 않는다.

## 시각 방향

독자는 커플·기념일 앨범을 직접 쓰는 사람이다. 책·문장을 빗대는 표현 대신
같이 보낸 장면과 짧은 기록으로 말한다.
패턴 표제, 장면을 여는 문장, 사진을 모은 기록, 사진 곁의 기록, 편지, 사진으로 마무리한 인사의
6가지 조판을 설계했다. 큰 사진이 있는 페이지를 사이에 두어 밀도를 조절한다.

- 북크명조 Bold: 표제 핵심 단어, 장의 시작, 강조 단어, 편지 제목.
- 을유1945: 표제 윗줄, 약속의 문장, 편지 본문과 작은 헌사.
- Noto Sans: 사진 캡션과 기록. Cormorant Garamond: 인용부호와 장 번호.
- 장식: 새로 생성한 목판화풍 패턴 2종. 문자는 이미지에 포함하지 않는다.
- 색: 먹빛 청록, 진한 자주, 차가운 하늘색, 종이색.
- 가로형의 사진·헌사는 좌우 구성으로 다시 조판한다. 세로형을 납작하게 압축하지 않는다.

## 실제 연결한 범위

`lib/core/templates/authored_prose_study.dart`는 네이티브 `LayerModel`로 해석되는
편집 가능한 원본 문서를 생성한다. 기존 완성 템플릿의 페이지 구성을 복제하지 않았다.
사진과 문자는 별도 레이어이고, 원본 내보내기·다시 읽기의 보존을 테스트한다.

프리뷰: `http://127.0.0.1:4323/?collection=our-prose#/our-prose`

- 표제 윗줄, 강조 단어, 이름, 날짜, 4쪽 기록, 편지, 6쪽 마무리를 수정할 수 있다.
- 세 규격의 실제 글자 높이를 검사해 넘치는 문구는 적용 전에 차단한다.
- 문구 조판 갤러리는 기본 원문의 참고 6안이다. 선택하면 해당 책 페이지로 이동한다.
- 갤러리 방문과 규격 변경 후에도 현재 세션의 수정 문구를 보존한다.
- 즐겨찾기는 기기 로컬 저장이며 최근에 추가한 항목이 먼저 나온다.
- 즐겨찾기와 시안 문구는 별개다. 문구는 앱을 다시 열 때 영구 복원되지 않는다.
- 앱의 공용 문구 프리셋 목록에 6안을 배포하거나 결제를 연결한 단계는 아니다.

## 제작 기록과 검수

1차 그림: `assets/templates/prose_study/botanical_cartouche.png` (기록 보존, 현재 조판에는 미사용).
2차 그림: `assets/templates/prose_study/woodcut_endpaper.png`,
`assets/templates/prose_study/woodcut_ink.png`.
내장 image_gen으로 생성했으며 전체 생성 프롬프트와 원본 경로는 같은 폴더의
`provenance.json`에 기록했다. 사진은 기존 프로젝트의 시연용 사진이다.
앨범의 글·레이아웃은 별도로 작성했으므로 전체 템플릿을 AI 자동생성 결과라고 표기하지 않는다.

자동 검수: 세 규격의 실제 렌더링, 글자 영역·충돌·제본 여백, 편집 가능한 저장 왕복,
문구 입력 검사, 가로·세로 UI의 편집 보존과 갤러리·즐겨찾기 동작.
렌더 결과는 `output/template-preview/prose-study/`, 브라우저 결과는 그 아래 `browser/`.

1차 검증 결과: 관련 Flutter 테스트 96개 통과, 변경한 Dart 파일 분석 오류 없음.
Chrome 390×844, 844×390, 1440×900에서 세 규격·세 펼침, 문구 적용/취소/초과 차단,
갤러리 이동·최근 즐겨찾기·새로고침 후 즐겨찾기 보존을 확인했다.
검증 중 페이지 오류·리소스 HTTP 오류·외부 AI API 호출은 없었다.
1차 장식 원본은 1254×1254 PNG이며 투명 픽셀은 약 54.5%다. 최종 인쇄 해상도 보증은 아니다.

아직 필요한 검수: 사용자의 시각적 승인, 실제 사용자 사진으로 교체한 인쇄 결과,
새 원고 전체의 편집, 실물 교정쇄, 소재·폰트의 상품 배포 권리 점검,
앱의 실제 기기에서 사진 교체·저장·되돌리기 검수.
브라우저와 자동 테스트 통과를 인쇄 품질이나 경쟁사 대비 우위로 간주하지 않는다.

승인 후 이 조판을 기준으로 전체 앨범 원고와 변형을 확장한다. 승인 전에는
장수나 장식을 늘려 유료 완성을 선언하지 않는다.
