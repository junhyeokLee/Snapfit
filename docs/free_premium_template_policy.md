# SnapFit 무료·유료 템플릿 소재 규칙

기준: 2026-10-07. 이 문서는 운영 DB 적용이나 구매 권한 부여 기록이 아니다.

## 무료 템플릿

- 완성 템플릿 37종은 무료를 유지한다. 표지 스타일의 단순함 여부로 무료를 구분하지 않는다.
- 사진이 표지 전체를 채우는 디자인도 무료로 제공한다. 이번에는 7개 주제에 8종을 배치했다.
- 프레임·스티커·종이·문구 구성은 명시적으로 무료 승인된 재료만 사용한다.
- 기본 소재 40종을 무료 목록으로 고정했다. 현재 37종에 사용된 상품 소재는 그중 28종이다.
- 소재 가격이 미정이거나 목록에 없는 경우 무료로 추정하지 않는다. 제작·등록 검증에서 차단한다.
- 프레임이 포함하는 별도 장식도 함께 검사한다. 유료 장식을 일반 사진 레이어로 바꿔 넣어도 차단한다.
- 기본 사진 음영·단색 면·편집 가능한 기본 글자는 구매 상품이 아니다. 기존 무료 컬렉션 전용 그림 4개는 정확한 파일 경로로 승인한다.
- 샘플 사진은 미리보기용이다. 앨범 제작 시 사진 슬롯은 비워지며 사용자가 자신의 사진을 넣는다.

## 유료 템플릿

- 기존 유료 컬렉션의 분류·가격·소재는 그대로 유지한다. 이번 작업에서 유료 소재를 무료로 전환하지 않았다.
- 유료의 차별점은 독립적인 컨셉, 정교한 문구 조판, 특별한 프레임 구조, 장식 조합과 책 전체의 완성도다.
- 무료 표지를 일부러 작게 만들거나 품질을 떨어뜨리는 방식으로 차별화하지 않는다.
- 무료·유료 소재를 함께 사용할 수 있지만 사용한 소재의 종류와 권한은 구매 전에 안내한다.
- 템플릿 문서에 소재가 있다는 사실만으로 그 소재의 독립 사용 권한을 부여하지 않는다. 번들 구매 권한은 서버가 승인한 구성표와 결제 결과로 확인한다.

## 유지·검증

- `freeTemplateMaterialProductKeys`가 무료 상품 소재의 기준이다. 출시 가격표와 관리 화면에서 해당 키를 0P로 유지한다.
- 무료 소재를 유료로 바꾸려면 기존 키의 가격을 바꾸는 대신 새 유료 소재와 새 키를 만든다.
- `AuthoredCollection.document` 및 무료 확장 템플릿 생성에서 소재 규칙을 검사한다. 세 규격과 문서의 모든 변형도 검사한다.
- 사용자에게 이미 저장된 앨범 문서나 기존 구매 내역은 이 규칙으로 변경하지 않는다.
- 무료 등록용 출력 파일은 무료 템플릿 37종과 무료 소재 40종만 대상으로 한다. 유료 가격·지갑·구매 내역은 변경하지 않는다.
- 등록 시 운영 서버에 해당 키가 이미 유료로 등록되어 있으면 자동으로 가격을 내리지 않고 전체 적용을 중단한다. 소재 분류 충돌을 먼저 검토한다.
- 이번 연결에서 SnapFit 운영 프로젝트가 조회되지 않아 운영 DB 적용은 실행하지 않았다. `output/pricing/free-policy-2026-10-07/`는 검증된 적용 준비 파일이다.
