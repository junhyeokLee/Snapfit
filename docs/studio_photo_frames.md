# 스튜디오 사진 프레임

2026-09-07. 로컬 제작 템플릿과 실제 편집기에 적용. 유료 상품 게시 아님.

## 추가한 8종

| --- | --- | --- |
| 캡슐 컷 | studioCapsule | 양 끝이 둥근 외곽. 작은 정물이나 세로 인물 |
| 대각 라운드 | studioDiagonal | 대각의 두 모서리만 크게 둥글림. 사진 콜라주 |

| 수제지 프레임 | studioDeckle | 미세한 불규칙 외곽과 무광 섬유. 웨딩 정물과 편지 |

기존 스튜디오 6종과 합쳐 14종이다. 기존 원형, 하트, 폴라로이드 등도
지우지 않는다. 종이 테두리는 아이콘이나 플랫폼 글리프가 아닌 동일한
Flutter 클리핑/페인팅 코드로 그린다. 다른 종이와 스티커를 복제한 신규
소재라고 주장하지 않으며 이번 작업에 추가 이미지 생성/API 호출은 없다.

## 편집 동작

- 스튜디오 프레임은 현재 사진 영역의 크기, 회전, 위치를 유지한다.
  기존 편집 서비스의 일괄 3:4 변환에서 분리했다. 레거시 프레임의 크기 규칙은 유지한다.
- 선택창은 선택한 실제 사진과 현재 크롭 위치를 사용한다. 빈 슬롯에는
  기존 번들 샘플 사진을 사용하며 샘플이 앨범에 삽입되지는 않는다.
- 프레임 선택은 기존 편집기 히스토리를 사용한다. 선택창 취소 시 변경하지 않는다.
- 사진 교체 후 프레임이 남고, 저장 매퍼에 사진 위치를 슬롯 대비 비율로
  보존한다. 새 `payload.imageOffsetRatio`가 없는 구 문서는 기존 중앙 정렬을 유지한다.
- 홈/읽기 화면의 페이지 전환이나 앨범 디자인은 수정하지 않았다.

## 컬렉션 적용

3개 무료 컬렉션의 10개 사진 슬롯에 선택적으로 적용했으며 세 규격에 반영했다.
각 컬렉션의 표지 + 내지 20쪽 구성, ID, 무료 조건은 그대로다.

- 꽃처럼 피어난 날: 대각 라운드, 캡슐, 갤러리 매트, 수제지.
- 낯선 곳의 조각들: 티켓, 필름, 갤러리 매트.
- 좋아하는 순간들: 물결, 인화지, 대각 라운드.

프레임 종류가 많다는 이유로 모든 사진에 외곽 효과를 넣지 않는다. 얼굴과
손이 가장자리에 있는 사진에는 기본 사각형이나 갤러리 매트를 우선 사용하고,
티켓과 물결은 중요한 피사체가 홈에 걸리지 않는지 실제 크롭으로 확인한다.

## 미리보기와 검증

`http://127.0.0.1:4323/?frames=true` 또는 기존 미리보기의 사진 프레임 아이콘.
세로/정사각/가로, 사진 3장, 배경 3색을 바꾸어 비교한다. 이 개발용 화면의
실행 취소와 다시 실행은 프레임 비교용이며 앨범을 저장하지 않는다.
실제 앱의 프레임 선택창도 이 화면에서 열어 볼 수 있다.

```sh
flutter test test/widget/studio_photo_frames_test.dart test/design/authored_collections_test.dart
flutter test test/unit/album_editor_view_model_test.dart test/unit/layer_export_mapper_test.dart
node tool/template_studio/verify_frames.cjs
```

검사 범위: 경로 경계/비율 유지, 투명 천공, 무광 종이, 편집기/카탈로그 픽셀
일치, 사진 교체, 저장 매퍼, 실행 취소/다시 실행, 선택창 작은 화면/가로 화면.
운영 API의 추가 필드 보존, 실물 인쇄, 실제 기기 갤러리와 크롭 제스처,
여러 사람의 실제 사진을 이용한 미감 평가는 별도 출시 검수 대상이다.

새 유료 컬렉션은 `premium_template_release_plan.md`의 독립 아트디렉션,
인쇄와 권리 검수, 결제 준비를 거친다. 프레임 추가만으로 유료 완성도나
경쟁 제품 대비 우월성을 통과했다고 판정하지 않는다.
