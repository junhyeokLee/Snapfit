# 읽기 화면: 한 페이지 초점과 실제 펼침

사용자가 `album-spread-turn.html`의 실제 펼침·카메라 이동 방식을 승인했다.
세로 화면에서 앨범 한 장을 크게 보되 책의 왼쪽·오른쪽과 앞뒷면 관계를 유지한다.

- 저장된 정사각형, 4:3, 5:4 비율과 레거시 문서 비율을 변경하지 않는다.
- 표지는 앱 페이지 0, 내지 홀수는 왼쪽, 짝수는 오른쪽이다.
- 같은 펼침의 왼쪽→오른쪽은 카메라 이동이다. 오른쪽→다음 왼쪽은 실제 종이 넘김이다.
- 종이의 앞면 2와 뒷면 3이 같은 장이며 완료하면 3이 왼쪽에 놓인다. 역방향도 대칭이다.
- 드래그는 손을 따르고 취소하면 원래 페이지와 카메라 위치로 돌아온다.
- 세로는 한 장과 이웃 장의 작은 단서, 가로는 전체 펼침을 표시한다.
- 하단은 이전·현재 쪽·다음과 필요할 때 여는 페이지 목록으로 간소화한다.
- 편집·협업 메뉴 접근, 페이지 ID 기반 편집 복귀, 상세 보기, 표지 열기와 닫기,
  이미지 준비·캐시·렌더러 해제, 접근성의 모션 감소 동작을 보존한다.
- 전체 앱 빌드·설치·상시 서버 없이 실제 위젯 테스트와 원본 에셋 캡처로 검증한다.

구현 경계: 기존 BookFlip의 종이 매핑·메시·텍스처 생성은 유지한다. 뷰에 명시적
`singlePageFocus` 옵션과 카메라 전환 상태를 추가하고 실제 모바일 세로 리더에서 켠다.

검수 기준: 페이지 번호뿐 아니라 실제 제본선 위치, 렌더러 크기, 페이지 비율,
앞뒷면 매핑, 같은 펼침에서 엔진이 넘어가지 않는 동작을 확인한다. 마지막 왼쪽 한 장,
표지만 있는 책, 회전·페이지 선택·편집 복귀 중 전환 중단도 확인한다.
