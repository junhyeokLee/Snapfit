# 승인한 종이 넘김을 실제 읽기 화면에 적용

사용자가 이전 결과 영상이 승인한 `album-spread-turn.html`과 다르다고 지적했다.
이전 작업은 페이지의 좌우 관계와 카메라만 옮겼다. 이번 작업은 원본 종이 변형·투영·
그림자·시간 곡선을 그대로 옮긴다. 기존 엔진을 보존한다는 이전 구현 경계는 이 요청으로 갱신한다.

- 기준 원본: `/Users/devsheep/SnapFit/album-spread-turn.html`의 `leafVertices`, `drawLeaf`, `animate`.
- 종이: 40개 조각의 중점 적분. 회전 `pi*p + .28*sin(pi*p)*s^1.4`.
- 투영: 거리 `12*페이지폭`, 원근 효과에 `sin(pi*p)`를 곱한다. 역방향은 같은 경로를 역재생한다.
- 앞뒷면: 원본의 조각별 평균 각도로 선택한다. 글자가 거울상으로 바뀌지 않는다.
- 그림자: 바깥쪽 끝 ±34px, 원본 색상과 조각별 음영을 사용한다. 기존 강한 조명·굴곡은 섞지 않는다.
- 시간: 전체 500ms의 easeOutCubic. 일부 진행 후 정착은 `330 + 남은 진행량*170`ms.
- 손동작: 진행량은 이동 거리/(폭*.85), 완료 기준은 원본의 .38 또는 .08+600px/s다.
- 세로 한 쪽/가로 전체 펼침, 기존 저장 비율·편집/상세 복귀·권한·이미지 수명은 보존한다.
- 새 원본 프로파일은 실제 읽기 화면의 내지와 표지 열기·닫기에 선택한다.
  표지의 앞면은 표지, 뒷면은 첫 내지이며 닫기는 같은 종이를 반대로 재생한다.
  일반 material 프로파일을 사용하는 다른 화면의 효과는 유지한다.
- 하단 쪽 목록은 항상 펼치고 ‘전체 쪽’ 열기·닫기 버튼은 없앤다. 현재/전체 쪽수는
  표지에서도 계속 표시한다.

완료 기준: 원본 JS를 직접 실행한 좌표 fixture와 실제 Flutter 렌더 메시를 비교한다.
순·역방향, 0/25/50/75/100%를 같은 페이지 비트맵으로 비교하고 실제 넘김 영상도 확인한다.
페이지 번호·펼침·수명 테스트 통과만으로 시각적 일치를 주장하지 않는다.
