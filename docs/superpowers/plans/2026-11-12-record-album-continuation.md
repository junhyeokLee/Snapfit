# 기록에서 월간 앨범으로 이어지는 흐름 구현 계획

**목표:** 누적 사진 수와 무관하게 월간 앨범 실행에 접근하고, 저장 완료 안내가 확인한 데이터만 설명하도록 한다.
**구조:** Flutter/Riverpod 기존 월간 미리보기와 저장 완료 화면을 수정한다. 기존 제작·추가·공유 함수와 저장소를 유지한다.
**설계:** [범위와 선택](../specs/2026-11-12-record-album-continuation-design.md)
**승인 범위:** 사용자의 전체 점검·실제 개선 지속 요청. 기존 화면의 작은 개선이며 별도 제작 단계를 추가하지 않는다.

## 작업

- [x] 현재 직접 작성 저장 경로와 사진 36장 월간 미리보기를 캡처·측정한다. 최초 로딩/상단 누락 캡처는 제외한다.
- [x] `moments_reward_flow_test.dart`에 선택 중 만들기 접근·기존 앨범 행동/오류 복구 검사 3개를 추가하고 현재 코드의 실패를 확인한다.
- [x] `moment_draft_entry_navigation_test.dart`에 직접 저장 후 첫 장/월 합계를 단정하지 않는 실패 검사를 추가한다. 저장 전 서버 날짜 조회 1회는 유지한다.
- [x] `monthly_moment_preview_screen.dart`의 기존 행동을 하단 영역으로 이동한다. 선택 수·비공개 상태·오류·생성 결과를 함께 보여 준다. 실제 액션과 활성 조건은 그대로 재사용한다.
- [x] `moment_saved_preview_screen.dart`에 전체 월 데이터 여부를 전달하고 `moments_navigation.dart`의 직접 작성과 `moments_screen.dart`의 월 데이터 없는 복구를 불완전 상태로 명시한다. 폰트 준비 생성자에도 전달한다.
- [x] 관련 테스트와 변경 파일 분석, 전후 네이티브 캡처, 독립 검토를 완료한다. 임시 컴파일 결과를 다시 삭제한다.

## 검토 초점

작은 화면의 큰 글씨/키보드, 선택 0장과 9장, 제작 중 비활성·실패 후 복구, 기존 앨범 표지/쪽 보존, 계정 전환 시 행동 차단, 전체 월 데이터가 있는 기존 안내 보존.

독립 검토의 키보드 가림과 임시 복구 경로 누락도 각각 실패 테스트(1건/2건)로 확인한 뒤 수정했다.

최종 근거: [전후 화면·검증](../../verification/record-next-audit-2026-11-12/README.md). 기능 100건 및 사진 프레임 회귀 1건 통과, 오류·경고 0(기존 스타일 info2), 독립 검토 보완 완료.
