# Album Settings Implementation Plan

> **For agentic workers:** Root coordinates the settings view and serial native checks; bounded picker/test tasks may be delegated. Preserve the existing Flutter project and all business callbacks.

**Goal:** 승인된 2번 설정 화면에 단일 아코디언, 업체 커버 사진·설명, 작은 주문 안내를 반영한다.

**Architecture:** `AlbumCreateStep1`이 펼침 상태와 기존 이름 컨트롤러를 소유한다. 기존 `CreationWorkspace`의 동일 subtree·회전·포커스 복원과 부모 콜백을 유지한다. 크기 선택기는 compact 옵션만 추가하고 다른 사용처는 기본값을 보존한다. 사진은 공식 커버 선택 이미지 두 개를 그대로 번들에 포함한다.

**Tech Stack:** Flutter, existing widgets/theme/callbacks; no new dependency or backend change.

**Spec:** `docs/album-settings-design-review-2026-11-11.md`; 선택 2번과 사용자의 커버 설명/업체 사진 요청, 최종 `응 진행해줘` 승인.

## Global Constraints

- 시각 기준은 선택 2번과 공급업체 사진 반영 최종 시안 `exec-89eedb83-2a00-48eb-b57b-1aedba7014df.png`다.
- 소프트: `유연한 종이 표지` / `일반 책·잡지 같은 형태`; 하드: `단단한 보드 표지` / `오래 간직하기 좋은 형태`.
- 작은 회색 `앨범 주문 시 적용`; 큰 안내·`실물` UI 문구·대각선 화살표 없음.
- 이름 50자·공백 진행 차단, 표지 문구와 구분. 기존 한글 입력·포커스·복원 보존.
- 공식 크기 5종 전체, 소프트/하드 구분과 현재 제한 크기 비활성 유지. 커버 종류 변경으로 사진/크기를 초기화하지 않음.
- 내지 표지 별도 20~80쪽·2쪽 단위, 템플릿 최소 수량·초과 차단과 추가 빈 페이지 안내 유지.
- 직접 만들기 다음 `표지 만들기`, 템플릿 다음 `사진 채우기`. 임시 저장·계정 보호·부모 데이터 로직은 변경하지 않음.
- 실제 미리보기는 현재 문서·서체·표지 글·사진 상태를 반영. 예시 사진을 사용자 사진인 것처럼 표시하지 않음.
- 320/390px·가로·다크·200% 글자·48px 터치·원본 이미지 비율 보존.
- 앱 전체 빌드·상시 서버·운영 배포·DB 변경·커밋 없음. 무거운 테스트/렌더/분석은 직렬로 하나씩 수행.

## Review Focus

- 접힌 이름/쪽수 입력이 컨트롤러·부모 확정값을 잃거나 키보드/회전으로 재생성되지 않아야 한다.
- 펼침/접기 자체는 규격·커버·쪽수 콜백을 부르지 않아야 한다.
- 변경을 거절한 부모의 기존 값이 계속 선택 표시돼야 한다.
- 템플릿 최소/80쪽 초과·제한 규격·이름 공백/50자 조건을 유지해야 한다.
- 다른 크기/커버 선택기 사용처의 기본 모양과 동작을 보존한다.

## Tasks

- [x] 신규 아코디언·공백/50자·선택 거절·상태 보존 테스트를 작성하고 현재 UI에서 실패를 확인한다.
- [x] `PrintCoverTypePicker(selected, onSelected)`: 공식 사진과 짧은 설명, 기존 선택 Semantics·키·큰 글자 대응. pubspec 에셋 등록.
- [x] `CoverSizePicker(..., compact=false)`: 설정에서만 자연 폭의 간결한 다섯 크기와 정확한 비율을 사용한다.
- [x] `AlbumCreateStep1`: 이름/책 크기·커버/내지 세 섹션, 한 번에 하나 펼침. 이름이 비면 이름, 있으면 크기·커버로 시작한다. 기존 컨트롤러·콜백·키·페이지 가드를 유지한다.
- [x] 미리보기 높이와 중복 정보만 줄인다. 커버 상세 안내는 확인된 구조·소재만 제공하고 미확인 면지 사양은 확정하지 않는다.
- [x] 범위 회귀 테스트, 실제 네이티브 캡처, 동일 상태 시각 비교와 독립 리뷰 후 검증 기록을 남긴다.

## Rulings

- 사용자가 시안 2와 업체 기준 문구/사진 제안을 승인했다. 실행 방식·단순 문구를 재확인하지 않는다.
- 큰 미커밋 작업 폴더와 읽기 전용 Git 메타데이터를 보존하기 위해 `/tmp/snapfit-album-settings-before/`에 대상 파일의 시작 상태를 보관하고 이 폴더에서 제한적으로 수정한다.
- 네이티브 테스트는 이전에 확인된 로컬 엔진/test_api 경로를 사용한다. 브라우저·실기기·운영 검증과 혼동하지 않는다.

- RED: 새 테스트가 `creation-settings-name-toggle` 부재로 예상 실패함을 네이티브 엔진에서 확인.
- Compact form만 웹에서도 기존 고정 CTA 워크스페이스를 사용하고, 다른 단계의 웹 레이아웃은 기본값으로 유지한다.
- 회전 중 열린 입력의 한글 조합은 보존한다. 사용자가 명시적으로 접는 동작은 포커스를 해제하므로 조합 확정은 허용하고 텍스트·선택·컨트롤러는 보존한다.

- 시각 QA에서 바깥 카드 여백이 다섯 크기를 4+1로 만들고 커버를 밀어내는 것을 발견해 구분선과 무여백 본문으로 조정했다. compact 크기 순서는 정사각 세 종 다음 가로 두 종이고, 안정적인 canonical size 목록은 보존한다.
- 독립 리뷰의 80쪽 초과 오류 숨김을 하단 상시 안내와 접힌 내지 요약으로 수정했다.
- 범위 테스트의 인증 pending timer는 명시적 fake auth/컨테이너 해제로 격리했다. 이미지 대기는 실제 시간+가짜 프레임을 함께 진행하는 유한 반복으로 바꿨다.
- 제작 여정의 320px 제목은 의도된 단어 단위 개행과 최근 확인한 디자인 정보 삽입을 고려해 원제목 semantic label과 정규화한 표시 문구를 검증한다. 기존 선택 횟수·사진·규격·복원 검증은 유지한다.

- 최종: 범위 테스트83/83 통과(캡처7 포함), Dart13파일 문제0, 대상 diff check 통과, 독립 중요 이슈0. 네이티브7상태 및 기준/최초/스크롤 정규화 시각 비교 완료. 브라우저/전체 앱/운영 배포 미실행.
