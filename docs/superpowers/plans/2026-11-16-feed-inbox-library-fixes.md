# 피드·알림·내 디자인 후속 개선

사용자가 2026-11-16 검토 결과의 네 항목 적용을 승인했다. 익숙한 아이콘과 기본 화면 구조는 유지하고, 안내의 가독성과 조작 복구·공간 사용을 개선한다.

1. 공통 오류 Snackbar는 배경과 본문 색 역할을 함께 지정한다. 라이트·다크의 실제 대비를 확인한다.
2. 내 디자인에서 즐겨찾기 해제 시 짧은 되돌리기를 제공한다. 저장 실패, 항목이 이미 다시 선택된 경우, 종료된 화면의 오래된 동작을 처리한다. 편집기 선택 도구의 기존 조작은 유지한다.
3. 내 디자인의 단독 즐겨찾기 조건 요약 행을 생략한다. 검색·분류·정렬이 결합된 조건 표시와 빈 결과 초기화는 보존한다.
4. 댓글 작성자 이름이 큰 글자·좁은 폭에서 우선 공간을 갖도록 메타데이터를 다음 줄로 배치한다. 기본 크기는 한 줄을 유지한다.

관련 회귀 테스트와 실제 위젯 화면을 직렬 실행한다. 앱 전체 빌드·서버 요청·배포는 포함하지 않는다. 기존 작업이 많은 저장소이므로 시작 시점의 파일 해시와 수정 파일별 차이를 보존한다.
