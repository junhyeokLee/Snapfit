# 인쇄 주문 화면 디자인 개선

사용자가 승인한 표지 요약·결제 정보 통합·동의 가독성·완료 상태 개선을 기존 Flutter 화면에 적용한다. 결제 서비스, 금액 계산, 필수 동의 3개와 동의 원문·버전, 주문 진행 사실 판단은 보존한다.

1. 검증된 기존 snapshot에서 표시용 Album을 만들고 기존 표지 위젯을 재사용한다. 다른 앨범/변경된 미리보기의 표지는 남기지 않는다.
2. 제작 구성과 총액·확인된 배송비 정보를 한 카드로 묶고 좁은 화면·큰 글씨에서 세로로 배치한다.
3. 동의 항목을 묶고 정책 링크와 긴 주문제작 전문은 펼쳐 확인한다. 별도 동의 3개와 요약 고지는 항상 보인다. 펼치기는 동의를 변경하지 않는다.
4. 완료 화면은 영수증·현재 상태·다음 예정 단계를 먼저 표시하고 전체 과정은 펼친다. 취소·환불·확인 필요 상태에 제작 예정 단계를 예고하지 않는다.
5. 새 동작의 실패 재현 → 구현 → 결제/동의/완료/반응형 회귀 및 실제 위젯 이미지 확인 → 독립 리뷰. 실제 PG·발주·앱 전체 빌드는 실행하지 않는다.
