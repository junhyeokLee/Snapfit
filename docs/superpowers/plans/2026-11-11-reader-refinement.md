# 앨범 감상·편집 위치 연결 개선

승인된 기존 화면을 유지하며 앨범 감상 흐름을 이어서 정리한다. 사진 비율·책 넘김·편집기 구성은 보존한다.

- [x] 실제 내지·메뉴·가로 화면을 먼저 캡처해 확인하고, 수정 후 상세 화면까지 확인한다.
- [x] 더보기에서 현재 보고 있는 쪽을 편집하고 메뉴에 편집 대상을 표시한다.
- [x] 편집 중 앞쪽 페이지를 삭제해도 원래 보던 페이지 ID를 기준으로 돌아온다.
- [x] 상세 보기에서 넘긴 마지막 쪽을 감상 화면에 반영한다.
- [x] 다른 계정·앨범·편집 세션으로 바뀌면 이전 화면의 복귀 처리를 무시한다.
- [x] 관련 회귀 테스트·정적 분석·실제 화면 캡처와 독립 리뷰를 확인한다.

앱 전체 빌드, 배포, DB 변경은 하지 않는다. Mac 자원을 고려해 무거운 검증은 한 번에 하나만 실행한다.
