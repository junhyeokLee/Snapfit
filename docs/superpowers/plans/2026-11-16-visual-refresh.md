# 화면 위계·작품 미리보기 개선

사용자가 최신 디자인 흐름에 맞춘 UI/UX 개선과 구현을 위임했다. 현재 코드의 실제 위젯을 먼저 캡처하고 읽은 뒤 확인된 개선을 적용한다. 사진 중심의 기존 teal 브랜드와 계정·스토어의 기능 계약을 유지한다.

- 설정: 관련 항목을 세 그룹으로 묶어 surface·타이포그래피 위계를 정리한다. 계정 설정에서 사진 변경을 명시적인 48dp 이상 텍스트 동작으로 제공한다. 관리자 권한, 테마·가이드·약관·로그아웃 흐름은 보존한다.
- 디자인 상세: 짧은 세로 화면의 별도 페이지 이동 행과 썸네일 행을 통합해 작품 공간을 키운다. 사진·기록 구성을 검증된 문서 값으로 먼저 알리고 가격·규격·구매 안내를 보존한다.
- 홈: 새 캡처로 확인한 좁은 화면의 기록 카드 폭 문제를 반응형 배치로 개선하고 앨범 전체보기 진입을 추가했다. 기존 표지 크기·리더·주간 달력·내 앨범 탭 정책은 보존했다.
- 검증: 의미 있는 동작·접근성 회귀는 실패부터 확인한다. 제품과 테스트 분석, 관련 회귀 테스트, 같은 크기의 전후 실제 화면과 다크·큰 글씨 화면을 비교한다. 컴파일·테스트·렌더는 한 번에 하나만 실행한다.

새 가격·상품·운영 데이터·의존성·앱 전체 빌드·배포는 추가하지 않는다. 장식보다 주된 콘텐츠와 행동을 분명히 하는 Material 3 Expressive 및 Apple HIG의 위계 원칙을 적용한다.

관련 회귀 114개 통과, 수정 12개 파일 분석 이상 없음, 전후 실제 위젯 화면 35장 검증 완료. 결과는 `docs/verification/visual-refresh-2026-11-16/적용_결과.md`에 기록했다.

후속 사용자 피드백: 프로필 사진 변경은 이전 카메라 아이콘과 우측 배치로 복원했다. 이 단순 조작에 추가했던 텍스트 버튼은 채택하지 않는다. 나머지 개편은 유지하며, 익숙한 아이콘의 설명을 늘리기보다 화면의 균형과 강조 수준을 먼저 확인한다. 복원 결과는 `docs/verification/profile-photo-icon-2026-11-16/적용_결과.md`에 기록했다.
