# 승인된 UX 개선 구현 계획

**Goal:** 초대·포인트·보관함과 편집기·인쇄의 승인된 개선을 적용한다.
**Architecture:** 기존 Flutter/Riverpod 저장소·위젯을 수정하며 결제·보상·인쇄 정책은 유지한다. 독립된 화면별로 구현하고 검증은 한 프로세스씩 실행한다.
**Spec:** docs/verification/auxiliary-next-review-2026-11-16/검토_결과.md 및 docs/verification/editor-print-next-review-2026-11-16/검토_결과.md. 사용자가 전체 구현을 요청했다.

## 제약
- 기존 작업 트리와 내비게이션 보존. 커밋/초기화/앱 전체 빌드/배포 없음.
- Mac 메모리 제한: 무거운 컴파일·테스트·렌더는 한 번에 하나.
- 포인트 사용처는 실제 저장된 정보를 사용하고 없는 이름은 추정하지 않는다.

## 작업
- [x] 초대: 유효한 받은 코드가 있는 등록 가능 사용자에게 등록 카드 우선. 일반/자기 코드/기간 종료/계정 전환 테스트.
- [x] 포인트: 기존 구매 metadata에서 상품명을 읽고 사용처를 표시. 제목이 없는 과거 내역 fallback 및 금액 정렬. AI 제목의 실제 저장 경로 확인 후 최소 보강. 저장소·표시 테스트.
- [x] 보관함: 모바일 제목 중복 제거·안내 축약, 해제 성공 후 되돌리기. 계정 전환/화면 종료/실패 시 복구 보호 테스트.
- [x] 편집기: 현재·전체 내지 수, 겹침 순서 라벨. 표지와 마지막 쪽 테스트.
- [x] 인쇄: 빈 페이지 요약 강조·가까운 편집 복귀, 배치·금액 확인 문구. 빈 페이지 0/추가 상태·복귀 테스트.
- [x] 직렬로 관련 테스트·정적 분석·새 화면 캡처 후 독립 코드 리뷰. 실제 결제·발송·주문 없음.

## 운영 반영 완료
후속 사용자 승인으로 AI 제목 보존 SQL의 운영 적용 완료. 서버17건 재검증 및 운영 함수 본문·권한·이력 확인. 운영 집계 조회 없이 검증했다.
