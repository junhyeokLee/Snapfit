# 한 페이지 리더 적용 계획

승인된 설계: `../specs/2026-11-12-reader-single-page-design.md`

1. 실제 AlbumReaderScreen의 세로 페이지 크기와 같은 펼침 이동 회귀를 먼저 추가하고
   현재 구현에서 실패함을 확인한다.
2. AlbumReaderSinglePageView에 단일 페이지 뷰포트와 카메라 전환을 추가한다.
   같은 펼침 이동은 별도 애니메이션, 펼침 경계 이동은 기존 BookFlip의 앞뒷면과
   진행률을 사용한다. 시작·목표 페이지를 보관해 완료·취소를 정확히 복원한다.
3. 실제 화면에서 세로 옵션을 켜고 페이지 목록을 필요할 때 여는 형태로 바꾼다.
   헤더·하단을 정리하면서 편집·협업 접근을 유지한다.
4. 순방향·역방향·제스처 취소·회전·썸네일 선택·끝 페이지와 비율 테스트를 확장한다.
   기존 상세/편집 복귀, 이미지 품질·예산·수명, 가로 펼침 테스트를 함께 실행한다.
5. 원본 앨범으로 세로 좌우·가로·넘김 중간을 캡처하고 독립 코드 검토 후 필요한
   수정만 반영한다. 결과와 제한을 docs/verification에 기록한다.

작업 분담: 주 리더 뷰 구현, 위젯 테스트, 화면 조립·검증을 분리한다. 컴파일·테스트·
캡처 등 무거운 작업은 주 에이전트가 한 프로세스씩 실행한다. 기존 작업 변경은 보존한다.
