# 앨범 목록·비교·사진 선택 개선 구현 계획

**Goal:** 승인된 UX 검토 4항목을 반영한다. 사용자의 최종 지시에 따라 내 앨범은 진행 중·완료 상태로 나누지 않고 모든 앨범을 기본으로 표시한다.
**Architecture:** 기존 Flutter/Riverpod 및 SnapFit 디자인 토큰을 재사용한다. 목록·스토어·웹 사진의 독립된 영역을 나누고 무거운 검증은 root가 하나씩 실행한다.
**Spec:** docs/verification/next-ux-review-2026-11-16/UX_UI_추가_검토.md + 사용자 최신 지시. 상태별 개수와 진행·완료 탭 제안은 최신 지시로 대체됐다.

## 제약
- 큰 미커밋 작업 트리를 보존하고 작업 시작 사본과 비교한다. 커밋·초기화·전체 앱 빌드·상시 서버·배포·운영 DB·실결제는 실행하지 않는다.
- 새 의존성·전역 영속 상태를 추가하지 않는다. 앨범·구매 권한과 계정 보호를 유지한다.
- 앨범 쪽수는 계속 표시하며 별 즐겨찾기 기능을 보존한다. 즐겨찾기는 상태 분류가 아닌 기존 개인 선택 필터로 유지할 수 있다.
