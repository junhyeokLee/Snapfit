# 기록 삭제·초대 복구·인쇄 진입 개선 계획

**목표:** 사용자가 승인한 추가 UX 검토의 네 문제를 기존 Flutter·Riverpod 구조에서 수정한다.

**근거:** `docs/verification/record-invite-reader-ux-review-2026-11-16/검토_결과.md`와 적용 승인.

**구현 방향:** 기존 화면과 저장소 계약을 재사용한다. 기록 제거는 사진 ID·진행 상태·유효 세션으로 보호하고 실행 취소를 제공한다. 초대는 서버 확인을 기준으로 로그인 복구와 지연 상태 재확인을 제공한다. 내지 상세는 기존 메인 리더의 인쇄 검토 진입을 재사용한다.

- [x] 기록: `moment_photo_removal_recovery_test.dart`로 중복 삭제·초안·실행 취소·계정/날짜 변경을 검증한 뒤 `moment_compose_screen.dart`를 수정한다.
- [x] 초대: 사용된 초대의 로그인 복구, 지연 요청의 안전한 이탈과 재확인, 늦은 응답·계정 전환을 먼저 검증한 뒤 초대 수락 화면과 오류 표시를 수정한다.
- [x] 리더: 실제 내지 상세 메뉴에서 인쇄 검토로 이어지는 동작을 검증한 뒤 기존 리더의 확인 절차를 연결한다. 권한·저장·인쇄 및 결제 확인을 우회하지 않는다.
- [x] 새 문제 동작의 실패를 확인하고, 수정 후 관련 기존 테스트 173개와 함께 직렬 검증했다. 계정·날짜 기존 보호를 보존하는 테스트는 원래 통과할 수 있다.
- [x] 수정 파일 분석, 독립 코드 리뷰, 새 화면 캡처를 완료하고 결과를 저장했다. 추가 월간 화면 묶음의 150초 시간 초과는 적용 결과에 별도 기록했다.

기존 작업 파일은 보존하며 새 의존성·운영 DB 변경·앱 전체 빌드·배포는 추가하지 않는다. 이 Mac의 테스트·컴파일·렌더는 한 번에 한 프로세스로만 실행한다.
