# 읽기 화면 첫 입력 반응 개선

사용자 우선순위는 읽기 화면 진입 직후부터 스와이프·넘김 버튼이 자연스럽게 반응하는 경험이다. 일반 디자인 검토는 종료하고 이 경로를 수정한다.

확인한 원인은 전체 앨범을 순차 준비·캡처한 뒤 엔진이 시작되는 장벽, 준비 전 pointer-down 유실, 준비 전 버튼의 순간 점프 경로다. 기존 테스트는 준비 완료 후에만 입력해 이를 발견하지 못했다.

1. 로컬 책 넘김 패키지에 현재·인접 페이지 우선 준비를 선택적으로 적용한다. 전체 쪽수·사진 준비 검증·기존 곡면·앞뒷면·승인된 시간 곡선은 보존한다.
2. 준비 중 입력을 유지하고, 같은 손가락의 진행 거리와 버튼 의도를 준비 완료 시 이어 준다. 실제 앨범 미리보기의 넘김 시작에 불필요한 프레임 대기를 제거한다.
3. 준비 대기 없는 40쪽 리더와 먼 페이지 준비 지연 회귀를 먼저 실패시킨 뒤 수정한다. 취소·역방향·회전·문서 교체·메모리 해제·사진 품질도 확인한다.
4. 무거운 검증은 직렬로 실행한다. 앱 전체 빌드·배포는 하지 않는다. 테스트 시간과 실기기 프레임 성능을 구분해 보고한다.
