# 홈 배치 우선순위 조정

사용자 요청: 앞선 전체 배치 점검 후 개선 진행. 매일 기록과 직접 만든 앨범을 크게 보는 두 목적의 우선순위는 작업자 판단에 위임.

작업자 판단: **오늘 기록/월간 누적 → 큰 앨범/작은 선택 목록 → 모아둔 순간/앨범 엮기/이어 만들기**. 달력과 큰 앨범 크기는 유지하고 보조 구간만 앨범 뒤로 이동한다. 오늘 기록은 작은 높이 화면에서 달력 위에도 진입할 수 있게 한다. 기존 기록/앨범/초안/편집/인증 경로는 유지한다. 새앨범 버튼 확대, 사진 비율 변경, 서버 변경은 하지 않는다.

검토한 대안: 기존 순서 유지(앨범 강조가 늦음), 앨범을 달력 앞으로 이동(매일 기록 목적이 약해짐), 월간 기록 다음에 앨범 배치(선택). 이는 사용자의 별도 순서 확정이 아닌 작업자 제안이다.

## 검토 초점

작은 화면 기록 버튼 노출 및 콜백, 큰 화면 기존 배치, 글자 확대, 비유효 journal에서 쓰기 진입 비노출, 빈 앨범/초안 복구 보존, 단일 세로 스크롤과 앨범 선택 유지. 스크린샷에서 고정 헤더가 빠지는 기존 오프스크린 캡처 한계는 앱 버그로 보고하지 않는다.

## 자원/변경 제약

무거운 컴파일·테스트·렌더·분석은 루트가 직렬 실행. 기존 dirty 변경을 보존하고 `.git`은 변경하지 않는다. 진행 승인은 현재 대화에 이미 있으므로 추가 승인 단계 없이 완료한다.
