# 승인 모션 이식 계획

1. 승인 HTML JS를 추출하고 `leafVertices`를 직접 실행해 독립 좌표 fixture를 만든다.
2. 실제 리더 메시와 해당 fixture, 500ms 시간 곡선을 비교하는 회귀를 추가해 현재 차이를 확인한다.
3. BookFlip에 선택 가능한 albumPreview 프로파일을 추가한다. 기본 렌더링은 보존하고
   원본 메시·투영·면 선택·음영·그림자를 전용 경로로 옮긴다.
4. 실제 리더 내지에서 프로파일을 사용하고 정착 시간·드래그 매핑을 원본에 맞춘다.
5. 동일 비트맵으로 JS 참조와 네이티브의 진행률별 프레임을 비교하고 순·역방향 영상을 만든다.
   읽기 화면 회귀와 독립 검토를 수행하고 확인한 결과만 보고한다.

무거운 컴파일·테스트·렌더는 주 에이전트가 한 번에 하나씩 실행한다.
사용자가 실행한 앱을 재설치하거나 별도 앱 빌드·서버를 시작하지 않는다.
