# 인쇄 제작 기능 반영 기록

대상: 연결된 Supabase 프로젝트 `rrbhxdtriummqpztpjrk`.

- `20260908104605_redprinting_fulfillment_contract.sql` 적용 완료.
- `admin-ops` Edge Function 배포 완료. 외부 결제 공급자 코드는 포함하지 않는다.
- 배포 후 원격 조회: 기존 주문 0건, 고객의 새 주문 생성 RPC 실행 권한 없음, 고객의 내부 원가 테이블 SELECT 권한 없음, 인쇄 버킷 비공개, 49,900원 견적 함수 반영, PortOne 참조 DB 함수 0건.
- 인증 없는 관리자 API 요청은 403으로 거절됨.
- 서버 타입 검사 및 실제 Flutter PDF를 포함한 서버·SQL 테스트 9개 통과.
- Flutter 변경 영역 정적 분석 오류 없음. 렌더러 전용 8개 테스트, 고객·관리자·주문 표시 관련 17개 테스트가 통과했다. 최종 통합 실행에서 발견된 기존 결제 중지 화면 테스트의 누락된 `albumId`도 보완해 재검증했다. 전체 앱의 스토어 배포는 수행하지 않았다.
- 생성한 표지와 20페이지 내지 PDF를 Poppler로 열어 전체 페이지를 확인했다. 합성 시험 앨범을 사용했으며 실제 고객 사진이나 실물 샘플은 사용하지 않았다.

공유 작업공간 경합: dry-run에서는 인쇄 migration 하나만 미적용이었으나, 실행 사이 다른 작업이 `20260908111001_digital_point_shop.sql`을 생성해 함께 적용되었다. 해당 작업에 즉시 알리고 검토를 요청했다. 임의 롤백은 하지 않았다. 이 디지털 상점 migration은 실물 주문 결제를 제공하지 않으며, 적용 직후 인쇄 결제 비활성과 기존 주문 0건을 재확인했다. 이후 배포는 별도 디렉터리에 대상 파일과 migration 목록을 고정한 뒤 수행한다.

후속 확인: 디지털 상점 담당 작업은 원격 `111001` 이력의 statements가 null이고 실제 상점 테이블·RPC가 없음을 확인했다. 기존 이력을 수정하지 않고 `20260908112124_complete_digital_point_shop_schema.sql`을 격리된 배포 디렉터리에서 적용해 상점 스키마와 권한을 보정했다고 보고했다. 상품·소유·구매 내역은 0건이고, 인쇄 migration과 파일 및 실물 결제 비활성 상태는 유지했다. 이 내용은 해당 작업의 보고이며 이 인쇄 작업에서 원격 DB를 추가 변경하지 않았다.

검증 완료 보고: 담당 작업이 실제 authenticated/anon 역할로 구매·중복 차감 방지·잔액·소유권·관리자 사칭 거절·다른 사용자 데이터 접근 제한을 검증하고 전체 트랜잭션을 롤백했다. 후속 조회에서 상품·소유·디지털 구매 원장·임시 사용자와 PortOne 함수는 모두 0건이었다. 푸시/환불 cron은 활성 상태를 유지했다. 디지털 상품 가격은 등록하지 않았으며 이력 추가 정리는 필요하지 않다고 확인했다.

제작사 문의는 후속 대화에서 사용자가 제공한 Gmail 계정으로 2026-09-08 20:25 KST에 발송했다. 업체 답변은 아직 확인되지 않았다. 실물 샘플 주문이나 고객 주문 발주는 수행하지 않았다.


## 5종 규격 확장 반영

사용자 요청으로 200×150, 200×200, 250×200, 250×250, 300×300mm를 새 앨범 선택 규격으로 연결했다. 실제 크기와 상품 ID를 `cover_layers_json.printProduct`에 보존한다. 기존 세로형은 편집을 유지하고 새 생성 및 새 실물 제작에서 제외한다. 템플릿 원본 좌표와 신규 물리 캔버스를 분리하여 25×20cm의 1.25 비율을 유지한다. AI 요청과 응답도 선택 상품과 실제 캔버스 높이를 전달한다.

### 배포

격리 폴더 `/tmp/snapfit-five-size-deploy-20260908`에 30개 마이그레이션의 고정 사본을 만들었다. dry-run은 신규 `20260908114757_redprinting_five_size_contract.sql` 한 개만 표시했고, 실제로 그 한 개만 적용했다. 기존 적용 파일은 수정하지 않았다. `admin-ops`, `ai-album-draft` 두 함수만 같은 고정 사본에서 배포했다. 실물 결제는 비활성 상태를 유지한다.

원격 읽기 검증에서 5개 상품 치수와 예상 기본가, 신규 마이그레이션 내용의 존재를 확인했다. 로그인 사용자에게 견적 조회를 허용하고, 비로그인 견적 조회·고객 주문 생성·서비스 역할의 주문 생성·고객 원가 함수 및 비공개 원가 조회는 모두 차단한다. 기존 주문은 0개이고 제거된 외부 결제 함수도 0개다. 무인증 요청은 admin-ops에서 403, ai-album-draft에서 401로 거부됐다. 유료 AI 호출, 고객 앨범 생성, 실물 발주는 수행하지 않았다.

보안 advisors는 배포 전후 26개로 동일하며 신규 경고는 없다. 기존 프로젝트 전체 권한 및 설정 경고는 이번 규격 변경으로 추가되지 않았다.

### 검증

생성 UI 23개, 인쇄·UI·관리자 연결 36개, 저장·AI·템플릿 41개, 서버 인쇄 14개, AI 서버 20개 테스트가 통과했다. 중복 실행 수는 합산하지 않는다. 이후 비율 허용 오차 정합성 수정까지 포함한 상수·에디터 23개 테스트도 통과했다. 기존 번들 템플릿의 3종 전제 검사를 5개 상품 ID·실제 캔버스·동일 방향 크기별 레이어 배율 검사로 갱신한 112개 테스트도 통과했다. 초대 화면은 선택 크기를 줄을 나누어 표시하며 관련 5개 테스트와 화면 검수를 완료했다. 대상 정적 분석에 오류가 없다.

실제 300dpi 표지 5개와 내지 5개의 PDF를 생성했다. pypdf로 MediaBox, TrimBox, 페이지 수를 확인하고 Poppler로 시각 검수했다. `output/pdf/print-five-sizes/contact-sheet.png`와 `pdf-geometry-check.json`을 참고한다. 합성 앨범 샘플이며 업체가 승인한 견본은 아니다.

전 규격 가격은 예상값이다. 자세한 가격과 원가 가정은 [운영 문서](operations.md) 및 [조사 기록](vendors/redprinting/research-2026-09-08.md)에 있다. 추가 네 크기의 실제 견적과 페이지 수별 도면 대조는 업체 확인 대기다. 이번 Flutter 소스 변경은 이전에 만든 Android AAB에 포함되지 않으므로 출시 빌드는 별도로 새로 만들어야 한다.

## 소프트커버·하드커버 선택 추가

공식5개 재단 크기에 소프트커버/하드커버 이미지랩을 별도 선택하도록 연결했다. 일반·AI 생성, 크기/템플릿 변경, AI 승인, 저장 후 복원, 예상 견적, 제작 미리보기, 관리자 발주 정보가 `_SOFT`/`_HARD` 상품ID를 유지한다. 표지 종류만 바꾸면 사용자의 사진과 문구 배치는 유지한다. 초대 화면도 선택 종류를 표시한다. 디지털 템플릿 구매의 공통 소유권은 그대로다.

하드커버 도면7개(5크기20p +200×15022p +300×30080p)를 내려받아 보관했다. 보드가 내지보다 가로/세로6mm 크고 감싸기20mm이며, 책등은 소프트커버와 다른 별도 계산을 사용한다. 미측정 면수는 추정 출처를 표시한다. PDF 및 업체 실물 승인 상태를 혼동하지 않도록 `verified:false`와 검수 절차를 유지한다. 관리자 화면은 도면을 자동으로 채우고 기본 도면의 책등 폭을 수정하면 표지 전체 폭/앞표지 위치를 함께 조정한다.

고정 배포 폴더 `/tmp/snapfit-cover-type-deploy-20260908`에서31개 마이그레이션 사본의 해시를 고정했다. dry-run은 신규 `20260908120849_redprinting_cover_types_contract.sql` 한 개만 표시했고 그 한 개만 적용했다. 과거30개 마이그레이션 원문이 앞선 배포 사본과 같음을 확인했다. `admin-ops`와 `ai-album-draft` 두 함수만 같은 사본에서 배포했다.

원격 읽기 검증:10개 상품의 치수/종류/예상가격 및5개 하드커버 기본 도면 확인. 새 마이그레이션 본문이 이력에 기록되었다. 인증 사용자 견적 권한은 유지했고, 비인증 견적·고객/서비스 역할 신규 주문 생성·고객 내부 원가 조회 권한은 차단 상태다. 실물 주문0건/폐기된 결제 검증함수0개를 확인했다. 미인증 HTTP는 admin-ops403, ai-album-draft401로 거절한다.

검증:생성 관련30개, 루트AI/저장/복원44개, 초대5개, 인쇄 관련50개 테스트 통과. 서버/격리PostgreSQL19개, AI서버20개 통과, 최신도면목록 변경영향15개 재통과. Flutter 대상 분석과 두 Edge Function 타입 검사 정상. 하드5종 표지1페이지/내지20페이지 PDF를 실제로 만들고 pypdf와Poppler로 크기/TrimBox/페이지 수/화면 배치를 확인했다. 결과는 `output/pdf/print-hardcover/contact-sheet.png`와 `pdf-geometry-check.json`에 있다. 합성 샘플이며 업체 승인 견본은 아니다.

가격은 커버 종류별 예상 정책이다. 실제 하드커버 웹 견적은 조사 문서에 별도로 기록했고 최종원가/배송·동봉조건은 공급사 회신과 발주 직전 견적으로 확인한다. 실물 결제는 중지 상태를 유지한다. 이번 Flutter 변경은 새 앱 빌드가 필요하며 이전 Android AAB에는 포함되지 않는다.

배포 전후 Supabase 보안 Advisor 비교는 기존26건으로 동일하며 새 경고0건이었다.
