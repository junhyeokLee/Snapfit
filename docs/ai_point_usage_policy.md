# Snapfit 포인트 사용 정책 정리

## 목적

Snapfit의 포인트는 사용자가 실제 비용이 발생하는 AI 도움을 받을 때만 쓰는 보조 재화다. 직접 앨범을 구성하는 기본 경험은 포인트 없이 유지한다.

## 권장 포인트 표

| 기능 | 권장 포인트 | 차감 시점 | 차감 실패/환불 기준 | 비고 |
| --- | ---: | --- | --- | --- |
| 직접 앨범 만들기 | 0P | 없음 | 없음 | 기존 수동 생성 흐름 유지 |
| AI 앨범 초안 만들기 | 300P | 추천 초안이 성공적으로 생성된 뒤 | 사진 부족, 권한 실패, 생성 실패, 서버 오류 시 차감 없음 | 첫 1회 무료 체험 권장 |
| 정밀 AI 앨범 추천 모드 | 추후 결정 | 정밀 추천 결과 생성 성공 뒤 | 생성 실패/동의 철회/사진 부족 시 차감 없음 | 서버 Vision/고급 모델을 붙일 때만 별도 검토 |

## 1차 출시 권장안

1차 출시에서는 포인트가 들어가는 기능을 많이 늘리지 않는다.

```text
직접 만들기: 무료
AI 앨범 초안 만들기: 첫 1회 무료, 이후 300P
그 외 AI 보조 기능은 1차 정책에서 제외
```

이유:

- Snapfit의 핵심은 앨범 제작 경험이지 포인트 상점이 아니다.
- 첫 AI 기능은 `AI 앨범 초안 만들기` 하나를 깊게 보여주는 것이 좋다.
- 제목 추천, 표지 추천, 사진 교체 추천, 품질 체크를 각각 유료 기능으로 나누면 앱이 과하게 상업적으로 보일 수 있다.
- 사용자는 포인트 메뉴를 이해하기 전에 앨범 만들기 자체를 먼저 경험해야 한다.


## 제외한 AI 포인트 항목

다음 기능들은 당장 별도 포인트 상품으로 만들지 않는다.

```text
AI 제목/짧은 문장 추천
AI 표지 후보 추천
AI 사진 교체 추천
AI 인쇄 전 품질 체크
```

이 기능들은 개별 유료 버튼으로 분리하면 Snapfit이 포인트 상점처럼 보일 위험이 있다. 필요하다면 나중에 `AI 앨범 초안 만들기` 결과 안에 자연스럽게 포함하거나, 사용량/비용이 확실해진 뒤 다시 검토한다.

## 차감 원칙

포인트는 반드시 **결과가 성공적으로 준비된 뒤** 차감한다.

```text
사용자 확인
→ AI 초안 생성 시작
→ 결과 생성 성공
→ 포인트 차감
→ 추천 리뷰 화면 표시
```

다음 상태에서는 차감하지 않는다.

```text
사진 권한 거부
선택한 사진 수 부족
서버/네트워크 오류
AI 결과 생성 실패
사용자가 생성 전 취소
```

## 사용자 신뢰 카피

포인트 확인 화면:

```text
AI 초안을 만들어볼까요?
선택한 사진 안에서 어울리는 장면과 앨범 흐름을 먼저 정리해드릴게요.

사용 포인트
300P

초안은 바로 확정되지 않아요. 결과를 보고 마음에 드는 구성만 선택할 수 있어요.
초안 생성이 실패하면 포인트는 차감되지 않아요.
```

첫 무료 체험:

```text
무료 AI 초안을 사용해볼까요?
오늘은 1회 무료로 AI 초안을 만들 수 있어요.
무료 초안을 사용해도 결과는 직접 확인한 뒤 시작해요.
```

포인트 부족:

```text
포인트가 조금 부족해요
AI 초안을 만들려면 300P가 필요해요.
직접 구성하기로 시작하면 포인트 없이 바로 만들 수 있어요.
```

## 금지 방향

- 제목 추천, 표지 추천, 사진 교체 추천, 품질 체크를 각각 포인트 상품처럼 늘어놓지 않는다.
- 시작 화면에서 포인트 구매를 전면에 내세우지 않는다.
- 직접 만들기 경로에 포인트 안내를 넣지 않는다.
- 실패했는데 포인트를 차감하지 않는다.
- `AI가 완성해드립니다`처럼 사용자의 편집 권한을 빼앗는 표현을 쓰지 않는다.
- 얼굴/감정 분석처럼 민감하게 들리는 표현을 기본 UX에 쓰지 않는다.
