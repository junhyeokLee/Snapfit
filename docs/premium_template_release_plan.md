# 스냅핏 유료 템플릿 품질·출시 기준

기준일: 2026-09-08
상태: **7개 주제의 36종을 무료 기준으로 유지**. 새 유료 상품은 아직 등록하지 않음.
소재 기반 확장 현황은 [소재 스튜디오](studio_atelier_foundation.md)를 따른다.
**바람을 수집한 여행**도 사용자 요청으로 무료로 전환했다. 표지 3안과 내지 32쪽,
전용 그림 및 세 규격을 유지한다. [제작·검수 기록](premium_wind_atlas.md).
이후 유료 기획은 [타이포그래피·문구 중심 상향 기준](premium_typography_standard.md)을
먼저 적용한다. 아래 이전 후보 기록과 점수 기준보다 최신 상향 기준이 우선한다.
아래 3종 재분류 및 이전 후보 기록은 당시 이력이며, 현재 카탈로그 수를 뜻하지 않는다.

## 현재 결정

빛으로 엮은 우리, 여행의 결, 작은 날의 기록, 바람을 수집한 여행은 무료 기준이다.
이전 무료 시안 3종은 신규 선택 목록에서 제거한다. 상세 범위와 앞으로의
유료 차별화 기준은 [무료 템플릿 기준](free_template_baseline.md)을 따른다.
아래의 이전 유료 후보 제안은 현재 상품 분류가 아니다.

## 이번 반영

- 현재 제작 컬렉션 이름, 표지 제목과 표지 하단 이름을 한글로 통일했다.
  - petal_archive: 꽃처럼 피어난 날
  - lost_and_found: 낯선 곳의 조각들
  - good_things: 좋아하는 순간들
- 기존 검토 시안의 메뉴 이름도 섬에서 보낸 시간, 제주에게 쓰는 편지,
  잠시 쉬어가는 날로 변경했다. 내지의 모든 영어 문구를 번역한 것은 아니다.
- 컬렉션 ID, 무료 이용 조건, 기존 사용자 앨범은 유지한다.
- 무료 컬렉션을 같은 ID로 유료 전환하지 않는다. 유료판은 별도 신규 상품으로 검수한다.

## 경쟁 기준과 전략

미리캔버스는 무료·프리미엄 템플릿, 사진·그래픽, 배경 제거와 AI 도구를
제공한다. AI 프레젠테이션도 개요 구성, 디자인 적용과 편집 기능을 제공한다.
따라서 “AI 지원”, “다양한 도형”, “편집 가능한 레이어” 자체는 독자적인 우위가 아니다.
공식 기능 소개를 확인한 것이며 전체 모바일 앱을 직접 사용한 경쟁 사용성 평가는 아니다.

- [공식 요금제](https://www.miricanvas.com/ko/pricing)
- [공식 AI 프레젠테이션 기능](https://www.miricanvas.com/ko/features/ai-presentation-maker)
- [템플릿 제작 가이드](https://miricanvas-designhub.zendesk.com/hc/ko/articles/24701872100633)

목표는 모든 그래픽 디자인 분야에서 더 낫다고 주장하는 것이 아니라,
**사용자 사진으로 완성한 실물 포토앨범의 편집 완성도**에서 앞서는 것이다.
경쟁 결과물은 비교 평가에만 사용하고, 해당 레이아웃이나 소재를 상품 원본으로 가져오지 않는다.

## 현재 구성에 남아 있는 약점

1. 20쪽 구성과 다중 사진 배치는 확보했지만, 큰 제목·사진·작은 장식이라는
   공통 문법이 세 컬렉션에 반복된다. 색상과 폰트 외에 독립적인 시각 문법이 더 필요하다.
2. 선정된 샘플 사진은 보기 좋지만, 어두운 실내 사진·셀피·단체 사진·스크린샷·
   긴 이름 등 실제 사용자 입력의 변동을 견디는지는 별도 검수가 필요하다.
3. 원형·아치·찢어진 프레임은 장식 옵션이다. 무엇을 강조하고 왜 그 형태인지
   페이지 역할과 연결되어야 한다. 얼굴과 손, 중요한 사물을 자르면 실패다.
4. 가로형 표지는 재구성하지만 다수 내지는 정규화된 좌표를 공유한다.
   비율 유지와 규격별 최적 조판은 다르다. 제본 안쪽 여백도 별도 검사가 필요하다.
5. 현재 자동 검사는 텍스트 높이·기하·디코딩·저장 계약 중심이다.
   심미성, 좋은 크롭, 실제 사진 교체 후 품질, 물리 인쇄는 통과 판정하지 않는다.
6. 샘플 사진의 생성 기록은 있지만 폰트·장식·생성 소재의 판매/재배포 범위와
   인쇄 결과까지 확인한 완성 상품 증빙은 아직 없다.

“고해상도 파일” 표시만으로 인쇄 품질을 통과시키지 않는다. 크롭한 후 실제
배치 크기에 대한 유효 PPI를 계산하고, 통과 기준은 인쇄 파트너의 요구사항으로
확정한다. 단순 확대 저장은 원본의 세부 정보를 복원하지 않는다.
[미리캔버스 공식 해상도 안내](https://help.miricanvas.com/hc/ko/articles/52440475704985)

## 이전 후보 제작 기록

**빛으로 엮은 우리**는 신규 원본으로 제작했으며, 현재는 무료 기본으로 채택했다.

대표 시안 제작 현황: [빛으로 엮은 우리 제작 기록](lightbound_wedding_draft.md).
현재는 표지 1개와 12스프레드(내지 24쪽)의 검토용 원본까지 제작했다.
추가 표지 선택안과 실제 사용자 사진·인쇄 검수는 남아 있다. 이 컬렉션을 유료로 출시하지 않는다.

- 표지 후보 3개와 내지 24쪽/12스프레드를 1차 목표로 한다.
  표지는 선택안이며 내지 장수에 중복 합산하지 않는다. 더 긴 책이 자동으로 더 좋은 것은 아니다.
- 먼저 표지와 대표 4스프레드만 설계해 아트디렉션을 승인받는다.
- 전용 한글 제목 체계, 사진 중심 양면 구성, 감정이 담긴 작은 캡션,
  편지와 기록 구성을 별도로 설계한다.
- 핵심 스프레드에서 얼굴과 주 피사체가 제본 중앙을 지나지 않도록 한다.
- 1/2/3/4/6장 사진 구성과 적은 사진용 대안을 같은 디자인 체계로 만든다.
- 규격별 조판을 개별 검수하며, 표지 3개나 규격 3개를 별개 상품 수로 부풀리지 않는다.
- 신규 소재는 편집 가능한 레이어 또는 고품질 투명 이미지로 제작한다.
  과도한 그림자, 임의의 금박 효과, 의미 없는 스티커를 “고급”의 대체물로 쓰지 않는다.

여행 **여행의 결**, 일상 **작은 날의 기록**도 각각 표지 + 내지 24쪽을
독립 콘셉트로 제작했다. 세 물리 규격의 편집 가능한 원본과 개발용 미리보기를 제공한다.
이름만 바꾼 무료 컬렉션의 재등록이 아니며, 판매 중인 상품도 아니다.
[여행·일상 제작 기록](editorial_volumes_drafts.md)을 참고한다.

## “더 뛰어나다”를 확인하는 방법

다음은 제안하는 내부 출시 기준이며 아직 달성했다는 뜻이 아니다.

- 디자인 리뷰: 독창성 25, 책 전체의 흐름 20, 한국어 조판 15,
  사진 교체 내성 20, 편집 경험 10, 인쇄 준비 10의 100점 체계.
  3인의 독립 평가 평균 85점 이상, 모든 항목에서 배점의 70% 이상을 목표로 한다.
- 필수 차단 항목: 텍스트 잘림, 중요한 얼굴 잘림, 저장 손실,
  인쇄 안전영역 침범, 권리 미확인 소재, 구매 후 사용 불가가 하나라도 있으면 보류한다.
  점수 평균으로 필수 실패를 상쇄하지 않는다.
- 실제 사진 검수: 동의를 받은 사진이나 사용 권리가 확인된 자료로 최소 6개 세트.
  사진 방향, 얼굴 수와 위치, 어두운 실내, 저해상도, 긴 문구, 적은 사진을 포함한다.
- 경쟁 파일럿: 동일한 사진·문구·앨범 규격·편집 시간으로 만든 결과를 비교한다.
  브랜드를 가린 상태에서 목표 사용자 12명 이상에게 선호 이유와 수정 난이도를 받는다.
  가능하면 서로 다른 편집자 2명 이상이 각각 제작해 제작자 숙련도 편향을 줄인다.
  이 소규모 결과는 방향 판단용이지 통계적으로 우월하다는 광고 근거가 아니다.
- 최종 단계: 세 규격 교정쇄와 실제 기기 편집을 확인하고, 최소 한 번 디자인 수정 후 재검수한다.

## AI 템플릿과의 관계

AI가 기존 완성 템플릿을 고르고 사진을 자동 끼워 넣는 것을 핵심 기능으로 삼지 않는다.

사용자 디자인 요청 → 시각 방향/페이지 역할 제안 → 새 좌표와 편집 가능한
레이어 생성 → 실제 렌더링 검수 → 수정할 부분만 재생성의 순서로 간다.
좋아하는 영역을 잠그고 나머지만 수정하는 기능을 포함하는 방향이다.
사진 넣기 단계의 크롭 보조는 별도 편집 기능이며, AI 디자인 생성과 혼동하지 않는다.

유료 수작업 컬렉션은 품질 기준과 평가용으로 사용한다.
AI 결과로 위장하거나 기존 컬렉션 JSON을 반환하는 폴백으로 쓰지 않는다.
실제 생성 호출과 품질 평가는 API 사용량 확보 후 별도 수행해야 한다.

## 실제 등록 전 기술 작업

현재 코드에서 확인한 사실:

- 무료 원본은 `bundled_creation_templates.dart`의 음수 ID이며 운영 상품이 아니다.
- `TemplateDetailScreen._ensureSubscriptionForPremium`은 활성 구독을 확인한다.
  미구독자는 “구독 및 결제 기능은 현재 준비 중” 안내만 보며, 이 진입 경로에는
  결제 화면 연결이 없다. 앱 전체 결제 시스템을 검증했다는 의미는 아니다.
- `PremiumTemplate`과 기존 게시 도구에는 개별 상품 가격/product ID 필드가 없다.
  현재 구조는 프리미엄 여부 표시와 구독 확인 중심이다.
- 게시 도구는 `asset:`를 거부하며 제목으로 기존 상품을 찾아 upsert하고
  `active: true`를 보낸다. 이름 변경과 초안 업로드를 즉시 운영 게시로 연결하면 안 된다.
- 정교한 원본 조판 유지 여부가 일부 경로에서 로컬 번들 ID로 결정된다.
  서버 유료 문서도 명시적 메타데이터로 동일 렌더링을 유지하도록 계약 검증이 필요하다.

따라서 순서는 다음과 같다.

1. 신규 컬렉션 아트디렉션과 대표 스프레드 승인.
2. 전체 페이지·세 규격 제작, 실제 사진 교체와 인쇄·권리 검수.
3. 구독 포함인지 낱개 판매인지, 가격·이용 범위·복원 정책 확정.
4. 신규 안정 ID와 버전 지정. CDN 원본/미리보기 등록, 모든 URL·해상도 확인.
5. 서버 템플릿을 실제 편집기에서 불러와 동일성·저장·권한 검증.
6. 구매/구독, 복원, 환불 후 권한 처리를 스테이징에서 검증.
7. 검수 결과와 상품 상세를 승인한 뒤 운영 게시. 현재 무료 원본은 유지.

기존 `TEMPLATE_REGISTRY_GUARDRAILS.md`의 병합·잠금 절차를 따른다.
이 문서는 기존 게시 도구를 실행하거나 서버 설정을 변경하지 않는다.

## 권리와 판매

소재의 “상업적 이용 가능”과 앱에서 편집 가능한 템플릿으로 재배포할 수 있는
범위는 따로 확인한다. 폰트 임베딩, 스티커 원본, 사진, 생성 이미지의 약관과
