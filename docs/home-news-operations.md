# 메인 새 소식 운영

관리자 계정으로 **마이 → 설정 → 관리자 → 새 소식 운영**에 들어갑니다.

각 소식의 스위치·시작/종료 시간·노출 순서를 바꾼 뒤 해당 카드의 **설정 저장**을 누릅니다. 일반 회원은 이 메뉴와 관리 API를 사용할 수 없습니다. 이 운영 기능이 포함된 앱 버전부터 이후 이벤트 변경에 앱 업데이트가 필요 없습니다.

- 이달의 디자인, 출석 혜택, 친구 초대, 월말 돌아보기 네 종류를 각각 운영합니다.
- 시간은 한국 시간입니다. 시작 시간부터 노출하고 종료 시간에는 노출을 끝냅니다. 시간을 비우면 해당 경계가 없습니다.
- 켜진 소식을 한 팝업에서 스와이프하거나 페이지 표시로 넘깁니다. PC에는 이전·다음 화살표도 있습니다. 버튼은 현재 카드의 실제 화면으로 이동합니다.
- 변경은 다음 새 소식 조회/팝업 진입부터 반영됩니다. 이미 열린 카드라도 버튼을 누를 때 서버 설정을 다시 확인합니다. 새 소식 목록의 새로고침으로도 갱신할 수 있습니다.
- 자동 팝업은 한국 날짜 기준 하루 한 번, 월요일 시작 주간에 두 번, 앱 실행 중 계정별 한 번으로 제한합니다. 네 카드를 넘겨도 팝업 한 번으로 계산합니다. 이벤트를 껐다 켜도 이미 사용한 노출 횟수가 초기화되지 않습니다.
- 자동으로 여는 첫 소식은 아직 보지 않은 적절한 소식이어야 합니다. 출석·초대 완료 상태도 다른 카드와 함께 확인할 수 있으나 이를 이유로 자동 팝업을 띄우지 않습니다.
- 월말 실제 돌아보기는 마지막 7일·저장한 사진·아직 만들지 않은 월별 앨범 조건을 유지합니다. 사진이 없거나 월중이면 나의 기록 시작으로 연결하며, 이 안내를 봐도 실제 월말 알림 기회는 남습니다.
- 닫은 뒤 **알림 → 혜택·새 소식**에서 다시 볼 수 있습니다. 수동으로 열어 보는 것은 자동 노출 횟수에 포함되지 않습니다.

실제 지급 포인트는 출석/초대 서버 정책을 따릅니다. 새 소식을 보거나 운영 설정을 바꿔도 포인트가 지급되거나 차감되지 않습니다.
