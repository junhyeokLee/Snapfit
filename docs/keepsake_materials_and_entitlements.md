묶음 구매 권한을 자동으로 의미하지 않는다.

## 추천하는 구매 정책

**템플릿 구매 = 완성된 편집 디자인 + 실제 포함된 유료 재료의 재사용 권한.**
이 정책은 제안 단계이며 이번 작업에서 서버 권한을 부여하지 않는다.

- 구매한 템플릿 내부에서 사진을 바꾸거나 장식을 이동·복제하는 데 추가 결제 없음.
- 포함된 재료는 같은 계정의 다른 앨범에도 새로 삽입할 수 있도록 내 재료에 해제.
- 같은 컨셉 팩이라도 템플릿에서 사용하지 않은 재료까지 모두 주지는 않음.
- 무료 재료에는 별도 가격이나 유료 혜택 가치를 붙이지 않음.
- 이미 보유한 포함 재료는 소유권을 중복 생성하거나 별도 차감하지 않음.
  이것이 템플릿 전체 가격을 자동 할인한다는 뜻은 아님. 템플릿의 편집 디자인
  가치가 있으므로 구매 화면에서 포함 항목·보유 항목과 최종 가격을 구분한다.
- 재료 팩의 기보유 항목 할인은 팩별 가격 배분과 하한가를 정한 뒤 별도로 도입.
  임의로 개별 정가를 합산해 할인하거나 음수·0P 가격을 만들어서는 안 됨.
- 템플릿을 복제하거나 친구에게 앨범을 공유해도 상대 계정에 재료 소유권이
  이전되지는 않음. 공유 앨범 열람 권한과 재료 신규 삽입 권한을 분리.
- 기존에 무료로 적용해 저장한 앨범은 향후 유료 전환 때문에 장식이 삭제되거나
  편집·출력이 막히지 않도록 유지. 신규 삽입 가격 정책과 기존 문서 호환성은 별개.

## 구현된 것과 아직 아닌 것

- 28종 모두 기존 관리자 포인트 상품 목록에서 독립 상품 키로 발견된다.
  종이·테이프도 현재 스키마의 `sticker:<id>` 키를 사용하며 프레임은 `frame:<id>`.
- 현재 가격은 미설정. 운영 DB의 가격·지갑·소유권은 이번 작업에서 변경하지 않는다.
  기존 정책상 상품 설정이 없는 재료는 무료 접근으로 처리된다. 가격을 입력하고
  활성화하면 기존 서버 구매 확인 경로를 사용한다. 새 재료를 이미 유료로
  출시했다는 뜻이 아니며 상업 배포 전 소재 검토는 별도로 필요하다.
- 실제 편집기 삽입 시 기존 구매 확인을 통과하고, 즐겨찾기는 기존 안정적인
  재료 키로 저장한다. 로컬 `/materials` 작업실의 무과금 미리보기는 별도 경계다.
- `templateVisualMaterialKeys`가 실제 표지·내지·규격 문서의 스티커·종이·프레임을
  중복 없이 추출한다. 레이스/리넨 프레임에 들어가는 하위 재료도 포함한다.
  문구는 텍스트 내용만으로 상품을 역추정하지 않는다. 유료 문구·스타일 묶음은
  앞으로 명시적 원본 상품 ID를 문서에 유지해야 한다.
- 판매 명세 export에 시각 재료 목록을 남긴다. 이는 편집자가 검토할 목록일 뿐,
  서버가 신뢰하는 승인 목록이나 실제 소유권 지급 기능은 아니다.

## 다음 판매 연결 조건

앱마켓 결제 검증도 유지한다. iOS에서 IAP로 구매한 크레딧에는 만료를 두지
않아야 하며, 복구 가능한 구매에는 복구 수단이 필요하다.
[Apple App Review Guidelines 3.1.1](https://developer.apple.com/app-store/review/guidelines/#in-app-purchase).
포인트 자체의 결제 복구와 SnapFit 재료 소유권 동기화는 각각 검증한다.

1. 상품 상세에 `포함 재료 N개`, 개별 미리보기, 보유 여부와 재사용 범위 표시.
2. 승인된 템플릿 버전별 재료 목록을 서버에 고정. 클라이언트 JSON의 재료 목록을
   믿고 소유권을 지급하지 않음. 기본판·확장판·규격 전체 포함 범위를 확정.
3. 템플릿 결제 한 트랜잭션에서 템플릿과 포함 유료 재료 소유권을 함께 기록.
   별도 재료 청구 없음. 재시도·동시 구매에도 지갑은 한 번만 차감.
4. 직접 구매와 여러 템플릿 포함 구매의 지급 출처를 별도 보존. 환불 시 다른
   유효한 구매 출처가 있는 재료까지 회수하지 않음. 현재 단일 소유권 테이블만으로
   이 출처 구분이 완성되었다고 판단하지 않음.
5. 템플릿 업데이트로 새 재료를 추가할 때 기존 구매자에게도 제공할지 버전 정책 확정.

## 가격 기획안

후속 작업에서 사용자가 가격 책정을 위임했다. 아래의 초기 범위는
[출시 가격 기준](point_shop_launch_pricing.md)의 상품별 책정가로 대체한다.
운영 가격과 자동 권한 지급은 여전히 변경하지 않는다.

확정 가격이 아닌 내부 검토 범위: 보조 종이·테이프 100~200P, 고밀도 실사
오브젝트·특수 프레임 250~400P, 컨셉 팩 800~1,200P. 실제 팩 구성과 무료 공개
범위를 먼저 정한다. 단순히 재료 수로 가격을 올리지 않고 대체 가능성,
인쇄 해상도, 정교한 마스킹, 여러 사진에서의 활용도를 본다.
템플릿 2,500P 안은 아직 제안이며, 포함 재료 정책이 확정되면 함께 조정한다.
