# 바람을 수집한 여행

제작일: 2026-09-08

**현재 분류: 무료 번들, ID -9304.** 사용자가 유료 기준에는 부족하다고 판단하여
무료로 채택했다. 기존 35종에 추가되어 총 36종이다. 스토어·앨범 생성·편집기에서
기본 표지와 내지 32쪽을 무료로 사용하며, 전용 미리보기의 표지 3안도 보존한다.
문서·파일 이름의 `premium`은 과거 작업명이다. 기존 원본 호환성을 위해 경로와
문서 ID를 유지하며 `accessTier: free`, `publicationStatus: bundled`로 분류한다.
새 유료 기준은 `premium_typography_standard.md`를 따른다.

## 구성과 차별화

- 표지 3안: 해안 화보 / 보태니컬 에디션 / 수집가의 표지.
- 내지 32쪽, 16스프레드. 표지 선택안이나 규격을 상품 수로 중복 계산하지 않는다.
- 세로형·정사각형·가로형: 앱의 `CollectionAspect.canvas` 기준으로 렌더링한다.
- 여행 화보, 식탁, 수집품, 엽서, 인물, 사진 모음, 편지, 다음 여행의 기록을
  한 권의 흐름으로 구성했다. 무료 템플릿의 페이지 구성을 가져오지 않았다.
- 한글 명조 제목과 작은 고딕 캡션, 물빛·짙은 녹색·적색·레몬색을 역할별로 사용한다.
- 별도 제작한 투명 배경 해안 수채화와 레몬 보태니컬을 장면별로 배치한다.
  일러스트를 사진 슬롯에 합성하지 않는다. 사진을 지우거나 바꿔도 그림은 유지된다.
- 원형에 가까운 타원, 아치, 물결, 인화지 코너, 우표, 엽서 등 기존 프레임
  렌더링 기능을 활용하되 페이지 배치는 새로 작성했다.
- 가로형 표지와 차창 페이지는 별도 구도, 사진 모음은 3열 2행으로 재배치한다.
  인물 페이지는 인물 사진의 세로 비율을 세 규격에서 동일하게 유지한다.

이는 AI 자동 템플릿 생성 기능의 결과물이 아니다. 레이아웃은 직접 작성했고,
전용 그림 2점은 imagegen으로 새로 생성했다. 문서의 `aiGenerated: false`는
레이아웃 생성 경로를 뜻하며, 그림의 출처는 별도 `artworkAuthorship`과
`assets/templates/premium_wind_atlas/provenance.json`에 기록한다.

## 편집 원본과 미리보기

원본: `lib/core/templates/authored_wind_atlas.dart`의 `buildWindAtlas`.
`DataTemplateEngine`을 거쳐 실제 앱의 `LayerModel`과 `TemplatePageRenderer`를 사용한다.
텍스트·사진·프레임·그림이 분리되며 기존 직렬화와 사진 초기화 계약을 따른다.

미리보기: `http://127.0.0.1:4323/?collection=wind-atlas#/wind-atlas`.

- 표지 변경 시 표지로 이동하며, 편집한 문구와 선택한 규격은 유지한다.
- 16스프레드 전체 보기, 목차 이동, 페이지 확대, 규격 변경을 지원한다.
- 여행지·기간·이름·마무리 편지를 바꿀 수 있다. 긴 문구가 세 규격 또는
  다른 표지 안에서 잘리면 적용을 막고 수정하도록 안내한다.
- 사진 숨기기와 여행·인물·단체·어두운 사진의 교체 검토 메뉴가 있다.
- 이는 개발용 워크벤치이며, 편집 내용이 영구 저장되는 사용자 앨범 화면은 아니다.

## 검증과 출시 경계

자동 검사: 33페이지의 독립 구성, 3표지의 구도 차이, 기존 무료 구성과의 중복,
텍스트 실측 높이, 문자·사진 충돌, 레이어 경계, 안쪽 사진 여백, 이미지 로딩,
레이어 저장·복원, 사진 초기화 시 그림 보존, 문구 편집과 두 화면 방향의 컨트롤.
가장자리 안쪽 12%는 현재 시안의 사진 보호 여백이며 인쇄 업체 규격 인증이 아니다.

실제 렌더러로 세 규격의 전 페이지와 추가 표지를 출력한다:

```sh
flutter test --no-pub test/design/wind_atlas_test.dart --dart-define=EXPORT_WIND_ATLAS=true
```

출력 위치: `output/template-preview/wind-atlas/`. 각 규격의 `document.json`은
기본 표지와 내지 원본이며, 추가 표지 이미지와 전 페이지 이미지도 함께 생성된다.
추가 표지의 개별 레이어 원본은 `cover-botanical.json`, `cover-photographic.json`이다.

2026-09-08 검증 결과:

  대신하는 것은 아니다. 브라우저 실행 기록은 `output/template-preview/wind-atlas/browser/report.json`.

**검수 경계와 남은 항목**

1. 샘플 사진을 실제 사용자 사진 6개 세트 이상으로 교체해 얼굴·초점 크롭을 검수한다.
   교체 메뉴는 스트레스 검토용이며 얼굴 자동 인식 보정을 구현한 것은 아니다.
2. 앱 실기기에서 생성·사진 교체·되돌리기·저장·재열기를 확인한다.
3. 그림·폰트·데모 사진의 상품 배포 범위와 재배포 권리를 확인한다.
4. 인쇄 파트너 규격·도련·제본·유효 PPI와 세 규격 교정쇄를 검수한다.
   `CoverSize.realSize`의 mm 주석과 cm 사용 경로가 불일치하므로 단위를 먼저 확정한다.
   화면에서 잘 보인다는 이유로 인쇄 해상도를 승인하지 않는다.
5. 이 컬렉션에는 가격·구매·복원 단계를 추가하지 않는다. 별도 신규 유료 상품의
   구매·복원·권한 검증은 그 상품의 출시 전에 진행한다.
6. 동일한 사진·문구로 경쟁 디자인과 블라인드 비교한다. 아직 미리캔버스보다
   뛰어나다는 결론이나 유료 경쟁 템플릿 실물 비교 결과는 없다.

무료 번들 등록은 인쇄 인증이나 서버 배포를 뜻하지 않는다. 위 미확인 항목 때문에
서버 게시·인쇄 승인 표시인 `catalogPublishable: false`는 유지한다.
