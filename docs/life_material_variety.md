# 생활 컨셉 재료 반복 개선

이 문서는 장식만 바꾼 단계의 기록이다. 이후 사용자가 전체 디자인 수정을 요청하여
내지 배치 보존 조건은 해제했다. 현재 내지와 검증 기준은 `life_editorial_redesign.md`를 따른다.
새 재료, 가격, 기존 원본 보관과 반복 제한은 유지한다.

2026-09-10. 사용자가 승인한 전체 디자인을 유지하고 최근 생활 컨셉 4종의
반복된 장식만 교체한다. 표지, 사진, 문구 내용, 주요 조판, 24쪽 구성은 변경하지 않는다.
새 유료 템플릿 추가나 운영 판매 활성화 작업이 아니다.

소품 8종은 built-in imagegen으로 만든 투명 PNG 원본이다.

등록된 비사진 장식은 각 앨범에서 최대 2회만 사용한다. 사진 프레임과 기본 조판은
이번 요청에서 유지한다. 카탈로그에서 기존 재료를 삭제하지 않는다.
수정 전 4종 x 3규격의 문서는
`tool/template_studio/archives/life-before-material-variety`에 보존했다.
`test/design/life_material_variety_test.dart`는 이 기준과 표지·사진·문구·주요 배치를
비교하고, 12개 재료가 실제 쓰이는지와 전체 장식 반복 횟수를 검증한다.

## 검증

- 관련 디자인·재료·가격·편집기 테스트 229개 통과.
- 관련 Dart 파일 13개 정적 분석에서 문제 없음.
- 브라우저 검증은 `verify_concept_volumes.cjs`, `verify_life_materials.cjs`로 수행한다.
- 릴리스 웹 빌드 성공. 기존 4323 미리보기 서버에 반영했다.
- Playwright: 390x844, 844x390, 1440x900에서 컬렉션 7종, 총 21개 조합 통과.
  표지, 첫/중간/마지막 펼침면, 제목 편집, 사진 숨김/복원, 즐겨찾기와 목록 이동 확인.
  화면 105개, 페이지 오류·누락 자산·외부 AI/구매 API 요청 없음.
  결과: `output/template-preview/concept-wave/browser/report.json`.
- 신규 재료 12종 x 3화면 크기에서 확대, 즐겨찾기, 실제 꾸미기 선택기 삽입 통과.
  소품은 색상 다양성, 절제된 기록지는 종이색과 구조 디테일의 픽셀을 확인했다.
  화면 72개, 페이지 오류·누락 자산 없음.
  결과: `output/materials/life-variety/browser/report.json`.
- 가격표는 90개 상품 키, 최근 재료 83종(무료 12, 유료 책정 71)이다.
  운영 DB, 고객 과금, 포함 재료 이용권은 변경하지 않았다.
