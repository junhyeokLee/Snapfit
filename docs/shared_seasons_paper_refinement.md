# 같이 사는 계절: 종이와 문구 조화 재설계

2026-09-10, shared-paper-3. 열쇠와 흰 문구 패널이 사진에 어울리지 않는다는
피드백에 따라 이 컬렉션의 내지 24쪽만 다시 구성했다.

## 변경 기준

- 열쇠, 화병, 실내화, 집게 등 따로 놓인 상품 이미지 같은 연출을 제거한다.
- 사진을 가리는 불투명 흰 라벨, 작은 흰 문구 상자, 진한 체크 천을 제거한다.
- 보라색 접힌 프레임, 다색 우편 테두리, 과한 장식 테두리를 이 책에서 제외한다.
- 수제지 섬유, 얇은 사진 모서리, 글라신 봉투와 소량의 압화/리본을 쓴다.
  사진에 붙이는 재료와 글을 적는 재료를 구분하고, 관련 없는 소품을 추가하지 않는다.
- 명조 제목과 NanumPen 손글씨를 편집 가능한 텍스트로 배치한다.
  큰 영문 제목과 흰 라벨을 매 장 반복하지 않는다.
- 12개 펼침면에서 두 쪽의 바탕색을 맞춘다. 녹회색, 옅은 로즈,
  종이색, 초록 식탁 면이 사진의 색과 이어지도록 한다.
- 서문/마지막 수제지는 실제 재료 비율로 중앙에 배치하고 글씨도 그 영역에 맞춘다.

## 유지

- 큰 사진 표지, 24쪽 분량, 12개 목차와 좌우 페이지 연결 유지.
- 제목/이름/날짜/마지막 기록의 편집과 샘플 사진 교체 유지.
- 다른 생활 컬렉션 3종, 이전 승인 3종, 무료 37종과 재료 카탈로그 유지.
- 이 시안에서 제외한 소품을 꾸미기 기능에서 삭제하지 않는다.
- 새 이미지 생성 없이 기존 사진/재료와 네이티브 프레임을 선별했다.
- 문서와 미리보기 내용 리비전만 3. 가격, 포인트, 판매 상태는 변경하지 않는다.
  유료 디자인 승인이나 경쟁 제품 대비 우위를 선언하는 수정본은 아니다.

## 보관 및 검증

이전 4종 x 3규격 문서는 `tool/template_studio/archives/life-editorial-2`에 보관했다.
다른 생활 컬렉션은 문서 전체가 이 보관본과 동일한지 테스트한다.
재료를 모두 억지로 사용하도록 강제하던 테스트는 제거하고, 재료 카탈로그의
보존과 같은 장식의 권당 최대 2회 사용을 확인한다.

- 디자인/보존 테스트 28개 통과. 7종 x 3규격 x 25쪽 렌더.
- 실제 폰트의 텍스트 높이, 사진/글씨 충돌, 재료 비율, 저장 복원 검사 통과.
- 변경 Dart 파일 정적 분석 통과.
- 꾸미기/프레임/가격 회귀 테스트 203개 통과. 디자인 검사와 합계 231개.
- Playwright 390x844, 844x390, 1440x900에서 이 컬렉션의 표지,
  첫/중간/마지막 펼침면, 제목 편집, 사진 숨김/복원, 즐겨찾기, 목록 이동 통과.
  15개 화면을 촬영하고 실화면의 폰트와 재료 표시를 확인했다.
- 실화면에서 발견한 첫 장 압화/손글씨 겹침을 보정하고, 세 규격의
  장식/문구 간격 회귀 검사를 추가했다. 최종 빌드 후 브라우저 검사를 재실행했다.
- 페이지 오류, HTTP 자산 오류, 외부 AI/구매 API 호출 없음.
  결과: `output/template-preview/concept-wave/browser/report.json`.
