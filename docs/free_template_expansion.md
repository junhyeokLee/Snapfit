> 현재 총 35종이다. 최신 내용은 `free_template_life_categories.md`를 따른다.

2026-09-08. 사용자의 카테고리별 5종 이상 제작 요청에 따라 기존 무료 기본 3종을

## 제작 방식

- 신규 12종은 표지 구도를 각각 설계하고, 책마다 12개의 펼침면에 제목·문구·사진 순서를 작성했다.
- 내지는 갤러리, 기록표, 편지, 엽서, 모자이크, 타임라인 등 신규 조판 프리미티브를 공유한다.
  기존 무료 3종이나 퇴출 시안의 페이지 데이터를 복사하지 않는다.
- 사진·텍스트·프레임·종이·스티커는 기존 네이티브 레이어 구조로 저장한다. 완성 이미지를
  한 장으로 합친 상품이 아니며, 사용자는 사진과 문구를 편집할 수 있다.
- 샘플 사진과 종이·스티커 소재는 기존 제작 자산을 활용한다. 새로운 사진을 생성하거나
  실시간 AI API를 호출한 결과가 아니다. `aiGenerated: false`, `accessTier: free`로 구분한다.
- 단체 사진은 원본 3:2 구도를 유지하고, 인물 사진의 얕은 가로 슬롯은 머리가 잘리는 크롭을 피한다.
  이는 샘플 사진의 미술 배치이며, 사용자가 넣는 모든 사진을 자동 얼굴 보정하는 기능은 아니다.
- 긴 장소명·이름·기간·메모를 세 규격에서 검사한다. 미리보기 문구 폼은 넘치는 입력을 거부한다.

## 앱 연결

`authoredCollections` → `bundledCreationTemplates` → 스토어·검색·앨범 생성·편집기 목록.
기존 기본 3종의 ID·순서·원본 디자인은 유지한다. 신규 12종은 별도 ID를 사용한다.
15종 전체를 사용하는 추천 캐러셀은 점 15개 대신 이전·다음 버튼과 현재 순번을 표시한다.

- 실제 스토어 미리보기: `http://127.0.0.1:4323/?catalog=store`
- 책 단위 미리보기: `http://127.0.0.1:4323/?collection=garden-promise`
- 상단 시안 선택에서 15종 이동, 규격 변경, 목차 이동, 샘플 사진 숨기기, 문구 수정 가능.

## 검수 범위

- 신규 12종 × 세 규격 × 25쪽 = 900개 페이지를 실제 Flutter 렌더러로 검사한다.
- 겹침·텍스트 넘침·캔버스 이탈, 페이지 ID, 중복 사진, 원본 문서 재사용 여부,
  사진 교체 후 프레임 보존, 저장·복원 좌표를 테스트한다.
- 기존 3종·퇴출 문서 호환, 카탈로그 갱신, 15종 검색, 카테고리당 5종 필터,
  무료 선택·세 규격 적용·사진 넣기, 작은 화면 캐러셀을 회귀 검수한다.
- 원본 렌더링 모음: `output/template-preview/free-expansion/`.
- 브라우저 검수 기록: `free-expansion/browser/report.json`, `published-store/report.json`.

검수 결과: 관련 테스트 237개 통과, 정적 분석과 `git diff --check` 통과.
브라우저에서는 15종 × 3규격 × 3화면(390×844, 844×390, 1440×900),
135개 조합의 표지 렌더링·비율·목차 이동·문구 폼을 확인했다.
종이·스티커 이미지가 있는 표지도 스토어에서 하나의 선택 버튼으로 인식되게
접근성을 보완했다. 전체 표지 모음은 `output/template-preview/free-expansion/catalog.png`다.
접근성 보완 후 같은 세 화면에서 15종 검색과 구 시안 제외를 다시 확인한
스토어 브라우저 검사 48건도 통과했다. 이 검사에서 이미지 로딩 실패나
AI·Supabase API 요청은 발생하지 않았다. 웹 릴리스 빌드를 로컬 미리보기에 갱신했다.

실물 인쇄, 사용자 사진 전수 크롭, 최종 배포용 권리 검토는 별도 검수 대상이다.
`catalogPublishable: false`, `printVerified: false`를 유지한다. 이번 작업은 앱 소스와
로컬 미리보기에 반영하며, 네이티브 앱 배포·서버 게시·기존 사용자 앨범 변경은 하지 않는다.
