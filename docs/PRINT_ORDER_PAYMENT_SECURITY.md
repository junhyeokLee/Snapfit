# 외부 실물 주문 결제 퇴역 기록

2026-09-08 사용자 요청에 따라 PortOne과 외부 실물 주문 결제 경로를 제거합니다. 현재 결제 범위는 Apple/Google의 소모성 포인트 구매이며, 대체 결제사나 새로운 실물 checkout을 추가하지 않습니다.

## 변경 이력과 보존 범위

- 최초 결제 점검 중 PortOne 서버 검증과 주문 결제 보안 처리가 추가되었습니다. 기존에 사용자가 선택한 결제사는 아니었습니다.
- `20260908094302_secure_print_order_payments.sql`은 실제 적용 이력이 있는 마이그레이션이므로 삭제하거나 과거 내용을 바꾸지 않습니다.
- 후속 `20260908105146_remove_external_print_payment_integration.sql`로 외부 결제 확인·회수 RPC를 제거하고 신규 고객 주문 생성 및 임의 결제 완료 처리를 차단합니다. 과거 주문, 결제, 제작 및 배송 기록은 삭제하지 않습니다.
- 앱의 외부 결제 시작·재시도·결제 확인 동작을 제거하고 기존 주문 내역 조회를 유지합니다. 구버전 앱의 checkout/확인 요청은 퇴역 응답을 받습니다.
- 준비 상태 점검과 secret 설정 도구에서 외부 결제 옵션·키 입력 경로를 제거합니다. 결제 웹훅 구현도 제거 대상입니다.

이 문서는 로컬 변경과 이력을 설명합니다. 실제 마이그레이션 적용, 구버전 함수 교체와 결제 웹훅 삭제 여부는 [배포 현황](PAYMENT_PUSH_DEPLOYMENT_STATUS.md)에 따로 기록합니다. 원격 작업을 하지 않은 상태에서 배포 완료로 간주하지 않습니다.

포인트 상품·검증 키·환불 대사는 [포인트 운영 안내](POINT_PURCHASE_OPERATIONS.md)를 확인합니다. 이 문서에는 퇴역한 연동을 다시 켜는 설정이나 결제사 키 발급 절차를 제공하지 않습니다.
