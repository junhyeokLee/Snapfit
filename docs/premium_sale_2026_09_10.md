# 2026-09-10 판매 연결

기존 무료 37종과 유료 14종을 앱 스토어, 생성 목록, 편집 디자인 목록에 연결했다.
기존 유료 상품의 식별자를 유지하며 Supabase `rrbhxdtriummqpztpjrk`의
`point_shop_products` 14행만 판매 활성화했다. 실제 조회에서 14행 모두
`matches_expected=true`, `available=true`, `is_free=false`를 확인했다.

- 프리미엄 컬렉션 7종: 2,500P. 24쪽 기본판과 지원되는 32/36쪽 확장판 포함.
- 컨셉 에디션 7종: 1,800P. 표지 + 내지 24쪽.
- 모든 상품은 세로·정사각·가로를 동일 구매 키로 제공한다.
- 템플릿에 배치된 장식은 앨범 생성에 포함된다. 꾸밈 목록에서 다른 작업에
  새로 추가할 수 있는 개별 소재 소유권을 별도로 지급하지 않는다.
- 샘플 사진은 생성 시 제거되며 사용자가 자신의 사진을 넣는다.

사용자 지갑이나 구매 기록은 변경하지 않았다. 실계정 포인트 차감은 실행하지
않았으며 구매 처리는 기존 서버 RPC와 앱 확인창을 유지한다.
기존 원본 문서의 인쇄·권리 검수 메모는 별도 검수 기록으로 유지한다.

실행 SQL과 검증 SQL: `output/premium-registration/sale-2026-09-10/`.
앱 실행본은 변경된 카탈로그가 포함되도록 재시작/재빌드해야 한다.
