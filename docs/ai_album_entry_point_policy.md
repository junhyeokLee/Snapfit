# Snapfit 새 앨범 만들기 / AI 포인트 정책 재기획

## 결론

새 앨범 만들기 첫 화면은 사용자가 **직접 만들지 / AI 초안 도움을 받을지**만 고르는 화면이어야 한다. `커플`, `여행`, `가족`, `아기`, `생일`, `일상`, `직접 입력` 같은 주제는 직접 만들기에는 필요하지 않으며, **AI가 사진 흐름과 제목을 제안할 때만 참고하는 AI 전용 힌트**다.

```text
새 앨범
├─ 직접 구성하기
│  └─ 기존 앨범 기본 설정 Step1로 바로 이동
│     └─ 제목 / 책 비율 / 분량 / 표지 / 에디터
│
└─ AI 초안으로 시작하기
   └─ AI 주제 선택
      └─ 사진 범위 선택
         └─ 포인트 확인
            └─ 추천 결과 리뷰
               └─ 기존 앨범 기본 설정 Step1 / 에디터
```

## 시작 화면 원칙

- 시작 화면에는 AI 주제 칩을 노출하지 않는다.
- 직접 구성하기 카드에는 `주제`, `테마`, `추천` 단어를 넣지 않는다.
- 직접 만들기는 AI 포인트가 들지 않는다는 점을 부드럽게 안내한다.
- AI 카드는 추천 경로이지만, 수동 제작이 열등해 보이지 않게 한다.

## 시작 화면 카피

```text
작은 책으로 남길 순간을 골라볼까요?
직접 차근차근 만들거나, Snapfit이 먼저 초안을 정리해드릴 수 있어요.
```

### 직접 구성하기

```text
직접 구성하기
제목, 책 비율, 분량을 직접 정하고 빈 앨범에서 시작해요.

• 사진과 문구를 원하는 순서대로 배치
• 기존 에디터 기능 그대로 사용
• AI 포인트 사용 없음

직접 만들기
```

### AI 초안으로 시작하기

```text
AI 도움
AI 초안으로 시작하기
앨범 주제와 사진 범위를 알려주면, 어울리는 사진과 흐름을 먼저 정리해드려요.
AI 초안 만들기 300P

AI 초안 만들기
```

하단 안내:

```text
어떤 방식으로 시작해도, 마지막에는 에디터에서 직접 고칠 수 있어요.
```

## AI 전용 주제 선택 화면

이 화면에서만 주제를 묻는다. 주제는 앨범 카테고리가 아니라 AI에게 주는 참고 힌트다.

```text
AI 초안
어떤 앨범으로 정리해볼까요?
선택한 주제는 AI가 사진 흐름과 제목을 제안할 때만 참고해요.
```

주제 후보:

```text
여행 — 날짜와 장소 흐름
가족 — 함께한 장면 중심
아기·성장 — 변화와 표정 기록
커플 — 둘의 시간
친구 — 같이 웃은 순간
생일·기념일 — 축하와 하이라이트
일상 — 남기고 싶은 하루
직접 입력 — 원하는 주제로
```

안내:

```text
정답을 고르는 단계가 아니에요. 나중에 제목, 사진, 페이지는 모두 바꿀 수 있어요.
```

## 포인트 가격 권장

기본 AI 앨범 초안 만들기는 **300P**를 권장한다.

이유:

- 무료처럼 보이지 않아 고기능 AI 큐레이터의 가치가 산다.
- 첫 사용자가 시도하기에 지나치게 부담스럽지 않다.
- 향후 서버 Vision/LLM이 붙어도 기본 원가 방어가 가능하다.
- 포인트 번들 UX와 맞추기 쉽다.

권장 정책:

```text
첫 1회 무료 체험
이후 AI 앨범 초안 만들기 300P
정밀 추천 모드가 생기면 700P 이상 별도
직접 만들기는 포인트 없음
```

## 포인트 차감 정책

포인트는 **AI 초안 결과가 성공적으로 만들어진 뒤에만 차감**한다.

실패/권한 부족/사진 부족/네트워크 실패 상태에서는 차감하지 않는다.

카피:

```text
AI 초안을 만들어볼까요?
선택한 사진 안에서 어울리는 장면과 앨범 흐름을 먼저 정리해드릴게요.

주제: 여행
사진 범위: 최근 30일
사용 포인트: 300P
보유 포인트: 1,200P

초안은 바로 확정되지 않아요. 결과를 보고 마음에 드는 구성만 선택할 수 있어요.
초안 생성이 실패하면 포인트는 차감되지 않아요.

300P로 AI 초안 만들기
사진 범위 다시 고르기
```

## 포인트 부족 상태

```text
포인트가 조금 부족해요
AI 초안을 만들려면 300P가 필요해요. 지금은 {보유 포인트}P를 가지고 있어요.
직접 구성하기로 시작하면 포인트 없이 바로 만들 수 있어요.

포인트 충전하고 계속
직접 구성하기로 만들기
사진 범위 다시 고르기
```

## 구현 주의사항

- 직접 구성하기 path에는 AI 주제 선택 화면을 절대 노출하지 않는다.
- AI 주제 선택은 AI path에서만 노출한다.
- 포인트 확인은 사진 범위 선택 뒤, 실제 AI 초안 생성 직전에 노출한다.
- 포인트 안내는 차갑게 결제 화면처럼 보이지 않게 `초안 생성 전 확인` 톤으로 쓴다.
- 추천 결과 리뷰 전에는 앨범을 확정 생성하지 않는다.
- 기존 Step1과 에디터 컨트롤은 유지한다.
