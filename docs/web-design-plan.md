# 스냅핏 웹 디자인 개선 계획

스냅핏 웹은 PC에서 사진을 정리하고, 앨범을 편집하고, 완성한 책의 주문 상태를 확인하는 작업 공간으로 구성한다. 앱의 청록색과 보라색은 유지하고, 넓은 화면은 앨범과 편집 도구에 배분한다. 첫 화면의 목표는 사용자가 자신의 앨범을 바로 찾아 다음 작업을 시작하는 것이다.

## 2026-10-20 후속 적용 기준

공개 첫 방문은 디자인 탐색, 로그인 후 첫 화면은 내 앨범 작업공간이다. 일반 웹 헤더는 넓은 창에서 한 줄 탐색, 좁은 창에서는 전체 메뉴로 구성한다. 카탈로그의 보조 필터는 작은 창에서 접는다. 템플릿과 꾸밈소재 탭은 주소·브라우저 이동과 연결하고, 개인 검색어를 주소에 넣지 않은 채 같은 작업공간의 입력과 스크롤을 보존한다. 비로그인 상세에는 계정용 메뉴·알림·보관을 노출하지 않고 공개 미리보기·로그인·공유만 제공한다. 아래 기존 기록과 다른 부분은 이 기준을 우선한다.

## 웹 전체 반영 내용

웹의 이미지 스플래시를 제거하고 계정 확인 뒤 로그인 또는 내 앨범으로 이어지게 했다. 공통 헤더·브라우저 탭·설치 아이콘은 앱에서 사용하는 실제 책 로고로 통일했다. 모바일 로고와 스플래시는 유지한다.

일반 화면은 브랜드·알림·테마 영역과 전역 탐색을 분리하고, 목록·설정 제목은 짧은 작업 이름으로 통일했다. 내 앨범은 임시 저장·검색·정렬·카드 및 목록 전환을 우선한다. 템플릿·소재·AI 만들기·디자인 보관함과 공유 앨범의 기존 진입을 유지한다.

템플릿과 소재는 검색·분류·무료 및 포인트·보유·즐겨찾기·정렬·초기화를 같은 도구줄에 배치했다. 상세 화면은 비율을 보존한 미리보기와 사용 버튼·규격을 나란히 보여주며, 긴 설명은 사용 버튼 뒤에 둔다. 좁거나 높이가 낮은 창에서는 전체 스크롤로 끝 행동까지 접근한다.

만들기는 단계·규격·사진 채우기 흐름을 유지하고 확인 행동을 하단에 모았다. 사진을 가져올 때 파일별 읽는 중·준비·중복·오류를 표시한다. 원본 사진의 바이트와 기존 용량 제한은 바꾸지 않는다.

편집·미리보기·페이지 상세는 제목·상태·저장 및 이동 행동을 간결한 헤더로 통합했다. 편집기의 페이지 목록·중앙 캔버스·속성과 큰 도구창·확대·축소·회전 조작을 유지한다. 좁은 편집창은 페이지 띠를 기본으로 접어 작업 면적을 확보하고, 버튼으로 다시 펼친다.

주문은 왼쪽 입력과 오른쪽 규격·금액 요약, 작은 창에서는 입력 후 요약 순서로 구성했다. 긴 폼과 주문 확인·완료 화면은 페이지 전체를 스크롤한다. 주문내역은 앨범·사양·금액·상태·택배사·송장을 비교할 수 있게 하며, 좁은 창에서는 카드로 전환한다.

계정·프로필·포인트·알림 설정·고객센터·주문 문의·정책 화면은 같은 웹 제목·입력·요약 구조를 사용한다. 좁은 목록 화면의 보조 안내는 접어서 확인할 수 있다. 계정 전환 시 정보 숨김, 저장·나가기·동의·결제 준비 검증과 기존 콜백을 유지한다.

## 전체 메뉴 구조

| 영역 | 사용자가 할 일 | 대표 행동 |
| --- | --- | --- |
| 내 앨범 | 만들던 앨범 찾기, 즐겨찾기, 검색 | 새 앨범 만들기, 앨범 열기 |
| 앨범 만들기 | 규격과 시작 방법 선택, 사진 올리기 | 다음 단계, 임시 저장 |
| 템플릿 및 소재 | 디자인 비교와 미리보기, 보관함 확인 | 미리보기, 내 앨범에 사용 |
| 앨범 편집 | 사진·글·페이지 구성 편집 | 저장 |
| 앨범 미리보기 | 전체 흐름과 각 페이지 검토 | 편집, 책으로 주문 |
| 주문 | 인쇄 사양, 주소, 최종 금액 확인 | 다음 단계 |
| 주문내역 | 진행 상태와 배송 확인 | 주문 상세 |
| 계정 | 로그인 정보, 포인트, 알림, 화면 설정 | 설정 저장 |

앨범 보관함과 디자인 보관함은 명칭을 구분한다. 실제 결제는 기존의 비활성 상태를 유지한다. 화면의 버튼 활성화는 서버의 판매 준비 상태를 따른다.

## 화면별 적용 구조

| 화면 | 적용 내용 |
| --- | --- |
| 로그인 | PC의 소개·로그인 2열, 좁은 창은 입력 폼 먼저 배치 |
| 만들기 | 단계·규격 요약, 하단 확인 행동, 파일별 가져오기 상태와 오류 |
| 템플릿 및 소재 | 항상 보이는 검색, 줄바꿈하는 분류와 이용 구분, 정렬·초기화 |
| 디자인 상세 | 큰 작품 미리보기와 사용·규격 영역, 낮은 창의 전체 스크롤 |
| 전체 디자인 미리보기 | 비율 유지, 확대·축소·초기화, 좌우 키보드 이동 |
| 편집 | 제목·저장 상태·저장을 통합한 헤더, 페이지·캔버스·속성 유지 |
| 편집 도구 | 레이어·레이아웃·템플릿·꾸미기·배경의 큰 선택창과 적용 후 복귀 유지 |
| 앨범 미리보기 및 페이지 상세 | 간결한 헤더와 큰 작품, 페이지 탐색·편집·주문 행동 분리 |
| 주문 | 배송지와 사양·금액 요약, 입력 유지, 페이지 전체 스크롤 |
| 주문내역 | 상태·사양·금액·택배사·송장 표시, 좁은 창 카드, 계정별 접근 유지 |
| 계정 및 보관함 | 프로필 요약·설정 묶음, 보유 디자인과 즐겨찾기 진입 |
| 포인트 및 알림 | 이용 내역 중심 배치와 접을 수 있는 보조 안내, 기존 충전·푸시 설정 유지 |
| 공유 및 고객지원 | 짧은 제목, 검색 조건 초기화, 권한·요청 내용·정책을 확인하는 웹 폼 |

## 공통 디자인 기준

| 항목 | 기준 |
| --- | --- |
| 브랜드 색 | 기존 스냅핏 청록색을 주요 행동에 사용하고 보라색은 보조 강조에 사용 |
| 화면 배경 | 밝은 배경과 흰 표면을 구분하고 다크 테마에서는 기존 웹 팔레트 사용 |
| 폭 | 일반 화면은 최대 1320px, 편집·미리보기는 작업 영역 전체 활용 |
| 간격 | 기본 8px 단위, 일반 화면 여백은 넓은 창 32px와 좁은 창 20px |
| 제목 | 목록·설정은 짧은 작업 이름, 소개 문구는 필요한 화면에 한정 |
| 버튼 | 주 행동 하나를 청록색으로 강조하고 탐색·취소는 보조 버튼으로 구분 |
| 작품 이미지 | 표지와 내지는 비율을 보존하고 자르지 않음, 확대 시 원본 또는 큰 미리보기 사용 |
| 입력 | 라벨과 오류를 입력 근처에 배치, 오류가 나도 입력 내용 보존 |
| 상태 | 색상과 함께 상태 이름 표시, 로딩·빈 결과·권한 없음·연결 오류를 구분 |
| 마우스와 키보드 | 클릭 가능 영역과 포커스 표시 유지, 아이콘 버튼은 이름 또는 툴팁 제공 |

## 반응형 배치

넓은 PC에서는 메뉴와 도구를 펼치고, 창이 좁아지면 검색 도구줄을 줄바꿈하고 카드 열 수를 줄인다. 웹에서 창 크기가 바뀌어도 선택한 앨범과 검색 조건을 유지한다. 모바일 앱의 레이아웃·조작·테마는 웹 변경과 분리한다.

확인은 1440px PC, 1024px 작은 PC, 768px 태블릿, 390px 및 320px 좁은 브라우저를 기준으로 한다. 밝은·어두운 테마와 글자 확대에서 가로 넘침, 잘린 버튼, 접근할 수 없는 다음 단계를 확인한다. 주문과 결제 관련 화면은 디자인 확인과 실제 결제 실행을 구분한다.

## 검증 범위

웹 전용 화면 구성과 실제 화면 경로를 로컬 예시 데이터로 검사한다. PC·작은 창·낮은 창·큰 글자·다크 테마에서 검색 조건 유지, 작품 비율, 버튼 접근, 사진 원본 보존, 계정별 정보 표시와 결제 비활성 상태를 확인한다. 모바일 편집·카탈로그·계정·주문의 기존 검사도 함께 수행한다.

실제 결제, 결제창 승인, 포인트 구매, AI 유료 생성, 업체 발주와 서버 설정 변경은 디자인 검증에서 실행하지 않는다. 로컬 예시 화면 이미지는 사용자 계정이나 실제 주문 정보를 포함하지 않는다.
